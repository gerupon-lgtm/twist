# twist

自機は画面中央に保ち、スマホの回転を打ち消して最初の上向きを保つ3D操作検証です。周囲が動く中で空中の光を集めます。これまでの探索モードに、ユーザーが提案した操作を試す飛行機モードを追加しました。

**操作検証 v0.1.3 / 2026-11-07**

公開URL:

- [飛行機モード](https://gerupon-lgtm.github.io/twist/?mode=flight&v=0.1.3)
- [探索モード](https://gerupon-lgtm.github.io/twist/?mode=explore&v=0.1.3)

`mode` の指定なしは探索です。開始画面・一時停止画面でも切り替えられます。切替時は速度0・ステージの最初へ戻ります。公開版への反映結果は [検証記録](docs/verification-v013.md) に記録します。

## 2つの操作

端末を回した後も、画面内に見えている自機の先端と左右を操作の目印にします。以下の「先端側」は端末本体の上辺に固定されません。

| 操作 | 飛行機モード | 探索モード |
| --- | --- | --- |
| 先端側を上げる・下げる | 上げると機首が上へ、下げると下へ回り続ける | 下げると加速、上げるとブレーキ |
| 自機の右側・左側を下げる | 翼を傾け、前進中はその側へ旋回 | その側へ曲がり続ける。停止中も見回せる |
| 小さく右・左へひねる | 右で加速、左で減速 | 右で上へ、左で下へ回り続ける |
| 中立へ戻す | 速さと機首の向きを保ち、翼の傾きは滑らかに戻る | 速さと進路を保つ |
| 手動で開始・再開 | 6m/sで前進を始める | 0m/sから始める |
| PCキー | W/Sで機首の上/下、A/Dで旋回、Q/Eで減速/加速 | Wで加速、Sでブレーキ、A/Dで左右、Q/Eで下/上 |

どちらも制動で0まで減速し、後退はしません。飛行機モードの翼の傾きは最大40度で、速度0では翼を傾けても旋回しません。上下の旋回は両モードとも一周できます。飛行機モードは操作を比べるための飛行機風の動きで、実際の飛行力学を再現するものではありません。

## スマホで試す

1. 公開URLをSafariまたはChromeで直接開き、「スマホの傾きで始める」を押します。
2. 動きと向きの利用を許可し、少しスマホを動かします。
3. 画面が見やすい持ち方に戻し、探索では「この持ち方で始める」、飛行機では「この持ち方で飛ぶ」を押します。
4. 飛行機はこの操作で6m/sの前進を始め、探索は停止から始まります。上の比較表に沿って先端・左右・ひねりを試します。
5. 空中の金色の光を順番に3つ集め、案内に従って青い出口へ進みます。青い六角の輪・点の道しるべ・高さ目盛は位置を把握する目印です。

持ち方を変えたいときは「持ち方を合わせ直す」。自機の上向きは保ったまま、操作の中立だけを取り直します。通常の画面の縦横変更では操作基準と速度を維持します。センサー消失、画面を離れた場合、自機が真横に見えて先端を判別できない角度では速度0へ停止し、手動で再開します。飛行機は再開ボタンから6m/sへ戻り、自動で再開はしません。

画面下には入力角度・前進速度・高さ・検証版番号を表示します。PCや「画面操作で試す」は疑似入力の練習で、スマホの操作感を確認したことにはなりません。

練習つまみは端末自身の上辺・右辺・回し角度を再現し、ゲーム側で自機基準に読み替えます。「姿勢を戻す」でも速度は維持します。すぐに全て止めたい場合は「一時停止」を使います。スマホ実機での物理的な見え方・操作感は未確認で、[確認項目](docs/verification-v013.md) に残しています。

## ローカル起動

Node.js 24以上を使用します。

```sh
npm ci
npm run dev
```

センサーの利用にはHTTPSが必要です。PCのHTTP開発サーバーをスマホで開いただけでは、センサーを使えない場合があります。スマホ確認には公開URLを使用します。

```sh
npm test
npx playwright test
npm run build
```

ブラウザー検証はWindowsでは既存のEdgeを使用します。CI環境で実行する場合は `npx playwright install --with-deps chromium` が必要です。
