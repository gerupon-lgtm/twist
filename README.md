# twist

自機は画面中央に保ち、スマホの回転を打ち消して最初の上向きを保つ3D探索の操作検証です。上部を下げて加速、起こしてブレーキ。周囲が動く中で、空中の光を集めます。

**操作検証 v0.1.1 / 2026-11-07**

公開URL: https://gerupon-lgtm.github.io/twist/?v=0.1.1

## スマホで試す

1. 公開URLをSafariまたはChromeで直接開き、「スマホの傾きで始める」を押します。
2. 動きと向きの利用を許可し、少しスマホを動かします。
3. 画面が見やすい持ち方に戻し、「この持ち方で始める」を押します。
4. スマホ上部を下へ倒している間は加速、上へ起こすとブレーキです。前後を基準へ戻すと、現在の速さを保ちます。ブレーキで止まり、後退はしません。
5. 左右に傾けると左右へ、平らに回すように右へひねると上へ・左へひねると下へ、傾けている間は曲がり続けます。
6. 空中の金色の光を順番に3つ集め、案内に従って青い出口へ進みます。青い六角の輪・点の道しるべ・高さ目盛は位置を把握する目印です。

持ち方を変えたいときは「持ち方を合わせ直す」。センサーが読めない場合、更新が途切れた場合、画面を離れた場合、画面の向きが変わった場合は停止します。

画面下には入力角度・前進速度・高さ・検証版番号を表示します。PCや「画面操作で試す」は疑似入力の練習で、スマホの操作感を確認したことにはなりません。

PCのキーはWで加速、Sでブレーキ、A/Dで左右、Q/Eで下/上です。練習用つまみの「傾きを0に」も、現在の速さは維持します。すぐに全て止めたい場合は「一時停止」を使います。

## ローカル起動

Node.js 24以上を使用します。

```sh
npm ci
npm run dev
```

センサーの利用にはHTTPSが必要です。PCのHTTP開発サーバーをスマホで開いただけでは、センサーを使えない場合があります。スマホ確認には公開URLを使用します。

```sh
npm test
npx playwright test
npm run build
```

ブラウザー検証はWindowsでは既存のEdgeを使用します。CI環境で実行する場合は `npx playwright install --with-deps chromium` が必要です。
