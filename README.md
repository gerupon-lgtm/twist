# twist

自機は画面中央に保ち、スマホの回転を打ち消して最初の上向きを保つ3D操作検証です。周囲が動く中で空中の光を集めます。飛行機モードでは、画面のエンジン出力と端末の傾きで飛び、速さと高さが影響し合う動きを試します。

**操作検証 v0.1.6 / 2026-11-07**

公開先URL:

- [飛行機・見失い対策（今回のおすすめ）](https://gerupon-lgtm.github.io/twist/?mode=flight&view=assisted&v=0.1.6)
- [飛行機・従来の見え方](https://gerupon-lgtm.github.io/twist/?mode=flight&view=classic&v=0.1.6)

`mode` の指定なしは探索、`view` の指定なしは見失い対策です。開始画面・一時停止画面の「遊び方」で飛行機・探索を切り替えると、速度・出力0でステージの最初へ戻ります。「見え方」は同じ位置・向きのまま切り替えて比較できます。現在の確認結果と残る作業は [v0.1.6の検証記録](docs/verification-v016.md) に記録します。

## 見え方を比べる

v0.1.6は、操縦と飛行の計算をv0.1.5から保ち、次の3点を加えた比較版です。探索モードでも表示を比べられます。

- 縦持ちの視野を広げ、周囲を見渡しやすくする。
- ステージの4方向へ、色と形の異なる大きな目印を置く。
- 次の目標が画面外へ出たら、画面の端に矢印・目標名・上下や後ろ・距離を表示する。

開始画面または一時停止画面で「見失い対策」「従来」を選びます。見え方の切替そのものは位置・向きや飛行の計算を変えません。従来では追加の目印と画面端マークを隠し、v0.1.5の視野へ戻します。スマホ実機で見失いにくくなったかは未確認です。端末を傾けた際に自機が細く見える点も、今回で解決済みとは扱わず確認項目に残しています。

## 2つの操作

端末を回した後も、画面内に見えている自機の先端と左右を操作の目印にします。以下の「先端側」は端末本体の上辺に固定されません。

| 操作 | 飛行機モード | 探索モード |
| --- | --- | --- |
| 先端側を上げる・下げる | 上げると機首が上へ、下げると下へ回り続ける | 下げると加速、上げるとブレーキ |
| 自機の右側・左側を下げる | 翼を傾け、前進中はその側へ旋回 | その側へ曲がり続ける。停止中も見回せる |
| 画面下のスロットル | 出力0〜100%。指を離しても出力を保つ | 使用しない |
| 右・左へひねる | エンジン出力・速度を操作しない | 右で上へ、左で下へ回り続ける |
| 中立へ戻す | 機首の向きと出力を保ち、翼は滑らかに戻る。速さは飛び方で変わる | 速さと進路を保つ |
| 加減速の中立範囲・最大角度 | 出力はスライダーで調整 | 前後各3度以内は中立、各12度で最大の強さ |
| 手動で開始・再開 | 出力50%・6m/sで前進を始める | 0m/sから始める |
| PCキー | W/Sで機首の上/下、A/Dで旋回、Q/Eで出力を弱く/強く | Wで加速、Sでブレーキ、A/Dで左右、Q/Eで下/上 |

飛行機モードでは、同じ出力でも機首を上げて登ると減速し、下げて降りると加速します。翼の傾きは最大40度。出力を絞ると速さと翼の支える力が減り、降下しやすくなります。出力0%でも勢いで滑空するため、すぐ止めるときは「一時停止」を使います。速度0で浮き続ける動きにはしません。

重力3m/s²、最高速度18m/sなど、操作感を試すための調整値を使っています。エンジンの推す力、空気抵抗、翼の支える力、重力を近似したゲーム向けの動きで、実際の航空機の性能は再現しません。

探索モードはv0.1.4の12度操作を継続します。12度は加速・ブレーキの**強さ**が最大になる角度で、すぐ最高速度になる意味ではありません。最高速度10m/s、最大加速3.5m/s²・最大制動6.5m/s²。中立では今の速さを保ち、反対側へ倒すと制動して0で止まります。後退はしません。

## スマホで試す

1. 公開URLをSafariまたはChromeで直接開き、「スマホの傾きで始める」を押します。
2. 動きと向きの利用を許可し、少しスマホを動かします。
3. 画面が見やすい持ち方に戻し、探索では「この持ち方で始める」、飛行機では「この持ち方で飛ぶ」を押します。
4. 飛行機は出力50%・6m/s、探索は停止から始まります。飛行機は画面下の出力スライダーと先端・左右の傾きを試し、探索は先端・左右・ひねりを試します。
5. 空中の金色の光を順番に3つ集め、案内に従って青い出口へ進みます。青い六角の輪・点の道しるべ・高さ目盛は位置を把握する目印です。

持ち方を変えたいときは「持ち方を合わせ直す」。自機の上向きは保ったまま、操作の中立だけを取り直します。通常の画面の縦横変更では操作基準と速度を維持します。センサー消失、画面を離れた場合、自機が真横に見えて先端を判別できない角度では速度・出力0へ停止し、手動で再開します。飛行機は再開ボタンから出力50%・6m/sへ戻り、自動で再開はしません。

飛行機が地面付近の高さ2mに達すると安全停止します。「最初から飛び直す」で出発地点から出力50%・6m/sで再出発します。

画面下には入力角度・速度・高さ・検証版番号を表示し、飛行機では出力・機首・翼の傾き・昇降速度も表示します。PCや「画面操作で試す」は疑似入力の練習で、スマホの操作感を確認したことにはなりません。

練習つまみは端末自身の上辺・右辺・回し角度を再現し、ゲーム側で自機基準に読み替えます。「姿勢を戻す」は飛行機では出力、探索では速度を保ちます。飛行機の練習用「出力0%」も即停止ではありません。全て止めたい場合は「一時停止」を使います。スマホ実機での物理的な見え方・操作感は未確認で、[確認項目](docs/verification-v016.md) に残しています。

## ローカル起動

Node.js 24以上を使用します。

```sh
npm ci
npm run dev
```

センサーの利用にはHTTPSが必要です。PCのHTTP開発サーバーをスマホで開いただけでは、センサーを使えない場合があります。スマホ確認には公開URLを使用します。

```sh
npm test
npx playwright test
npm run build
```

ブラウザー検証はWindowsでは既存のEdgeを使用します。CI環境で実行する場合は `npx playwright install --with-deps chromium` が必要です。
