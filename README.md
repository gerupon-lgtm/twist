# twist

自機を画面中央に保ち、周囲が動く中で空中の光を集める3D操作検証です。飛行機は右旋回なら右、左旋回なら左へ機体が傾き、スマホ本体の傾きと画面のエンジン出力で操縦します。探索ではスマホの回転を打ち消して最初の上向きを保ちます。

## v0.1.22の振動・別案BGM・目標高度の目印

通常飛行の振動を60ms間隔の細かな震えへ変更。失速は長い震えを強めに、取得は短・長、ゴールは3段、接地は長い1回の合図に分けました。「音と振動」の「通常飛行の振動間隔」で従来の400ms間隔にも戻せます。実機での感触と、振動によるセンサーへの影響は未確認です。

今の2曲をそのまま残し、別案のオリジナル曲「勇進の航路」（ホ短調・170BPM・約68秒）を追加。低音の16分刻み、音の立ち上がりと減衰、勇敢な主題、区切りのドラムで推進力を狙っています。「音と振動」の「飛行中の曲」で、従来2曲／別案／3曲を順番に、から選択・保存できます。指定なしは従来2曲です。[別案を試す](https://twist.sikumilab.com/?mode=flight&camera=cockpit&music=brave&v=0.1.22)。添付MMLは編成の一般的な参考に限り、旋律・波形・エンベロープ・ファイルは使用していません。

次の光・出口の高さと、高さを合わせる帯を全視点・探索にも追加。操縦席は右の高度計、それ以外は地面までの値の近くに表示し、帯の中では「高さOK」、間に合いにくい接近時は早めの上下合図を出します。高さだけでなく左右の進路も目標へ合わせる必要があります。「調整」の「目標高度の目印」でオン／オフして保存・コピーできます。従来表示では隠します。光・出口の位置、取れる範囲、操縦・物理計算は変更していません。

重複する資料A・Bはv0.1.20〜21の実装を継続し、新規Cと今回の直接依頼を反映。[検証と実機確認の手順](docs/verification-v0122.md)、[音楽の設定と差し替え](docs/music.md)。

## v0.1.21の操縦席改善（追加資料B）

機首の動きと旋回方向の手がかりを増やすため、操縦席だけ上の案内を1行にまとめ、下の出力スライダーと操作部分を小さくしました。停止・合わせ直しのボタンは高さ42pxを保ち、出力は下の1か所だけで表示します。外から見る2視点のパネル配置はv0.1.20のままです。

角度線は初期値で機首の前後10度だけ。中央に短く描き、負の角度の破線を薄くします。「調整」で前後5〜30度へ変更可能。高度の横には上昇/下降の棒と数値を、景色には大きくした進行方向の印を表示します。操縦席の上下の視野は初期の自動計算を保ち、自動を外すと60度〜今の視野まで狭められます。操縦や飛ぶ力へは影響しません。

上昇時は高く間隔の短い音、速い下降時は低く長い音で知らせる「バリオ」を追加しました。効果音専用PSGを使い、警告・取得・接地・ゴールを優先します。「音と振動」でオン/オフして保存できます。初期値はオンで、ほかの飛行視点でも使えます。

見失い対策では12方向の浮島と遺跡、中央付近の高い塔、太陽、12か所の高さの違う雲を追加。遠景は霧で消さず、淡い色にしています。従来/legacyは元の世界を保ちます。新しい景色に当たり判定はなく、地面だけで止まるルールも継続。[検証記録と実機手順](docs/verification-v0121.md)。見やすさ・方角の分かりやすさ・バリオの聞こえ方・Pixel 9aの負荷は未確認です。

## v0.1.19のホーム画面起動と画面の向き

画面の自動回転で操作の基準がずれないよう、Androidは最後の開始ボタンで全画面を試し、その直前の向きに固定します。固定/全画面が使えなくても遊べます。「持ち方を合わせ直す」で再固定、一時停止には解除ボタンがあります。ホーム画面のアプリ表示はOS側のため、解除後もバーが戻らない場合の案内も出します。

iPhoneは開始時に、縦向きロックの案内を10秒のトーストで表示します。横持ちでは縦ロックが横固定に使えないことを案内。飛行中に画面の向きが切り替わったら停止し、開始時の向きへ戻して、持ち方を合わせ直してから手動再開します。手動の一時停止中は持ち替えられます。

ホーム画面への追加に対応するmanifest/アイコンを同梱。Androidの追加ボタンはブラウザーから提案が来た場合だけ、iPhoneブラウザーには共有→「ホーム画面に追加」を表示し、アプリ起動時は追加案内を隠します。記録/コピーには`launch: browser|installed`と`fullscreen: true|false`を加えます。

毎回通信する最小のサービスワーカーを採用し、オフライン用キャッシュは作りません。開いたままの画面も復帰時に版を調べ、新版があれば停止して更新ボタンを出します。**ホームアイコンからの起動・物理的な向き固定・全画面はPixel 9a/iPhone XRで未確認**です。[検証記録と両端末の確認手順](docs/verification-v0119.md)。

正式URLは [twist.sikumilab.com](https://twist.sikumilab.com/?mode=flight&v=0.1.19)。[旧GitHub Pages URL](https://gerupon-lgtm.github.io/twist/?mode=flight&v=0.1.19)は新ドメインへ転送されます。設定はドメインごとの端末内保存なので、旧URLで保存した値は新ドメインには引き継がれず、初期値になります。

## v0.1.17の振動と効果音

画面を見続けなくても状態に気づけるよう、出力に応じたエンジン音・速度による風の音・失速前後と地面の警告・光/ゴール/接地の音を加えました。指定したSCCシミュレーター0.8.12の音源計算をそのまま同梱し、効果音専用のPSGを使用します。BGM用のSCC+別PSGは次の版のために分けています。[SCC/MAME等のライセンス表示](public/licenses/SCC-NOTICE.txt)。元の計算ファイルの取得元とSHA-256は`src/vendor/scc/source.json`に記録しています。

開始ボタンより前には音・振動を出しません。一時停止や画面を離れたときは止めます。光は短く2回、ゴール/接地は連続振動を止めてから一回の通知だけを再生します。振動の強さは実際の力ではなく「振動する時間の割合」です。迎え角（翼に風が当たる角度）が14度前後から増え、失速時は長短の不規則な振動になります。

「一時停止→調整→音と振動」でオン/オフ、音量（初期25%）、振動の倍率、通常飛行の細かな震えを変更・端末保存できます。振動が使えない端末では、その設定を隠して説明します。上の「計測」で入力の揺れ幅（意図的な操作も含む）、音源負荷、描画・操作のCPU時間を確認でき、設定/結果コピーにも含めます。**Pixel 9aでの音の聞こえ方・振動・センサーへの影響・処理負荷は未確認**です。[指示資料](docs/instruction-haptics-sfx.md) と [検証記録/実機手順](docs/verification-v0117.md)。

## v0.1.16の視点と機体

開始・一時停止画面の「視点」で、同じ位置・向きのまま表示だけを切り替えます。操縦・飛ぶ力・接触判定は共通です。

- **従来**：世界の表示はv0.1.15と同じです。自機だけ新しい機体の上面図に変わります。
- **追尾3D**：世界の中に置いた立体機を、約25m後ろ・9m上の位置から追います。上下・左右の向きを初期0.15秒遅らせ、旋回中は側面も見えます。調整の「追尾カメラの遅れ」は0〜0.5秒、0で即時。低空では見る位置が地面の下に入らないよう補います。bankは機体が傾き、fixedは機体の上向きを保って景色が傾きます。
- **操縦席**：自機を描かず、速度・地面までの高さ・昇降速度・方位・出力を緑色で表示します。地面を見る補助は使いません。水平線・5度ごとの機首角度の線・実際の進行方向の印は、景色と同じ画角・回転で描きます。機首の印と進行方向の印が離れれば、機首と移動の向きが違います。画面外の進行方向は内側の縁で「進行」と表示します。速度・高度・方位・出力・警告・ボタン・レーダーは回しません。

新視点では、有限のステージの先にも水平な地面の背景を描き、水平線とHUDの基準を一致させます。これは表示だけで、移動範囲は変わりません。機体は双発・双尾翼・長い機首のオリジナル模型を基本形状から生成し、両表示で共用。外部模型や実在機の名称・標章は使いません。出力を上げると2つの噴射が明るく長くなり、0で消えます。

コピーに`camera`を追加し、追尾以外の`chaseTimeConstant`は未使用にします。操縦席では下の入力角度表示を省き、注意・復帰補助をHUD内にまとめます。設定は端末内に保存します。

### 旋回を少ない動きで最大にする追加調整

画面が見えづらくなるほどひねらないと最大旋回にならない、という追加資料の報告を受け、機首と旋回の最大入力角度を分けました。公開前のため同じv0.1.16に含めます。「旋回が最大になるひねり」は初期15度（5〜30度）、「旋回が最大になる回し」は初期20度（8〜40度）。機首は初期25度のまま、翼の最大角度と旋回の強さの計算も維持します。

中立範囲は機首と旋回で別にし、ひねる3度・回す5度の既存値を保つため、保存値を`steerTiltDeadzone`と`steerTwistDeadzone`に分けました（各0〜8度、最大入力角度より1度以上小さく補正）。選んだ方式の項目だけを調整画面に表示します。`steerCurve`は1〜2、初期1の直線。大きくすると中立付近の反応を弱め、最大近くで強くします。最大の翼角は変えません。旧保存値を保ちながら新項目を初期値で補い、未選択方式の設定はコピーの`inactiveSettings`に入れます。[追加指示](docs/instruction-steer-angle.md)。実機の操作感は未確認です。

## v0.1.15のレーダー・光・記録

見失い対策（`view=assisted`）では、進行方向を上にした円形レーダーを飛行機と探索の両方に表示します。自機は中央の三角、次の光は大きいピンクの点、その後の光は小さい点です。取った光は消え、3つ取ると出口が青いひし形で現れます。▲は上、▼は下、＝は高さ差1m以内。次の光には高さ差のm値も添えます。

初期範囲は半径60mで、破線の円が範囲の縁です。範囲外は縁に留めます。一時停止の「調整」で20〜120mに変更・保存でき、探索ではこの項目だけを表示し、初期化もレーダー範囲だけに限定して保存済みの飛行設定を保持します。進行方向は横方向の移動がある間は実際の移動方向、停止中は機首の向きを使います。fixedでもレーダーはスマホの面内回転を打ち消さず、文字やメーターと同じく画面に沿います。

光はピンクの芯と白い輪にし、遠方にも画面上で約23px以上の輪を描きます。次の光だけ地面へピンクの柱を立てます。従来の`view=classic`、資料での別名`view=legacy`は同じ従来表示で、金色の光と旧表示を保ち、レーダーは出しません。操縦と飛ぶ力の計算は変えません。

記録は「この挑戦の合計」と「最後の1回」に分け、コピーには合計の`stats.legs`と別の`lastLeg`を追加します。「最初から飛び直す」で新しい1回に区切り、一時停止・持ち方合わせ直し・入力方式の切替では区切りません。合計の接地1回と、クリアした最後の1回の接地0回を区別できます。設定コピーには遊び方`mode`・見え方`view`も含め、探索や従来表示で使わない保存値は未使用として明記します。

v0.1.15資料では、fixedの自機が人から見て上向きに見え、遊びの感触がよくなったと1人分の実機報告がありました。bankは約259秒でクリア・合計接地1回・補助4.4秒、fixedは約190秒で接地・補助9.9秒という報告です。条件をそろえた比較や、表示方式の優劣の確定とは扱いません。画面の「標準／比較」ラベルを外し、未指定URLだけbankの初期値を互換維持します。新しいレーダーと光の実機での見やすさは未確認です。[指示資料](docs/instruction-v0115.md) と [検証記録](docs/verification-v0115.md) を参照してください。

## v0.1.14の固定表示

`display=bank`（未指定URLの初期値）は従来どおり機体が旋回側へ傾きます。`display=fixed`（比較）は自機を傾けず、地平線で翼の傾きを表します。どちらも開始画面・一時停止画面の「機体表示」で選べ、切替は位置・姿勢・速度や操縦を変えません。探索の表示は従来どおりです。

固定表示では、スマホの面内回転だけをカメラで打ち消します。自機と景色を同じ角度で描き直すため、文字・メーター・ボタンは回らず、画面の角に空白も作りません。前後・左右の端を倒す動きで模型を回さないため、模型が横を向いて細くなる補正を加えません。景色の傾きには実際の翼の全角度を使い、低空で地面を見る補助中も15度に縮めません。bank側の視点補助は継続します。

一時停止の「調整」に「固定表示の回転のならし」を追加しました。初期値0.05秒、範囲0〜0.3秒。0秒は即時で、大きいほど表示がゆっくり追いつきます。半回転をまたぐときは近い方向へ追いかけます。操縦入力はならしません。画面の縦横が切り替わる分は遅らせず別に補正し、合わせ直した中立の画面上向きを基準に保ちます。既存の調整値は保存を引き継ぎ、新項目だけ初期値を補います。

コピーには`display`と、結果がある場合に`result: clear|grounded`を追加。結果画面にも「クリア」「墜落」を表示します。rateで使わない`maxPitch`と`timeConstant`、bank表示では使わない`displayTimeConstant`は、`inactiveSettings`と画面の「未使用」で区別します。設定コピーは現在値（結果画面では結果種別も付加）、結果コピーは接地・クリア時点の値を保ちます。

提供資料では、v0.1.13の実機1人分としてangleは約240秒・墜落1回でクリア、飛び直し後は補助0秒・墜落0回、rateは約111秒・墜落3回・未クリアと報告されています。本人の感触と指示に沿ってangleを標準として継続します。比較条件が統一された試験としては扱いません。v0.1.15資料でfixedの上向き維持の実機報告がありました。新しいレーダー・光の見やすさは未確認です。[指示資料](docs/instruction-v0114.md) と [検証記録](docs/verification-v0114.md) を参照してください。

## v0.1.13の機首操作と調整

`pitch=angle`（未指定時の標準）は、スマホ上端の傾きが機首の目標角度です。初期値は中立範囲3度、スマホの傾き25度で機首15度。手前へ起こすと上、前へ倒すと下、中立へ戻すと機首も水平へ戻ります。機首は滑らかに追いつき、毎秒0.65radを超えて回りません。W/Sは押している間だけ最大目標、離すと水平へ戻ります。

`pitch=rate`は従来の回り続ける方式です。中立で機首角度を維持し、逆の入力で水平へ戻します。開始・一時停止画面で切り替えても、その場の位置と姿勢を保ち、勝手に動き出しません。旋回の`steer=tilt|twist`とは別に選べます。

一時停止画面の「調整」では、中立範囲0〜8度、最大傾き10〜30度、機首の最大角度5〜35度、追従時間0.1〜1秒、翼の最大角度5〜40度を変更できます。中立範囲と最大傾きは飛行機の前後・左右のひねりで共用。面内で回す旋回の入力幅は従来どおりです。機首の最大角度と追従時間は角度方式のみ、翼の最大角度は両旋回方式で使います。保存先は同じ端末・ブラウザーのlocalStorageで、方式はURLで指定します。「初期値に戻す」「設定をコピー」も利用できます。

クリア・接地画面には、飛行時間、接地回数、復帰補助の累積時間、到着・接地時点の方式と調整値を表示し、「記録をコピー」で1行のJSON文字列をコピーできます。一時停止・センサー待ちは時間に含めず、接地後の「最初から飛び直す」では累積します。「最初からやり直す」、クリア後の再挑戦、遊び方の変更、ページ再読込で新しい記録です。途中で設定・方式を変えた場合も時間は累積し、結果には到着・接地時点の設定を残します。結果は端末内のメモリーのみで、再読込後の記録は保存しません。

保存が使えない場合は初期値で開始し、その画面内で調整を続けられます。コピーが拒否された場合は手動で選択できる文字列を表示します。設定・記録を端末の外へ送る処理はありません。開始画面のカード上部にも「twist v0.1.13」を表示します。

センサーの許可・喪失時の停止は維持。資料中の再開条件についてはユーザーに確認し、現在の「停止中は速度・出力0、手動再開で出力50%・6m/s」を維持しました。飛行の物理計算と復帰補助はv0.1.12と同一です。[仕様の原文](docs/instruction-v0113.md) と [検証記録](docs/verification-v0113.md) を参照してください。実機の操作感は未確認です。

## 飛行機の入力を比べる

飛行機モードは、**スマホ本体の上端・右端**を入力の基準にします。本体上端は、画面の縦横が自動で変わっても動かない端末の物理的な上側です。上端を自分側へ起こすと機首上げ、前へ倒すと機首下げです。

v0.1.8では呼び方と標準を改めます。左右端を上下させる動きを「ひねる」、画面の面内で時計回り・反時計回りに動かすことを「回す」と呼びます。v0.1.7以前で「ひねる」と書いた面内回転は、現行では「回す」に当たります。

旋回は開始画面・一時停止画面で、次のどちらか一方を選びます。

- **ひねる（標準・おすすめ）**：本体の左右端を上下させます。右端を下げると右、左端を下げると左へ翼を傾けて旋回します。
- **回す（比較）**：画面の面内で、操縦輪のように時計回りなら右、反時計回りなら左へ翼を傾けて旋回します。

2つの旋回入力は同時に足しません。「ひねる・回すの違い」を開くと、左右端を上下させる動きと、面内で回す動きを図で確認できます。前後の機首操作と出力調整は両方で共通です。v0.1.11では飛行機だけ以前の向き固定から旋回方向へ傾く表示に変更します。探索は向き固定です。

## 見え方を比べる

v0.1.6で追加した次の3点は継続します。探索モードでも表示を比べられます。

- 縦持ちの視野を広げ、周囲を見渡しやすくする。
- ステージの4方向へ、色と形の異なる大きな目印を置く。
- 次の目標が画面外へ出たら、画面の端に矢印・目標名・上下や後ろ・距離を表示する。

開始画面または一時停止画面で「見失い対策」「従来」を選びます。見え方の切替そのものは位置・向きや飛行の計算を変えません。従来では追加の目印と画面端マークを隠し、v0.1.5の視野へ戻します。スマホ実機で見失いにくくなったかは未確認です。端末を傾けた際に自機が細く見える点も、今回で解決済みとは扱わず確認項目に残しています。

## 地面の近さを読む

v0.1.9では青灰色の床を茶色・黄土色へ変更し、空の水色と大きく区別します。地面だけは遠くで空色に薄める処理を使いません。濃い茶色の格子、明るいベージュの道、4m間隔の市松模様、真下の円形マークで距離と移動を示します。島の内外とも、「従来」「見失い対策」の両方へ適用します。

飛行機は低空・下降中に地面が見えるよう、表示を少し後ろ・上から見下ろす方向へ補助します。v0.1.11では表示の回転を毎秒30度、移動を毎秒3m以内に抑えます。補助中は「地面を見る補助中」と表示。機首の角度と画面の見る角度は別で、操縦や飛ぶ力の計算へ表示の補正値は入れません。

HUDには「地面まで」の実際の距離と、12mで満杯になるバーを表示します。12mを超えても距離の数値はそのままで、不明な値は「—」です。5m以下は橙、3.5m以下は赤で、画面の縁も点滅させず知らせます。下降中は今の速度が続くと仮定し、地表0mでの接地まで3秒以内なら橙、1.5秒以内なら赤でも知らせます。

v0.1.10では高さ2mで止める設定を廃止し、自機のゲーム内位置が地表0mに達したときに接地して停止します。地面への気づきやすさが実機で改善したかは未確認です。

## 2つの操作

飛行機はスマホ本体、探索は画面内に見えている自機の先端と左右を操作の目印にします。探索の「先端側」は端末本体の上辺に固定されません。

| 操作 | 飛行機モード | 探索モード |
| --- | --- | --- |
| 前後の傾き | 標準は傾きで目標角度を指定。比較用は上・下へ回り続ける | 自機の先端側を下げると加速、上げるとブレーキ |
| 左右端を上下させる（ひねる） | 「ひねる（標準）」選択時に、本体の下げた側へ翼を傾けて旋回 | 自機の下げた側へ曲がり続ける。停止中も見回せる |
| 画面下のスロットル | 出力0〜100%。指を離しても出力を保つ | 使用しない |
| 画面の面内で右・左へ回す | 「回す（比較）」選択時に、その側へ翼を傾けて旋回 | 右で上へ、左で下へ回り続ける |
| 中立へ戻す | 標準は機首と翼が水平へ戻る。比較用は機首角度を保つ。出力は保持 | 速さと進路を保つ |
| 加減速の中立範囲・最大角度 | 出力はスライダーで調整 | 前後各3度以内は中立、各12度で最大の強さ |
| 手動で開始・再開 | 出力50%・6m/sで前進を始める | 0m/sから始める |
| PCキー | W/Sで機首の上/下、A/Dで旋回、Q/Eで出力を弱く/強く | Wで加速、Sでブレーキ、A/Dで左右、Q/Eで下/上 |

飛行機モードでは、同じ出力でも機首を上げて登ると減速し、下げて降りると加速します。翼の傾きは最大40度。出力を絞ると速さと翼の支える力が減り、降下しやすくなります。出力0%でも勢いで滑空するため、すぐ止めるときは「一時停止」を使います。速度0で浮き続ける動きにはしません。

v0.1.12では、進行中の前後・上下・左右の勢いを保ち、姿勢を変えても移動方向を一瞬で機首へ置き換えません。失速時は機首の表示を0°付近へ、翼を水平へ戻し、出力を上げると低速用の前進力と復帰補助が働きます。落下の勢いは連続的に前進へ向き直り、速さが戻ると補助が弱まります。動作中は「失速からの復帰補助中」と表示します。v0.1.13の標準方式ではスマホの中立で機首も水平へ戻ります。比較用のrate方式では、前へ倒して機首を下げ、0°付近で中立にします。出力0%や機首が大きく上・下を向いたままでは補助しません。復帰にも高度が必要で、地面近くから必ず助かる仕様ではありません。

重力3m/s²、最高速度18m/sなど、操作感を試すための調整値を使っています。エンジンの推す力、空気抵抗、翼の支える力、重力を近似したゲーム向けの動きで、実際の航空機の性能は再現しません。

探索モードはv0.1.4の12度操作を継続します。12度は加速・ブレーキの**強さ**が最大になる角度で、すぐ最高速度になる意味ではありません。最高速度10m/s、最大加速3.5m/s²・最大制動6.5m/s²。中立では今の速さを保ち、反対側へ倒すと制動して0で止まります。後退はしません。

## スマホで試す

1. 公開URLをSafariまたはChromeで直接開き、「スマホの傾きで始める」を押します。
2. 動きと向きの利用を許可し、少しスマホを動かします。
3. 画面が見やすい持ち方に戻し、探索では「この持ち方で始める」、飛行機では「この持ち方で飛ぶ」を押します。
4. 飛行機は出力50%・6m/s、探索は停止から始まります。飛行機は画面下の出力スライダー、本体上端の前後、「ひねる」または「回す」を試し、探索は自機の先端・左右の傾きと面内で回す動きを試します。
5. 見失い対策では空中のピンクの光を順番に3つ集め、案内に従って青い出口へ進みます。青い六角の輪・点の道しるべ・高さ目盛は位置を把握する目印です。

持ち方を変えたいときは「持ち方を合わせ直す」で操作の中立を取り直します。Android/PCでは画面の縦横変更に対する従来の入力補正を保ちます。iPhoneではv0.1.19から向きが切り替わると一時停止します。センサー消失や画面を離れた場合は速度・出力0へ停止し、手動で再開します。探索では自機が真横に見えて先端を判別できない角度でも停止します。飛行機は再開ボタンから出力50%・6m/sへ戻り、自動で再開はしません。

飛行機は地面まで0mで接触して停止します。「最初から飛び直す」で出発地点から出力50%・6m/sで再出発します。

停止画面には接地直前の出力、機首、下降速度、前後の操作も残します。通常の旋回だけでは急落を再現できていないため、実機で再発した際の確認に使います。

画面下には入力角度・速度・高さ・地面までの距離・検証版番号を表示し、飛行機では出力・機首・翼の傾き・昇降速度も表示します。PCや「画面操作で試す」は疑似入力の練習で、スマホの操作感を確認したことにはなりません。

練習つまみは端末自身の上辺・右辺・回し角度を再現します。飛行機は本体基準で使い、探索はゲーム側で自機基準に読み替えます。「姿勢を戻す」は飛行機では出力、探索では速度を保ちます。飛行機の練習用「出力0%」も即停止ではありません。全て止めたい場合は「一時停止」を使います。スマホ実機での物理的な見え方・操作感は未確認で、[確認項目](docs/device-controls-v018.md) に残しています。

## ローカル起動

Node.js 24以上を使用します。

```sh
npm ci
npm run dev
```

センサーの利用にはHTTPSが必要です。PCのHTTP開発サーバーをスマホで開いただけでは、センサーを使えない場合があります。スマホ確認には公開URLを使用します。

```sh
npm test
npx playwright test tests/smoke.spec.js tests/flight.spec.js tests/visibility.spec.js tests/device-flight.spec.js tests/ground-proximity.spec.js
npx playwright test tests/flight-input.spec.js tests/flight-display.spec.js tests/radar.spec.js
npm run build
```

ブラウザー検証はWindowsでは既存のEdgeを使用します。CI環境で実行する場合は `npx playwright install --with-deps chromium` が必要です。
