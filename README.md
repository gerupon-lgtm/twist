# twist

自機を画面中央に保ち、周囲が動く中で空中の光を集める3D操作検証です。飛行機は右旋回なら右、左旋回なら左へ機体が傾き、スマホ本体の傾きと画面のエンジン出力で操縦します。探索ではスマホの回転を打ち消して最初の上向きを保ちます。

**操作検証 v0.1.12 / 2026-11-07**

公開先URL:

- [飛行機・ひねる（標準・おすすめ）](https://gerupon-lgtm.github.io/twist/?mode=flight&view=assisted&steer=tilt&v=0.1.12)
- [飛行機・回す（比較）](https://gerupon-lgtm.github.io/twist/?mode=flight&view=assisted&steer=twist&v=0.1.12)

`mode` の指定なしは探索、`view` の指定なしは見失い対策、飛行機の `steer` の指定なしは「ひねる（標準）」です。開始画面・一時停止画面の「遊び方」で飛行機・探索を切り替えると、速度・出力0でステージの最初へ戻ります。「見え方」は同じ位置・向きのまま切り替えて比較できます。[操作・地面表示](docs/device-controls-v018.md) と [公開版の検証記録](docs/verification-v018.md) を参照してください。

## 飛行機の入力を比べる

飛行機モードは、**スマホ本体の上端・右端**を入力の基準にします。本体上端は、画面の縦横が自動で変わっても動かない端末の物理的な上側です。上端を自分側へ起こすと機首上げ、前へ倒すと機首下げです。

v0.1.8では呼び方と標準を改めます。左右端を上下させる動きを「ひねる」、画面の面内で時計回り・反時計回りに動かすことを「回す」と呼びます。v0.1.7以前で「ひねる」と書いた面内回転は、現行では「回す」に当たります。

旋回は開始画面・一時停止画面で、次のどちらか一方を選びます。

- **ひねる（標準・おすすめ）**：本体の左右端を上下させます。右端を下げると右、左端を下げると左へ翼を傾けて旋回します。
- **回す（比較）**：画面の面内で、操縦輪のように時計回りなら右、反時計回りなら左へ翼を傾けて旋回します。

2つの旋回入力は同時に足しません。「ひねる・回すの違い」を開くと、左右端を上下させる動きと、面内で回す動きを図で確認できます。前後の機首操作と出力調整は両方で共通です。v0.1.11では飛行機だけ以前の向き固定から旋回方向へ傾く表示に変更します。探索は向き固定です。

## 見え方を比べる

v0.1.6で追加した次の3点は継続します。探索モードでも表示を比べられます。

- 縦持ちの視野を広げ、周囲を見渡しやすくする。
- ステージの4方向へ、色と形の異なる大きな目印を置く。
- 次の目標が画面外へ出たら、画面の端に矢印・目標名・上下や後ろ・距離を表示する。

開始画面または一時停止画面で「見失い対策」「従来」を選びます。見え方の切替そのものは位置・向きや飛行の計算を変えません。従来では追加の目印と画面端マークを隠し、v0.1.5の視野へ戻します。スマホ実機で見失いにくくなったかは未確認です。端末を傾けた際に自機が細く見える点も、今回で解決済みとは扱わず確認項目に残しています。

## 地面の近さを読む

v0.1.9では青灰色の床を茶色・黄土色へ変更し、空の水色と大きく区別します。地面だけは遠くで空色に薄める処理を使いません。濃い茶色の格子、明るいベージュの道、4m間隔の市松模様、真下の円形マークで距離と移動を示します。島の内外とも、「従来」「見失い対策」の両方へ適用します。

飛行機は低空・下降中に地面が見えるよう、表示を少し後ろ・上から見下ろす方向へ補助します。v0.1.11では表示の回転を毎秒30度、移動を毎秒3m以内に抑えます。補助中は「地面を見る補助中」と表示。機首の角度と画面の見る角度は別で、操縦や飛ぶ力の計算へ表示の補正値は入れません。

HUDには「地面まで」の実際の距離と、12mで満杯になるバーを表示します。12mを超えても距離の数値はそのままで、不明な値は「—」です。5m以下は橙、3.5m以下は赤で、画面の縁も点滅させず知らせます。下降中は今の速度が続くと仮定し、地表0mでの接地まで3秒以内なら橙、1.5秒以内なら赤でも知らせます。

v0.1.10では高さ2mで止める設定を廃止し、自機のゲーム内位置が地表0mに達したときに接地して停止します。地面への気づきやすさが実機で改善したかは未確認です。

## 2つの操作

飛行機はスマホ本体、探索は画面内に見えている自機の先端と左右を操作の目印にします。探索の「先端側」は端末本体の上辺に固定されません。

| 操作 | 飛行機モード | 探索モード |
| --- | --- | --- |
| 前後の傾き | 本体上端を起こすと機首が上へ、前へ倒すと下へ回り続ける | 自機の先端側を下げると加速、上げるとブレーキ |
| 左右端を上下させる（ひねる） | 「ひねる（標準）」選択時に、本体の下げた側へ翼を傾けて旋回 | 自機の下げた側へ曲がり続ける。停止中も見回せる |
| 画面下のスロットル | 出力0〜100%。指を離しても出力を保つ | 使用しない |
| 画面の面内で右・左へ回す | 「回す（比較）」選択時に、その側へ翼を傾けて旋回 | 右で上へ、左で下へ回り続ける |
| 中立へ戻す | 機首の向きと出力を保ち、翼は滑らかに戻る。速さは飛び方で変わる | 速さと進路を保つ |
| 加減速の中立範囲・最大角度 | 出力はスライダーで調整 | 前後各3度以内は中立、各12度で最大の強さ |
| 手動で開始・再開 | 出力50%・6m/sで前進を始める | 0m/sから始める |
| PCキー | W/Sで機首の上/下、A/Dで旋回、Q/Eで出力を弱く/強く | Wで加速、Sでブレーキ、A/Dで左右、Q/Eで下/上 |

飛行機モードでは、同じ出力でも機首を上げて登ると減速し、下げて降りると加速します。翼の傾きは最大40度。出力を絞ると速さと翼の支える力が減り、降下しやすくなります。出力0%でも勢いで滑空するため、すぐ止めるときは「一時停止」を使います。速度0で浮き続ける動きにはしません。

v0.1.12では、進行中の前後・上下・左右の勢いを保ち、姿勢を変えても移動方向を一瞬で機首へ置き換えません。失速時は機首の表示を0°付近へ、翼を水平へ戻し、出力を上げると低速用の前進力と復帰補助が働きます。落下の勢いは連続的に前進へ向き直り、速さが戻ると補助が弱まります。動作中は「失速からの復帰補助中」と表示します。スマホの前後を中立へ戻すだけでは機首角度は変わらないため、前へ倒して機首を下げ、0°付近で中立にします。出力0%や機首が大きく上・下を向いたままでは補助しません。復帰にも高度が必要で、地面近くから必ず助かる仕様ではありません。

重力3m/s²、最高速度18m/sなど、操作感を試すための調整値を使っています。エンジンの推す力、空気抵抗、翼の支える力、重力を近似したゲーム向けの動きで、実際の航空機の性能は再現しません。

探索モードはv0.1.4の12度操作を継続します。12度は加速・ブレーキの**強さ**が最大になる角度で、すぐ最高速度になる意味ではありません。最高速度10m/s、最大加速3.5m/s²・最大制動6.5m/s²。中立では今の速さを保ち、反対側へ倒すと制動して0で止まります。後退はしません。

## スマホで試す

1. 公開URLをSafariまたはChromeで直接開き、「スマホの傾きで始める」を押します。
2. 動きと向きの利用を許可し、少しスマホを動かします。
3. 画面が見やすい持ち方に戻し、探索では「この持ち方で始める」、飛行機では「この持ち方で飛ぶ」を押します。
4. 飛行機は出力50%・6m/s、探索は停止から始まります。飛行機は画面下の出力スライダー、本体上端の前後、「ひねる」または「回す」を試し、探索は自機の先端・左右の傾きと面内で回す動きを試します。
5. 空中の金色の光を順番に3つ集め、案内に従って青い出口へ進みます。青い六角の輪・点の道しるべ・高さ目盛は位置を把握する目印です。

持ち方を変えたいときは「持ち方を合わせ直す」で操作の中立を取り直します。通常の画面の縦横変更では操作基準と速度を維持します。センサー消失や画面を離れた場合は速度・出力0へ停止し、手動で再開します。探索では自機が真横に見えて先端を判別できない角度でも停止します。飛行機は再開ボタンから出力50%・6m/sへ戻り、自動で再開はしません。

飛行機は地面まで0mで接触して停止します。「最初から飛び直す」で出発地点から出力50%・6m/sで再出発します。

停止画面には接地直前の出力、機首、下降速度、前後の操作も残します。通常の旋回だけでは急落を再現できていないため、実機で再発した際の確認に使います。

画面下には入力角度・速度・高さ・地面までの距離・検証版番号を表示し、飛行機では出力・機首・翼の傾き・昇降速度も表示します。PCや「画面操作で試す」は疑似入力の練習で、スマホの操作感を確認したことにはなりません。

練習つまみは端末自身の上辺・右辺・回し角度を再現します。飛行機は本体基準で使い、探索はゲーム側で自機基準に読み替えます。「姿勢を戻す」は飛行機では出力、探索では速度を保ちます。飛行機の練習用「出力0%」も即停止ではありません。全て止めたい場合は「一時停止」を使います。スマホ実機での物理的な見え方・操作感は未確認で、[確認項目](docs/device-controls-v018.md) に残しています。

## ローカル起動

Node.js 24以上を使用します。

```sh
npm ci
npm run dev
```

センサーの利用にはHTTPSが必要です。PCのHTTP開発サーバーをスマホで開いただけでは、センサーを使えない場合があります。スマホ確認には公開URLを使用します。

```sh
npm test
npx playwright test
npm run build
```

ブラウザー検証はWindowsでは既存のEdgeを使用します。CI環境で実行する場合は `npx playwright install --with-deps chromium` が必要です。
