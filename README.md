# twist

自機は画面中央に保ち、スマホの回転を打ち消して最初の上向きを保つ3D探索の操作検証です。見えている自機の先端側を下げて加速、逆側でブレーキ。周囲が動く中で、空中の光を集めます。

**操作検証 v0.1.2 / 2026-11-07**

公開URL: https://gerupon-lgtm.github.io/twist/?v=0.1.2

## スマホで試す

1. 公開URLをSafariまたはChromeで直接開き、「スマホの傾きで始める」を押します。
2. 動きと向きの利用を許可し、少しスマホを動かします。
3. 画面が見やすい持ち方に戻し、「この持ち方で始める」を押します。
4. 自機の先端が見えている側を下げると加速、逆側を下げるとブレーキです。自機が画面の左を向いていれば、端末の左側を下げて加速します。傾きを中立へ戻すと速さを保ち、制動で停止して後退はしません。
5. 自機の右側を下げて右へ、左側を下げて左へ曲がります。小さく右へひねると上へ、左へひねると下へ曲がり続けます。大きく回した場合も上下旋回が急反転せず、半回転・一回転付近で中立へ戻ります。
6. 空中の金色の光を順番に3つ集め、案内に従って青い出口へ進みます。青い六角の輪・点の道しるべ・高さ目盛は位置を把握する目印です。

持ち方を変えたいときは「持ち方を合わせ直す」。自機の上向きは保ったまま、操作の中立だけを取り直します。通常の画面の縦横変更では操作基準と速度を維持します。センサー消失、画面を離れた場合、自機が真横に見えて先端を判別できない角度では停止し、持ち直して再開します。

画面下には入力角度・前進速度・高さ・検証版番号を表示します。PCや「画面操作で試す」は疑似入力の練習で、スマホの操作感を確認したことにはなりません。

PCのキーはWで加速、Sでブレーキ、A/Dで左右、Q/Eで下/上です。練習つまみは端末自身の上辺・右辺・回し角度を再現し、ゲーム側で自機基準に読み替えます。「姿勢を戻す」でも速度は維持します。すぐに全て止めたい場合は「一時停止」を使います。

## ローカル起動

Node.js 24以上を使用します。

```sh
npm ci
npm run dev
```

センサーの利用にはHTTPSが必要です。PCのHTTP開発サーバーをスマホで開いただけでは、センサーを使えない場合があります。スマホ確認には公開URLを使用します。

```sh
npm test
npx playwright test
npm run build
```

ブラウザー検証はWindowsでは既存のEdgeを使用します。CI環境で実行する場合は `npx playwright install --with-deps chromium` が必要です。
