# v0.1.39 初回BGMの読み込み待ち

2026-11-09。公開・配信確認済み。アプリe53fce4の[Actions](https://github.com/gerupon-lgtm/twist/actions/runs/42533301468)は全12ステップ成功。単体111/791、PWA13、配信版/公開先の初回SCC/FMと、公開350ファイル/21項目・旧保存版11個等を確認した。修正版の実機確認は未了。

利用者から「ページを開いて最初の飛行・SCCで、BGMが鳴り始めるまで長く待った」と報告を受けた。前版は開始前に全16曲を順番に読み、再生時もその全体の完了を待っていた。選択外の1曲を止めると、開始音が終わっても選択曲を再生できないことを単体・実ブラウザーで再現した。利用者の実際の通信ログはなく、端末で起きた原因すべてを断定するものではない。

曲ごとに読み込み中の処理と完了した譜面を共有する。再生時は選択曲だけを待ち、他の曲の完了を待たない。開始前は選択曲・選択したクリア曲・AB追加音だけを準備し、再挑戦では既存の譜面を再利用する。音楽の一覧は未読み込み曲も表示する。選択曲の取得に失敗した場合の代替曲、許可の変更や停止による取消は保持する。

ABの音が遅れて届いたときは、同じ再生の所有権を確認して現在のBGMの拍へ合流する。停止・曲変更後の古い読み込みは音を再開しない。全曲を明示的に準備するAPIも残すが、同時2件に制限し、通常の開始では使わない。

GO音の約1.5秒と、その終了後にBGMへ移る条件は変更しない。MIDI・音色・音声処理・飛行・コース・振動は保護する。本編コース説明の反映、戦闘機風の機体、シエラ1/10・亜音速の受領資料は後続に保持し、今回の修正へ混ぜない。

版・画面・HTML/PWA/ガイドのキャッシュ識別をv39へ更新する。独立した画面見本も生成器で現在の版を使い、今後のbuildから自動生成する。見本の配置・動き・機体の形は変更しない。公開済みv38の33原本を照合して保存版へ残す。

検証と実機の未確認項目は[検証記録](verification-v0139.md)へ分ける。
