# v0.1.62 変更内容

Overdrive HorizonとIgnition Skyの指定フレーズを原譜の感じへ戻し、IgnitionのFMリードをOverdriveと同じシンセ音色へ合わせる。

- Overdrive Track 1の44〜45・48・52小節にあった追加の装飾音9音を取り除く。その小節にかかる元の音の長さも原譜へ戻し、休符を保つ。
- Ignition Track 1の42小節には追加音は見つからなかった。直前から続くE音に加えていた約0.104拍の延長を取り除き、音の切れ目を原譜へ戻す。この延長だけが聴感上の違和感の原因だとは断定しない。
- 伸ばす音のビブラートは維持。Ignitionの承認済み18小節目、Overdriveの承認済み68小節目、それ以外のリードの演奏、伴奏・ドラム・テンポは保つ。
- IgnitionのFMリードを`minimoog-lead`へ変更し、Overdriveと同じプリセット・基準音量99を使う。既存の音域と他パートの音量は維持する。OverdriveだけのFMリードの1オクターブ下げも維持し、Ignitionへは適用しない。
- 音符と休符の修正は共通MIDIのためSCC/FM両方へ反映。音色変更はFMリードだけで、SCCの音色・波形・音量設定は維持する。
- 再生成用の譜面計画へ修正を反映。68小節目の専用処理は、確認済みの旧データと今回の生成データのハッシュを照合し、未確認の編集と保存版の保護を保つ。

画面の版表示とキャッシュ番号を0.1.62へ更新し、公開済み0.1.61の本編33ファイルを同じバイトのまま保存する。
