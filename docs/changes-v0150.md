# v0.1.50 変更内容

HUDの左右の大きさと高さがそろっておらず、視点によって配置も変わっていたため、全3視点で共通の配置を選べるようにした。

- A：左右対称の縦型。左に速度とマッハ/G、右に高度と昇降速度。
- B：下部に横一列。速度・マッハ/G・高度・昇降速度を一つの帯にまとめる。通常コースではマッハ/Gを表示しない。
- C：円形ミニ計器。左右に同じ大きさの速度・高度計、その下に補助値。

設定の先頭付近に「HUDの配置」を追加し、一時停止中に変更できるようにした。最初はA。保存済みの操縦や単位の設定を引き継ぎ、配置だけ変更・戻すこともできる。

最初の依頼では背景を完全透明にする想定だったが、後の指定により、約22%の濃さの暗い青緑の面と細い枠に変更した。数値に縁取りを付け、目標高度などの小さな補足表示は約18%の面を使う。地面に近い高度と緊急の目標高度は明るい警告色で区別する。

速度・高度・昇降の表示は一つにまとめ、外から・追尾3D・操縦席で重複させない。方位や中央の実進路、案内の輪は各視点に適した表示を保つ。追尾3Dで実進路が高い位置に来ることを考慮し、計器をその進路へ重ねない。レーダーと計器の位置が互いに押し合って動くことも避ける。

小さい縦画面と横画面では、実際の操作パネル・レーダー・視点ボタン・操縦席の下側の案内枠を測って配置する。補助の目盛りだけを省く場合があるが、現在の数値や必要な操作は残す。長い数値は字体と表示幅に合わせて文字の大きさを調整し、符号・小数・桁を省かない。

飛行や入力の条件、コース、記録、音は変更しない。画面の版とキャッシュ更新番号を0.1.50に変更し、公開確認済みの0.1.49本編33ファイルを保存版に追加する。

新配置は通常の開始画面を使う製品画面が対象。古い開発検証用の画面（`dev=1&flow=legacy`）は既存の検証条件を保つ。探索の開発画面でもA/B/Cの速度と高さを使用できる。
