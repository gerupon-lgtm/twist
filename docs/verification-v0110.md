# v0.1.10 地面を見る補助と接地停止

2026-11-07。上向きのまま下降すると空ばかりが映り、2m手前で停止する問題に対する更新。ユーザーから下降中/低空でも地面を見せ、実際の接地で止めるよう依頼された。

## 変更した前提と実装

- これまで同一だった機体の向きと表示の向きを分ける。低空/下降時は少し後方・上方から見下ろす。物理計算に使う機首/翼の角度へ表示の補正を逆流させない。
- 高さ12m以上の非下降では従来の向き。5〜12mで滑らかに補助が増え、5m以下で全面的に地面を見る。下降速度0.1〜0.8m/sでも滑らかに補助を増す。
- 補助時は低空で12〜18度下向き、下降中の上空では最大35度下向き。表示上の左右傾斜は最大15度へ寄せ、後方最大6m・上方最大1.8mの表示位置を使う。画面上の自機中心と描画カメラ位置は固定し、世界の表示変換を変える。
- 補助用の方角は低速から連続して実移動の方角へ寄せる。機首が垂直を通過しても表示方角を突然反転させない。
- 目標の距離は機体位置から測り、画面の矢印/投影は補助後の表示位置・向きで計算する。「従来」「見失い対策」の両方で地面を見る補助を使う。
- 飛行機は高さ2mで止めず、下降中に自機のゲーム内位置が地表基準0mへ到達したとき停止する。1フレームで地表を跨いでも、移動区間と地表の交点へ位置を合わせる。探索の移動計算とは分けている。
- 接地直前の移動方向を表示用に保持し、停止で速度をゼロにした直後に視点が跳ねないようにする。接地と同じフレームでHUDを更新し、停止なのに距離が直前の値を示す遅れを解消。
- 接地時間の予測も2mから0mまでへ変更。「地面に接触して停止」「地面まで0m」の説明に更新。自動再出発は行わず、手動で最初から飛び直す。
- 画面・favicon・設定URL・package版を0.1.10へ更新し、内容別のJS/CSSファイル名でキャッシュを更新。
