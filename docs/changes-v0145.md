# v0.1.45 改修範囲

この会話の依頼と最新の補足を実装の根拠とする。v0.1.44（c0bfcf04b620730775e6d5f5485e8598ad9af81e）を比較元とする。

- 音速を上抜けする爆発音を強める。二段の衝撃、低・中音の余韻を追加し、鳴っている間は背景音を短く下げる。音割れ防止は直流成分の除去と音量適用の後に行う。爆発時以外のSCC混合処理を変えない。ミュート・停止・警告・取得音の優先とイベントの一度限りの消費を維持する。
- 操縦席で太い二重の圧力波と周囲の柔らかい霧を表示する。照準の中央を残す。動きを減らす設定では二つ目の動く輪を止め、霧を弱くする。機体やカメラの操縦・揺れを増やさない。既存の追尾視点の炎と衝撃波を維持する。
- 高速空域で門の中心から少しずれていても実際の開口を通れる進路なら、直前に旋回し直す案内を出さない。実際の門の半径・取得判定・飛行挙動は変更しない。本当に外す場合の旋回し直す案内を保つ。シエラ1/10の共有案内にも適用する。
- Ignition Skyの6小節目終わりと42小節目終わり〜43小節目に以前追加した3音フレーズだけを除去し、休符を戻す。
- 最新の補足により、18小節目の以前の「一音を切らずC#→E」は変更する。利用者のSMFサンプルの当該箇所に合わせ、C#5を下からすくい上げて揺らし、短く切り、D#5を再発音して半音上のE5へチョーキングして揺らす。他の小節・伴奏をサンプルから採用しない。参照ファイルSHA-256は93605ec1571b985764ac4afbf5faf0a58258d085063c6b998aef6528b5c900c9。製品音源のピッチ変化の幅は±2半音のまま、参考資料の±12半音で記された曲げ方を音程へ換算する。
- FMでOverdrive Horizonの16分音符（第2パート）を専用の短い音色とFM限定の音量で目立たせる。SCCの音量・音符は維持する。
- FMのディストーションギターをさらに歪ませ、少し異なる音程の二つの発音を混ぜて厚くする。ドラム以外をFMで鳴らす既存割当を保つ。
- 表示版番号とキャッシュ更新を0.1.45へそろえ、検証後に公開する。
- 追加指定：タイトルの設定・遊び方を、同じ大きさの枠付きボタンと小さなアイコンで目立たせる。配色は空色・青緑・濃い青を維持し、既存の日本語書体を使う。ほかの戻る・設定・試聴・一時停止・選択ボタンにも同じ面色と輪郭、押した反応を適用する。主操作は青緑の塗り、補助操作は明るい面、選択中は濃い枠とする。操作の意味・配置は保つ。タイトルの2ボタンだけを横に等分し、縦横でスクロールが出ないよう確認する。

検証では単体、全曲の実AudioWorklet、実際の門通過と外した後の復帰、操縦席のGPU描画、SCC/FMの最大音量合成、PWAと公開配信を分けて記録する。実機の音色・迫力の評価を自動試験で済んだとは扱わない。
