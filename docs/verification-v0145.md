Pixel 9aで確認してほしい点：

- 高速空域で音速突破の爆発が十分に強く、BGM・エンジン音と重なっても耳障りな音割れがない。
- 操縦席で二重の輪と周囲の霧がはっきり見え、中央の照準と目標を見失わない。
- 高速空域の直線で、門の中心から少しずれた通過でもディレクターが急に横を向かない。本当に門を外した場合は戻れる。
- シエラ1/10でも目標通過前後の案内が自然。通常コースの案内・旋回感は従来通り。
- Ignition Skyの6小節目と42〜43小節目の余計な音がなく、18小節目がサンプルに近いチョーキングの雰囲気になっている。SCC・FMをそれぞれ確認する。
- FMのOverdrive Horizonで細かく連続する音型が聴き取れる。ギターの歪み・厚さと伴奏の釣り合いを確認する。

これらの実機での感触は未確認。ブラウザの計算・描画と区別する。
