# v0.1.21 操縦席の見やすさ（追加資料B）

[指示資料](instruction-next.md)のBを実装。PWAはv0.1.19、ハードBGMはv0.1.20で公開確認済み。操縦、速度/高度の物理、復帰補助、地面だけの接地判定、振動、光の色は変更しない。

## 実装

- cockpitの飛行中だけ、上のブランド/版番号/目標/計測を小さく1行に配置。下は半透明にし、出力の数字は下だけへ集約する。停止/合わせ直しボタンは高さ42px。横持ちは下の1本の帯にする。overlay/chaseの位置と寸法は、公開v0.1.20の6配置をfixtureに保存して比較する。
- 角度線は機首の前後10度だけを5度刻みで表示し、各側2〜7度の短い線と小さな端ラベルへ。水平より下の破線は細く薄くする。調整範囲は前後5〜30度。垂直を越える姿勢では、水平に対する実際の仰角へ折り返す。水平線と投影計算は世界と共通。
- 高度の横に符号付きの昇降バーを追加。±0.15m/s未満は中立、5m/sで最大46/100の長さ。進行方向の印は半径10px・翼幅42pxとし、機首から離れると太くする。画面外の印とラダーは、目標マーク/練習パネルを避けて切り抜く。
- 上下の視野は「自動計算」が初期値で、従来の計算を変えない。自動を外すと60度から現在の算出値まで調整でき、縦横で上限を計算し直す。保存上の0は自動を意味する。cockpit以外では視野とラダー設定を未使用として表示/コピーする。
- バリオは上昇0.3m/s以上で480+95×速度Hz（8m/sで上限）、間隔720−75×速度ms（150ms下限）。下降−2m/s以下は170〜90Hzを1150/1500ms鳴らす。中間は鳴らさない。ゲーム用の音で、航空計器の校正値ではない。効果音専用PSGの3番を使い、警告と取得/接地/ゴールを常に優先。初期オンで音/効果音の設定に従い、個別オフも保存する。ほかの飛行視点でも使用する。振動のパターンとBGM用のSCC/PSGは変えない。
- assistedに12方向の浮島と形の違う遺跡、中央付近(-36,-18)の高さ116mの塔、太陽1つ、12か所の高度の違う雲を追加。8つの描画まとまりにし、動的生成を毎フレーム行わない。追加物はfog=false、空へ寄せた色で遠さを示す。assistedだけカメラの遠方描画を1800mまで伸ばし、legacy/classicは250mのまま。既存の4方の目印/光/レーダーの描き方・投影は保持。レーダーの配置では操縦席で見えない案内を障害物に数えず、端末の切欠きの余白を避ける。
- 塔/雲/遠景に接触処理は追加しない。世界と一緒に動くため、近い雲と遠い島の動きの差が高さ/移動の手がかりになる。legacyでは追加一式を隠す。

## 確認

単体6件を追加し成功。ラダーの範囲/反転/無効値、バーの中立と上下/上限、バリオの境界/高さ/間隔/無効値/優先順位、新設定の既存保存互換、遠景の霧なし/8まとまり/衝突なしを確認。影響する既存単体と合わせ97件/4ファイルで成功、終了コード0。

ブラウザー・レビュー・負荷比較・公開確認は完了後に追記する。最初のブラウザーでは横持ち時に方位表示が右側へはみ出す問題と、上の目標/計測が重なる問題を検出。レーダーが左右どちらにある場合も実際に重なるときだけ方位表示を移し、計測の余白を確保して再確認する。

## 負荷比較の条件

資料中の描画平均約2.5ms/最大約22msは提供記録。今回のPC参考値はWindows Edge headless/SwiftShader/390×844、assisted/cockpit/50%直進。2秒の準備後に挑戦をリセットし、境界へ到達する前の16秒を同じ条件で測る。前のv0.1.20はframeCpu平均2.6340ms/最大14.50ms。後は公開v0.1.21で追記する。実GPU全体の負荷や実端末の性能を代用しない。

## Pixel 9aの確認手順（未確認）

1. 公開URLをcamera=cockpit&v=0.1.21で開き、版番号を確認。縦/横で、上の1行・出力・停止/合わせ直し・レーダー・昇降バーが読め、重ならないか確認する。
2. 機首を上げ/下げ、角度線が前後だけに残ること、棒と進行方向の印で上昇下降が分かるか試す。調整で線の範囲5/10/30度と視野の自動/60度/中間を比較する。操縦の効きは変わらないことも確かめる。
3. 構造物のない方向へ向けて旋回し、遠い浮島/遺跡・塔・太陽が方角の手がかりになるか確認。高さの違う雲を通過し、速度や昇降の分かりやすさを試す。legacyで追加一式が消えるか比較する。追加の物に当たっても接地扱いにならないことも確認する。
4. バリオが上昇時に高く速く、速い下降で低く長く鳴るか、警告音を邪魔しないか、BGMとの音量の釣り合いを確認。オフ→再読込後もオフか確認する。
5. 同じような飛行でframeCpuの平均/最大と音源負荷をコピーし、旧記録と比較する。見やすさ/方向感覚/聞こえ方/実機の負荷は未確認のまま残す。iPhone XRでも画面の安全領域と音を確認する。
