# twist v0.1.3 飛行機モード

2026-11-07。ユーザーが提案した操作を試すための、切替可能な飛行機風モード。現行の探索モードと同じステージで比べる。

## ユーザーが選んだ方向

- 前後の傾きは機首の上下、左右の傾きは翼を傾けた旋回、ひねりは加減速にする提案を試す。
- 自機の位置を固定し、景色・地平線を逆に動かすテーマを継続。
- 触りやすくなった探索モードを残し、別の飛行機モードとして比較できるようにする。
- 実装・検証・GitHub Pages更新まで前の依頼に続けて行う。

## 今回の実装判断

- `?mode=flight&v=0.1.3` で飛行機を選択済みにする。指定なしは探索。開始画面/一時停止画面で切替でき、切替時は速度0・ステージを最初からにする。
- 自機の見えている先端側を持ち上げると機首を上へ、下げると下へ。傾けている間は機首が回り続ける、という元の操作感を継続する。中立では現在の機首角度を保つ。
- 自機の右側/左側を下げると、翼をその側へ傾けて旋回。翼の傾きは最大40度、入力を戻すと滑らかに中立へ戻る。追加の傾きは背景の地平線へ反映する。
- 時計回りの小さなひねりで加速、逆で減速、中立で速度維持。半回転付近の折返しは探索と同じく急反転を避ける。制動で0になっても後退しない。
- 飛行機モードは明示した開始/再開ボタンから6m/sで前進を始める。画面の非表示・センサー消失・一時停止では即0、勝手に再開しない。探索モードの開始/再開は従来どおり0。
- 停止して見回せるゲーム向けの飛行機風操作で、失速・揚力・風・エンジンの詳細な飛行力学は実装しない。既存の空中目的物と範囲は維持する。
- 自機基準の入力・画面の縦横補正・持ち直し時の物理上向き保持を両モードで使う。

## 内部の取り決め

`flightRates(angles,sensitivity=1)` -> `{pitchRate,bankAngle,acceleration,brake}`。正pitchで機首上、正steerで右へのbankAngle、正twistで加速。rad/s・rad・m/s²、最大pitchRate .65、bankAngle 40度、加速3.5、制動6.5。
`createStage(canvas).update(dt,{mode='explore',pitchRate,yawRate,bankAngle,speed,craftQuaternion})`。探索は今の挙動。飛行機はbankAngleへ緩やかに追従し、右bankで右、左bankで左の旋回を生成。速度0ではbankによる旋回なし。描画は飛行の基準姿勢にbankを重ね、前進は基準姿勢の前方向、カメラ・自機中心は固定する。
`getStatus()` に `bank`（rad）と `yawRate`（rad/s）、`mode` を追加し、実際の姿勢・旋回の確認に使う。resetはbank/yawとも0へ。

## 確認すること

探索の既存15画面項目・30計算項目を継続。飛行機の前後/左右/ひねり単独・同時入力、翼の追従/戻り、bankの左右と旋回方向、速度0、姿勢一周、上下差のある目標と出口、モード切替、許可・再中立・安全停止、スマホ寸法、公開URLを確認。実機での見え方・感触は疑似入力の結果と分けて残す。
