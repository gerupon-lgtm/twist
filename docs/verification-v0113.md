# v0.1.13 角度方式・調整・飛行記録

2026-11-07。依頼元は [ユーザー提供資料](instruction-v0113.md)。追加依頼は開始画面で版番号を明瞭にすること。

## 実装判断

- `pitch=angle`を標準、`rate`を比較用として残す。角度方式は中立3度、25度入力で機首±15度、追従時間0.3秒、回転上限0.65rad/s。1フレームの追従量は指数関数で求め、目標を行き過ぎず時間刻みによる違いを抑える。ステージの従来の回転入力へ渡すため、飛行物理のコードは変更しない。
- 回転を繰り返した比較方式からの切替にも備え、表示用の上下±90度の角度とは別に、前後回転の角度±180度をステージから読む。姿勢を瞬間的にリセットせず最短方向へ水平に戻す。
- 設定は5項目。中立0〜8度、最大入力10〜30度、機首最大5〜35度、追従0.1〜1.0秒、翼最大5〜40度。翼の範囲は既存の40度上限を維持するために選んだ。前後と左右ひねりで入力幅を共用、面内回転の入力幅は変更せず翼の上限だけ調整する。探索には適用しない。
- 開始・一時停止画面の機首方式切替は、旋回方式と同様、位置と姿勢を維持し自動再開しない。PCのW/Sは角度方式で最大目標、離すと0度。
- localStorageに保存するのは調整値だけ。方式はURL、結果は画面を開いている間のメモリーで保持。保存が拒否された場合は初期値から始め、その場での調整は可能。自動コピーが使えない場合は選択できる文字列を出す。
- 飛行時間はステージが進んだ時間だけ。休止・待機は除く。復帰補助は画面の補助表示と同じ強さ0.05超の時間を累積。接地回数は接地した時に1回。接地後の主ボタン「最初から飛び直す」では累積し、「最初からやり直す」、クリア後の再挑戦、遊び方変更、再読込では新しい挑戦にする。
- 設定・方式を途中で変えても累積時間は継続する。結果の設定は到着・接地時点のスナップショットと明記し、結果表示後の調整で過去のコピー内容を書き換えない。
- 資料の再開時0の記述と現状の違いを質問し、ユーザー回答「現在の再開動作を維持」を採用。停止時に速度・出力0、手動で再開すると出力50%・6m/s。センサー許可・停止条件は継続。
- 開始・休止・結果のカード内に `twist v0.1.13` を読みやすく表示。ゲーム中のヘッダー表示も維持。favicon、設定URL、packageを更新し、ビルド資産は内容ハッシュで更新。

新しい角度入力の中立復帰、W/S、方式切替、設定保存と初期化、保存/コピー拒否時の継続、接地回数・休止除外・復帰補助時間、角度方式で全目標と出口への到達を初期確認済み。最終の全テストと公開版確認は進行中。
