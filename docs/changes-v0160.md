# v0.1.60 変更内容

後方・操縦席の上部にある方位・高度表示の枠と文字を大きくする。

- 共通の枠幅を180pxから最大300pxへ拡大。狭い画面と画面端の安全余白に収まる幅を使い、左右の中央揃えを保つ。
- 方位の枠は高さ28→36px、文字10→12px。操縦席の中央の方位は13→16px。
- 高度の枠は高さ32→48px。現在高度14→18px、目標高度と差・案内10→12px。行の間にも余白を加える。
- レーダーの大きさは100×100pxを保ち、広げた高度枠の下へ配置する。操縦席の目盛りを描く範囲も新しい枠の下へ合わせる。
- 常時出ないゲートオープン表示の枠180×24pxと文字サイズは維持し、高度枠の下に追随させる。
- 小さい縦画面では下部中央の状態表示を左右の計器の間に収まる幅にし、画面操作パネルを開いた場合も計器と重ならないようにする。

前版の左右の計器の白い下地50%、操縦と音楽は維持する。画面の版表示・キャッシュ番号を0.1.60へ更新し、公開済み0.1.59の本編33ファイルをそのまま保存する。
