# v0.1.54 変更内容

押下音の立ち上がりと、後方・操縦席の上部高度案内を調整する。

- 後方・操縦席の上部を、同じ「現在高度・目標高度・高度差と案内」に統一する。現在高度を右側へ見に行かなくても、上部で目標との差を把握できるようにする。
- 上部の2行の並び・文字の大きさ・字体・枠を共通化。32pxの高さ、方位と同じ中心、100×100のレーダー、A/B/Cの配置を保つ。数値と取得可能な範囲の計算は従来の共通処理を使う。

- 約70msの音全体に左右対称の音量曲線を付けていたため、最大音量まで約35msかかっていた。2msで滑らかに立ち上げ、その後は緩やかに減衰する曲線へ変更する。
- 44.1kHz・48kHzで、最大値の80%へ初めて到達する時刻は約24.8msから約1.5ms、実際の波形の最大値は約34.6msから約3.8msになった。
- PSGの520Hzの音、900Hzで丸める処理、最大値0.09、約70msの長さ、末尾を無音へ戻す処理を維持。BGM・警告音・FM/PSG/SCCの音量や楽曲データは変更しない。
- 再生タイミング・連続押下・消音・試聴・カウントダウンに関するv0.1.53の処理を維持する。ブラウザーや端末の再開にかかる時間を、波形の改善と混同しない。

画面に表示する版とキャッシュ更新番号を0.1.54へ更新。公開確認済み0.1.53の本編33ファイルを、同じバイトのまま保存版へ追加。
