## v0.1.30：開始前地図と開始導線（実装中・未公開）

- 追加指定に従い、飛行機の3視点でスロットルの位置・幅・見た目を操縦席視点へ統一する。細い表示の周囲は44px以上のドラッグ領域を確保する。角度の調整と詳細値は設定へ置き、明示的に選んだ画面操縦の入力欄だけを練習中のプレイ画面へ残す。
- 開始待ち中の画面離脱では、古い予約を取り消し、タイトルのボタンも押せる状態へ戻す。許可待ちから設定を開くときも、その待機を取り消す。古い許可が届いても、設定画面や次の許可待ちを上書きさせない。
- 初回にセンサーの許可が必要で、ボタンを押す瞬間の有効なデータがない場合は、許可後に最初に届いた新しい3方向の傾きを中立にする。許可前の姿勢を取得できたとは扱わず、古い傾きを流用しない。既に許可済みでも古いデータしかない場合は、新しい値を待ってからカウントダウンへ進む。
- 次の挑戦は開始記録を分ける。`entrySource`はtitle／course／retry、`entryAt`と`entryToFlightSeconds`はその入口からの時間。実際にタイトルを押していない挑戦の`titleAt`と`titleToFlightSeconds`はnullとし、タイトルから出たような時刻を作らない。全画面の時点は実際の要求結果を保持する。

v29の公開確認を完了してから着手した。以下は指示の範囲で決めた実装上の前提で、最終統合の合格やPixel 9aの受入を意味しない。[実装資料](implementation-v0130.md)と[検証記録](verification-v0130.md)へ根拠と残りをまとめる。

- 地図はコース決定後、持ち方を合わせる前へ挟む。地図を読む間に持ち方が変わっても、直後の中立合わせで出発できるため。閉じても即座に飛ばず、構える→カウントダウンへ進む。地図・説明・待機・カウントダウンは既存の飛行時計に含めず、最初のフレームへも待機時間を持ち込まない。
- 順路の描画は3.6秒。終わっても表示を続け、タップ／SKIPで直ちに閉じる。動きを減らす設定では完成図を最初から表示する。高さの文字は全点分を常時表示する一覧へ分け、狭い地図での重なりを避ける。無音・無振動を維持する。
- 一時停止の地図も開始方向を上に固定し、現在の自機の記号だけを実際の向きへ回す。境界外の現在位置も全体の縮尺へ含め、レーダーの端へ寄せる方式を流用しない。閉じた先は一時停止で、自動再開しない。
- 地図の初回は「その配置の地図を開いた時」で記録し、途中でスキップしても表示済みとする。コースID・座標・開始方向・境界で判定し、単なる名前変更では初回へ戻さない。初期every／first／offは専用`twist.briefing.v1`へ、説明・視点・操作方法は専用`twist.start-flow.v1`へ保存する。既存の調整値や自己ベストを本人の操作なしに書き換えない。
- 全画面の注意文はブラウザー側の表示なので、アプリから消えた時刻を測れない。全画面はタイトルで要求し、成功から飛行まで最低6秒を仮の余裕とする。メニューと3秒のカウントダウンも含め、不足分だけ待つ。拒否・未対応なら3秒のみ。6秒で実機の注意文が消えるとは未確認で、Pixel 9aの操作を塞ぐ時間を測って判断する。
- 新規出発は3・2・1、通常の一時停止からの再開は既存の飛行を続ける。画面離脱や取消は待ち予約を取り消し、後から自動で発進しない。全画面解除時も安全側に止まり、再開は明示操作にする。
- タイトルとプレイは3寸法・センサー／画面操作で縦スクロールなし。全入力と出力・停止等へ触れられることを確認する。履歴・詳しい記録・戻す詳細は設定へ移し、設定画面のスクロールは許す。旧画面の「内部スクロール可」の成功は、新しい通常画面の成功の代わりにしない。
- 通常は飛行機。探索は検証用`dev=1`へ、機首方式と従来の見え方は設定の検証用段へ残す。比較用旧画面は`dev=1&flow=legacy`を両方指定した場合だけ。旧機能の試験はこの明示入口、新しい通常導線は別の通し試験で全範囲を確認し、既存試験を外さない。
- 視点はコース選択と飛行中に切り替え、位置・向き・速度・時計を続ける。新ボタンは案内・HUDの避ける領域へ含める。コピーは開始操作／全画面／カウントダウンの記録と地図の表示／描画前に閉じたか／表示時間／見返しを分ける。地図の表示時間は画面が見えていた時間で、理解したかは判定しない。
- 40kmの仮データは地図の縮尺とkm目盛りの備えだけ。高速空域の物理・海・浮動原点は実装しない。公開順はv30完了後にv31のまま。開始前の自動音・振動を足さず、明示したBGM試聴の例外は保持する。
- 個別の地図・部品試験と、端末APIを模した通常の全画面導線は成功を確認したが、最終統合後の全体・公開・保存版29の初公開確認は未完了。保存版25／26／29を変更せず、v29の完了記録を残す。
