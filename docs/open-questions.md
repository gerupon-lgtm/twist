# 仮決め・保留

## v0.1.25

- 輪は進行方向から左右15度・上下10度、設定された機首角度と失速開始20度から3度の余裕を取る。低速時は水平飛行に必要な角度を見積もって上昇を抑える。出力0で上昇を保証しない。
- 近すぎる目標では回り込みを案内。境目で左右反転を繰り返さないよう、比率0.9/1.1と0.6秒の保持、0.2秒の変化を採用。
- 輪と実際の進行方向の印を安全な角度のまま両方表示できない場合は、輪を隠し理由を表示する。測定であるFPMの位置は移動しない。通常の3寸法・3視点での完走検証は省略しない。
- 新しい目標の初回表示は、前方・描画距離内・画面全体の範囲内に中心が入る条件を採用。既存の出口初回表示は比較を続けるため上下パネルの間というv0.1.24の定義を維持する。光や柱の一部が見える時刻や人が認識した時刻は測れない。最大約1フレームの精度。
- 英語の略語はdocs/settings-guide.mdと調整内の一覧へ記録。既存の記録キーと日本語の区間名は保持し、設定値とtargetViewsだけ追加。
- 禁止された変更は実装していない。実機の感触・音の聞こえ方は未確認。

- 取得球の中心を通れなくても既存の取得範囲へ進めるときは、そのまま向かう案内を優先する。現在の高さとの差を差し引いた水平の範囲の80%だけを見込み、安全の余裕を取る。取得判定の拡大はしない。
- 上部のカードは案内使用中だけ小さくし、横画面で左寄せにする。通知と方位帯は実FPMと輪を塞がない位置へ移す。レーダーの処理は保ち、輪がレーダーを避ける。

## v0.1.26

- 前提を変更する。v25では飛行の計算を維持したが、今回は発案者が許可した旋回の変更を行う。旋回の強さ9.8（3〜15）を独立させ、揚力・落下・失速に使う重力3と既存の力の式は維持する。機首だけを速く回しても実進路の半径は変わらないため、水平の速度の向きも旋回に対応させる。垂直速度と速さを保ち、元の旋回成分を二重に加えない方法を採る。
- 同じコースの旋回使用率は、20m/sでは10m/sの4倍になる。同じ3〜6割等の下限を両速度へ同時に当てはめることはできない。両速度で上限1以下を確認し、難度の帯は20m/s側に適用する。45度以上の角の数と周回時間も別に制限する。
- コースの角を内側へ丸める旧検証では、大きな角と既存の取得半径が両立しないため、3点を通る円の半径で局所的な曲がりを判定する。幾何の合格だけで実飛行の合格とはせず、実際の入力・物理計算による完走も確認する。
- やさしい3光・ふつう5光・むずかしい8光を採用し、初期選択はやさしい。旧コースは比較用のcourse=legacyで残す。標準の選択肢は3コース。
- ステージ中心から前後左右350mを遊ぶ領域とする。端は雲で見せ、速度に応じて早めに警告と中心へ戻る矢印を出す。境界を越えても速度を消さず、操作を続けられる形にする。地面は境界の外にも広げる。従来の高度上限45mは維持する。
- 広さに合わせ、レーダーの初期半径を180m、調整上限を500mにする。保存済みの60m等は保持する。コースと区間記録は目標数から作り、3光の古い区間ID・項目名は維持する。
- v25の配信ファイル21個を、内容を変えずpublic/versions/0.1.25へ保存した。後続版の公開後も比較できるようにする。版別URLも設定保存の領域は同じブラウザーで共通。古い版で保存すると新しい項目が初期値へ戻る場合があるため、比較の記録にはその版の設定値も残す。比較用URLはブラウザーで開き、ホーム画面アプリは最新版を使う。
- WindowsとCIのHTML改行の差をなくすため、ビルド後のルートindex.htmlだけLFへ統一する。保存した旧版のファイルには触れない。
- 禁止された重力・取得半径・外部送信・開始前の音や振動の変更は行わない。Pixel 9aでの曲がりやすさ・面白さ・重さは未確認のまま残す。

- 旋回の足し方は、従来の力学が作る自然な旋回を残し、強さ9.8と従来3との差分だけを水平へ加える方法にした。小さな純粋な計算では、翼35度・初速10・出力50%・10秒の高度損失が従来2.731mに対して2.646mで、別案の3.425mより近かった。安定後の実進路の旋回率は計算式と約0.1%差。これは計算上の比較で、3Dでの完走や実機の受入確認は別に行う。

- 目標が4個以上のレーダーでは、次の目標の番号と上下差を優先し、ほかの印は番号だけにして文字の密集を抑える。点の位置・全目標の情報・色・取得後の更新は維持する。


## v0.1.27

- 旋回9.8・±350m・3コース・取得半径3.2/4mはv26のまま。通常の巡航10/上限30も維持し、ABの追加推力18と一時上限45だけを加える。45m/sの既存抵抗は18.225なので、弱い推力追加では届かないための仮値。揚力・落下・失速・抵抗の式は変更しない。
- AB解除直後に45→30へ切り詰めると勢いが突然消える。ABで30を超えた場合だけ、その時点の速さを増やさず既存抵抗で30以下へ戻す。通常の30以下と通常の不正な過大速度入力は、v26固定360例で同じ出力を維持する。
- ゲージは100・開始0、光25、出口40。10秒以内の連続取得は追加5/10/15（上限15）。低空は高さ0〜12m・速度6以上で、近いほど最大4/秒、AB使用中は低空の自己充電をしない。消費12/秒。全数値はafterburner.jsの1か所。記録の獲得量は上限で捨てた分を除く実際の補充量。
- 手動は横ドラッグ110%で点火・100%へ戻すと解除、その間は状態を保つ。トラック単独タップは値を飛ばさず、5px以上の横移動・明示キーだけでABを要求する。縦スクロールは値を変えない。空のまま要求した場合も解除待ちにし、補充直後に突然点火しない。
- 自動ABは初期オフ。機首下げの操縦入力35度（範囲25〜60）を0.18秒保持して点火、5度戻すと解除。機体が自然に下がっただけでは点火しない。画面の向きに対応済みの入力を使う。部分燃料は支払えた秒数だけ推力を加え、負燃料を作らない。
- 休止・非表示・接地・クリアでABは止め、燃料と統計はその飛行内で保持。再開は既存どおり出力50%・速度10。再挑戦/コース変更は燃料0へ戻す。総記録は再試行をまたいで二重加算せず、最大速度は接地で0にする前の実速度を数える。ABの記録は飛行機モードだけ。
- 速度単位はkm/hを初期値にし、m/s/ktを選べる。内部速度と最高速のコピー値はm/s。探索でも単位とassistedの流線・地面/雲を共有し、表示の一括初期化で単位/流線も初期値へ戻す。探索の入力設定は維持。
- 流線は周辺の固定80本以内・中心72%を空け、量0〜2（初期1）。地上は最大640個を3組で描き、近い雲を追加。選択コースの目標の周囲を空け、当たり判定は付けない。
- 飛行の視野追加は初期最大10度（0〜15）、AB時はその設定に比例してさらに3度相当、最終上下視野は115度以下。基準の操縦席設定は書き換えない。0で両方の追加を止める。高速揺れは初期オンで外視点最大0.12度・操縦席0.035度、オフ可能。最終の実カメラの視野と向きをHUDの投影も使う。
- AB音は効果音PSGのAで120msの点火から轟音へ。ノイズ周期が共通なので、警告/既存イベント中は追加分を抑え、昇降音/方位音中は弱める。別の予約点火イベントを作らず、警告後に遅れて点火音を出さない。BGMと外部音源は維持。
- 振動はモーター強度を指定できないため、短い周期内の振動時間を増す。fineは30/30msを4回、classicは120/280ms。通常飛行の震えオフはABの継続振動も抑える。警告/取得/接地を優先し、開始操作前には音も振動も出さない。
- v26の配信21ファイルを、公開成功後にバイトを変えずpublic/versions/0.1.26へ保存した。v27公開時に保存版25/26の専用URLも再確認する。版別の設定共有という前提は継続。
- 全既存テスト、実際のドラッグ・音源・振動要求・描画、前後の負荷測定、公開確認を終えてから完了とする。Pixel 9aでの速さ/酔いやすさ/爽快感/操作/描画と音の重さは未確認として残す。
