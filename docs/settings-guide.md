# twist 調整パネルの早見表

調整パネルの各設定が、何を変えるのか、上げる・下げるとどうなるのかをまとめたものです。
初期値と範囲は、現在のアプリの設定に合わせています。

## 調整のコツ

- **1回に変える設定は1つだけ**にします。2つ以上を同時に変えると、どれが効いたのか分からなくなります。
- 変えたら数回飛んで、記録（墜落回数・復帰補助の時間・最後の1回の時間）を比べます。
- 迷ったら、その項目の「初期値」または「変更前へ」で戻します。全体の初期化はほかの項目も戻すため、最後の手段にします。

## 困ったときの逆引き

| こう感じたら | まず触る設定 | どちらへ |
|---|---|---|
| 機首が上下に動きすぎる、落ち着かない | 機首が最大になるスマホの傾き | 上げる |
| 機首を上げるのに大きく傾けないといけない | 機首が最大になるスマホの傾き | 下げる |
| 機首の反応がもっさりしている | 機首が追いつく時間の目安 | 下げる |
| 機首がカクカク・ピクピク動く | 機首が追いつく時間の目安 | 上げる |
| 上昇が遅い、高い目標に届かない | 機首の最大角度 | 上げる（失速しやすくなる） |
| すぐ失速する | 機首の最大角度 | 下げる |
| 水平に飛んでいるつもりなのに、機首が少し動く | 機首の中立範囲 | 上げる |
| 旋回が敏感すぎる、ふらつく | 旋回が最大になるひねり | 上げる |
| 大きくひねらないと曲がらない、画面が見づらい | 旋回が最大になるひねり | 下げる |
| 中立付近の細かい旋回が難しい | 旋回の効き方のカーブ | 上げる |
| 最大までひねっても曲がりがゆるい | 翼の最大角度 | 上げる |
| 曲がりが急すぎて制御しにくい | 翼の最大角度 | 下げる |
| 景色の回転が手ぶれでガタガタする（固定表示） | 固定表示の回転のならし | 上げる |
| 景色の回転が遅れてついてくる、酔う（固定表示） | 固定表示の回転のならし | 下げる |
| 操縦席視点で機首の上下が分かりにくい | 操縦席の上下の視野 | 下げる（見える範囲は狭くなる） |
| 操縦席視点で角度線がごちゃごちゃする | 操縦席の角度線の範囲 | 下げる |
| 遠くの目標がレーダーの縁に張り付いて距離感がない | レーダーの半径 | 上げる |
| 近くの目標の位置が細かく分からない | レーダーの半径 | 下げる |

## 各設定の説明

### 機首の上下（傾き＝角度方式）

画面の上辺を起こした角度に応じて、機首の**目標の角度**が決まり、機首がそれを追いかけます。

| 設定 | 初期値（範囲） | 上げると | 下げると |
|---|---|---|---|
| 機首の中立範囲 | 3°（0〜8°） | 少しの傾きでは機首が動かない。手ぶれに強いが、小さな修正が効きにくい | 小さな傾きにも反応する。細かく操作できるが、手ぶれも拾う |
| 機首が最大になるスマホの傾き | 25°（10〜30°） | 大きく傾けないと最大にならない。穏やかで正確。ただし画面が見づらくなる | 少しの傾きで最大になる。機敏だが、敏感になる |
| 機首の最大角度 | 15°（5〜35°） | 機首を大きく上下でき、上昇・下降が速い。上げすぎると失速しやすい（失速の始まりは翼に当たる風の角度20°） | 機首の動く幅が小さく、失速しにくい。上昇・下降は遅くなる |
| 機首が追いつく時間の目安 | 0.3秒（0.1〜1.0秒） | 機首がゆっくり追いかける。なめらかだが反応が遅い | 機首がすぐ追いかける。機敏だが、小刻みに動きやすい |

**注意**：機首を上げても、高度はすぐには変わりません。機首の向きが変わってから、進む向きが少しずつ変わるためです。

### 旋回

スマホをひねった（または回した）角度に応じて、**翼の傾き**が決まります。翼が傾くと、その方向へ曲がります。

| 設定 | 初期値（範囲） | 上げると | 下げると |
|---|---|---|---|
| 旋回の中立範囲（ひねる） | 3°（0〜8°） | まっすぐ飛びやすい。小さな旋回はしにくい | 小さなひねりにも反応する |
| 旋回が最大になるひねり | 15°（5〜30°） | 大きくひねらないと最大にならない。穏やか。画面が見づらくなる | 少しのひねりで最大になる。中立範囲を引いた残りが実際に使える幅なので、下げすぎると極端に敏感になる |
| 旋回の中立範囲（回す） | 5°（0〜8°、最大入力より1°以上小さく補正） | 小さな回しを無視する | 小さな回しにも反応する |
| 旋回が最大になる回し | 20°（8〜40°） | 大きく回して操縦する | 少しの回しで最大になる |
| 旋回の効き方のカーブ | 1.0（1.0〜2.0） | 中立付近はゆるやかに、最大付近で急に効く。細かい修正がしやすい | 1.0で、ひねった分だけ比例して効く |
| 翼の最大角度 | 40°（5〜40°） | 最大で曲がったときに、鋭く曲がる | 曲がりがゆるくなる。安定する |

**注意**：6m/sより速い範囲では、同じ翼の傾きなら遅いほど鋭く曲がります。6m/s以下では、それ以上鋭くならないよう上限を設けています。速度0では旋回せず、出力と姿勢を戻して速度を取り戻します。

### 見え方

| 設定 | 初期値（範囲） | 上げると | 下げると |
|---|---|---|---|
| 固定表示の回転のならし | 0.05秒（0〜0.3秒） | 景色の回転がなめらかになり、手ぶれが減る。ただし回転が遅れてついてくる | 景色がスマホの回転にすぐ合う。手ぶれも出やすい |
| 追尾カメラの遅れ（外から見る3D視点） | 0.15秒（0〜0.5秒） | 旋回や上昇で、自機を斜めから見る角度が大きくなる。迫力が出るが、狙いはつけにくい | 自機の真後ろに近くなる。0で遅れなし |
| 操縦席の角度線の範囲 | 10°（5〜30°） | 多くの角度線が出る。画面が混む | 今の機首の角度の近くだけ出る。すっきりする |
| 操縦席の上下の視野 | 自動（手動は60°〜今の画面で計算した上限、最大100°） | 広く見える。機首の動きは小さく見える | 機首の動きが大きく見え、上下が分かりやすい。見える範囲は狭くなる |
| レーダーの半径 | 60m（20〜120m） | 遠くまで映る。近くの細かい位置は分かりにくい | 近くが細かく分かる。遠くの目標は縁に張り付く |

### 音と振動

| 設定 | 何を変えるか |
|---|---|
| 音量・BGM音量 | 全体と、BGMだけの大きさ |
| 効果音 | エンジン、風切り、警告、光の取得などの音のオン・オフ |
| バリオ | 上昇すると「ピッ、ピッ」と高く鳴る音のオン・オフ。上がっているか下がっているかを耳で分かるようにする |
| 振動・振動の強さ | 振動のオン・オフと強さの倍率。振動する時間の倍率。モーターの強度を直接変えるものではなく、v0.1.22以降の細かな震えがセンサーへ与える影響は実機で未確認 |
| 通常飛行の震え | エンジン出力に応じた通常飛行の震えのオン・オフ。失速の手前や警告の振動はそのまま残る |

## 今の版で追加された表示・操作

- 目標高度の目印：初期値オン。現在高度、目標高度、差と取れる高さの帯を表示します。legacyでは表示しません。高さだけでなく進路も合わせます。
- 調整と画面練習のゲージは、横にずらして変更します。触れただけでは飛ばず、±でも変更できます。「変更前」の値は項目ごとに端末内へ保存します。
- 視野の「初期値」は自動に戻します。「変更前へ」で自動/手動のどちらも戻せます。
- 通常飛行の振動間隔：細かな震え/従来を選びます。失速・取得のパターンとの区別は端末で比較してください。
- 飛行中の曲：従来2曲、勇進の航路、ギター風のリードのロック別案、全4曲を選べます。既存曲は保持します。
- 区間時間：開始→光1→光2→光3→出口を、1回のルートごとに記録します。未完了は未完了、一時停止やセンサー待ちは除きます。
- 中立範囲は最大入力より1°以上小さくなります。翼の最大角度は初期値40°が上限なので、それ以上は上げられません。

## 元の早見表から合わせ直した点

v0.1.21の早見表を元に、項目別の履歴/初期化、視野の実際の上限、回す方式の個別範囲、6m/s以下の旋回上限、振動パターン変更後の未確認を補足しました。機首を上げるだけで上昇が保証されるわけではなく、出力と速度も関係します。

現在高度と目標高度はHUDの上に並び、目的物の印には上下の差も出ます。出口が低く視野に入っていないときは、「下に○m」の表示を目安に高さを合わせます。


## 目標への案内とHUD

| 設定 | 初期値 | 意味 |
|---|---|---|
| 目標へ向かう輪 | オン | 白いFPMを水色の輪へ近づける。重なると緑。自動操縦ではありません。 |
| 方位目盛りの目標の印 | オン | 印が中央へ来る方向へ曲がる。目盛りの外は矢印と角度。 |
| 画面の縁の目標案内 | オン | 画面外の目標を大きな矢印と距離で知らせる。 |
| 次の目標の合図 | オン | 光を取った直後1.8秒、次の向きと高さを表示。 |
| 左右から聞こえる案内音 | オン | 目標側から短音。正面に近いほど短い間隔。警告・昇降音・取得音を優先。 |
| HUDの表記 | 英語 | 日本語へ切替可。メニューと記録の既存の項目は日本語のまま。 |

TGT＝目標、EXIT＝出口、SPD＝速度、ALT＝高度、V/S＝昇降速度、HDG＝方位、THR＝出力、FPM＝実際の進行方向、FD＝案内の輪、TRK＝進行方向、TGT ALT＝目標高度。▲＋/▼−は上下の差、ALT OKは取れる高さ、CLIMB/DESCENDは上昇/下降の目安、TERRAIN/PULL UPは地面の警告、STALLは失速からの復帰補助、NEXTは次の目標、EXIT OPENは出口開放です。
