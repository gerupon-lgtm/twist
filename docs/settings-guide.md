# twist 調整パネルの早見表

対象：v0.1.42（2026-11-09）。

調整パネルの各設定が、何を変えるのか、上げる・下げるとどうなるのかをまとめたものです。
初期値と範囲は、現在のアプリの設定に合わせています。

## v30の開始と設定

選択肢を一度に見せないため、通常はタイトル→初回の遊び方→コース選択→地図→構える→3・2・1→飛行の順です。地図や待ち時間はコースの時間へ含めません。「はじめる」で全画面を要求し、構えた時点で持ち方を合わせ、必要ならセンサー許可と向き固定を行います。全画面の成功から飛行まで最低6秒の余裕を取りますが、Pixel 9aの注意文が消える長さは未確認です。拒否・未対応でも3秒のカウントダウンで進める設計です。

| 場所・項目 | 操作と保存 |
|---|---|
| コース選択 | 通常3コース・シエラ縦断（1/50）・高速空域（試作）・シエラ縦断（1/10・亜音速）の6カード、選択中の大きな斜め地図、自己ベスト。目標の番号と出口は大きな記号で表示する。選択画面には機影を出さず、開始は四角で示す。外から／追尾3D／操縦席をここで選び、前回の視点を覚える。検証用の探索は通常3＋1/50の4コースで、高速空域と1/10は飛行限定 |
| 開始前の地図 | 初期は「毎回表示する」。「コースごとに初回だけ」「表示しない」へ設定で変更。機体が斜め地図の目標を順に通り、リングの色が変わる。地面の格子と支柱で高さを示す。全体図は真上から表示する。3.6秒で描画後も留まり、タップ／SKIPですぐ進める。描画後はCONTINUE |
| 操作の方法 | 設定の「スマホの傾き／画面で操縦」。初期は傾き。センサーが使えない場合は、自分で画面操作を選べる |
| 飛行中の「視点」 | 外から→追尾3D→操縦席の順。位置・向き・速度・時計を続ける |
| スロットルの位置 | 3視点とも操縦席視点に合わせた共通の位置。細い表示の周囲を含めてドラッグできる |
| 一時停止 | 再開、持ち方を合わせ直す、地図を見る、視点、設定、コース選択へ。飛行途中のコース選択には終了確認を出す |
| 一時停止の地図 | 現在位置と方向、取得済みを重ねる。場外の位置も含める。閉じると停止へ戻り、自動で再開しない |
| 結果 | タイムと自己ベスト、もう一度、コース選択、コピー。履歴や詳しい記録は設定へ |

地図の表示方式と初回判定は`twist.briefing.v1`、説明を見たか・視点・操作方法は`twist.start-flow.v1`という専用の保存先を使います。従来の調整値や自己ベストを初期化しません。「初回」は地図を開いた時に記録し、途中でスキップしても表示済みとします。配置が異なるコースは別の初回として扱います。

設定の段は①基本の操縦、②詳しい設定、③音と振動、④検証用の表示・操作です。操作方法と地図表示の選択も設定にあります。見え方「従来」と機首「回り続ける」は④へ移し、探索は`?dev=1`で出る検証用項目へ残します。旧画面で比較する場合は`?dev=1&flow=legacy`。これは過去版そのものを開く指定ではありません。

**タイトルとプレイ画面は縦スクロールを使わず、画面操作でも3入力・出力・停止等を画面内へ収めます。** 角度の調整、履歴と戻す操作、詳しい記録は設定へまとめ、設定画面はスクロールできます。プレイ画面の「上辺・右辺・回し角度」は、画面操作を選んだ練習時だけ使う入力欄です。通常のスマホの傾き操作では表示しません。

## コースと広いステージ

従来の3コースは、やさしい（光3個・巡航目安60〜100秒）、ふつう（5個・90〜150秒）、むずかしい（8個・120〜180秒）です。選択は端末内に保存します。変更すると、そのコースの最初へ戻ります。この3コースの最終目標の先にはv29から270m／330m／350mのAB直線があります。入口・出口は開いた枠と柱で示し、出口まで40m以上の余裕を取っています。柱と枠には当たり判定はありません。

### シエラ縦断（1/50）：今回は平地のコース

長い実在ルートを通常のゲーム速度で遊ぶため、提供された推定の緯度・経度を水平方向1/50へ縮めています。**距離・ALT・SPDは縮小後のゲーム内の値**です。10m/sは従来どおり36km/hで、実機相当として50倍にはしません。高さは`(推定標高−790)×2÷50+10`で門の位置に変換します。推定値を使うため、測量済みの位置や標高の再現ではありません。

地面は全域0mの平面です。数値標高データ（DEM）は取得せず、山・谷や山との接触は今回追加しません。A〜Fの6光を順に取り、Gが出口です。GからAへ戻る閉じた周回ではありません。Aの150m手前・高さ10mからA→Bの向き（約350°）へ出発します。開始→Aも含む7区間を記録します。Fの門は平地から41.6mであり、すべての門が地面から10mにあるわけではありません。

Sierraだけ空域を前後左右1850m・高度上限70mへ広げ、レーダーは一時的に1000mを使います。**通常のレーダー保存値は変更しません。** ほかの通常コースへ戻ると、その保存値を使います。飛行と検証用の探索で選べ、力・速度・取得範囲は通常コースと共通です。ABによる時間短縮や使い心地、Pixel 9aでの完走時間・見やすさ・負荷は未確認です。

見失い対策の地面は、ステージの外も含め16mと4mの模様を繰り返します。「地面の模様の濃さ」は0〜1、初期0.8。0で模様を消せます。従来の見え方では元の地面を使います。以前の初期値60mを保存している場合だけ、一時停止中の「調整」のレーダー項目付近で180mへの変更を一度提案します。「60mを維持」を選べば変更しません。案内を見ずに閉じた場合は、次に開いた時にも確認できます。

端の嵐に近づくとSTORM、外へ出るとTURN BACKと、内側へ戻る矢印を表示します。飛行や入力を自動で止める案内ではありません。地面は嵐の外にもあります。目標が4個以上のレーダーでは、次の目標だけに上下の差を添え、ほかは番号を短く表示します。

### シエラ縦断（1/10・亜音速）：低空を速く飛ぶ

1/50の速度だけを上げると区間が短すぎて曲がれないため、別コースを追加しています。水平1/10・高さの強調1倍、門の高さは`(推定標高−790)÷10+60`です。平らな地面0mの上をA〜F、出口Gへ向かいます。山並みは遠景で、谷や尾根の地形はまだありません。推定座標を使ったゲーム内の距離であり、測量値の再現ではありません。

Aの1km手前・高度60mから、実速度150m/sで出発します。門は半径40m、A〜Gは高度60〜139m、開始から約19.9km。出力100%の水平飛行は約250m/sへ近づき、AB（追加推力）は最大300m/s。音速340m/sを越える設定はありません。AB後の慣性や下降で250m/sを越えても、300m/s以内で飛びます。表示は実速度で、250m/sは900km/h、300m/sは1080km/hです。

このコースだけ最大9G・機首の効き0.35・レーダー5km・有限ABを固定します。通常や高速空域の保存設定は上書きせず、設定画面には専用条件を表示します。ABゲージは容量100・開始60・毎秒4消費、門で12、地面まで160m以内かつ100m/s以上では毎秒0.75補充します。一時停止中は増えません。

地面は320m・40m・8mの模様を重ね、数十mの柱・旗と遠景で距離を伝えます。接触は機体の実形状で判定し、中心高度0mより先に翼が触れる場合もあります。ALTは中心から平地までの高さ、記録の`minimumGroundAltitude`は最低中心高度、`minimumGroundClearance`は機体最下部の最低余裕です。A〜Gの区間時間・区間ごとのAB秒数と消費量、最高実速度・M・最大Gもコピーへ残します。Pixel 9aの速さの感覚・操作・酔い・発熱は未確認です。

## 高速空域（試作）の設定と表示

通常コースの700m四方では音速で約2秒で横切るため、高速空域は40km四方の別コースです。中心高度1500m・実速度200m/sから始め、出力の右端の先でABを使うとM2（680m/s＝2448km/h）を目指せます。半径80mの門5枚と出口を6kmごとに通ります。通常の3コースの力や取得範囲は変更しません。

| 高速専用の設定 | 初期値・範囲 | 意味と適用する時点 |
|---|---|---|
| 最大G | 9G・3〜12G | 上下と旋回で使える力の共通の上限。水平巡航は1G。大きくすると同じ速度で小さく曲がれる。次の新しい飛行から適用 |
| ABの燃料 | 無制限／ゲージ制 | 無制限は∞で表示。ゲージ制は100から開始し、毎秒1.5消費・門で20補給。次の新しい飛行から適用 |
| 高速空域の機首の効き | 0.35倍・0.1〜1倍 | 15度を基準に、初期は最大5.25度へ写す。通常の機首角を上書きしない。次の新しい飛行から適用 |
| 高速空域のレーダー範囲 | 10km・2〜20km | 高速空域だけの表示範囲。表示の変更はすぐ適用 |

Mは実速度÷340m/s、Gは実際に使っている支持・揚力の大きさ÷9.8m/s²です。最大Gの設定値と現在のGは別です。M0.95〜1.05では機体周りの白い雲、操縦席では縁のもやを出します。音速の境界で合図を連打しないよう、M1.01で上抜け、M0.99で下抜けの音・振動を各1回出します。正確なM1・M2の到達時間は別に記録します。

ALT 1.5kは中心高度1500m。機体のいちばん低い部分から海面までの余裕は、中心高度とは異なります。翼を傾ければ片方の翼が低くなり、中心高度が0mになる前に海へ触れます。中心を沈めて止める処理ではありません。6000mの上端はCEILING／DESCENDの案内とし、速度や位置を急に変えたり、自動停止したりしません。

高速の物理設定は一時停止して変更しても、現在の飛行へ混ぜません。再開は位置・姿勢・速度を保ち、保存した新設定は次の挑戦から使います。通常用の機首最大角・翼最大角・旋回の強さ・地面の模様などは、高速では未使用として隠します。通常用の設定と自己ベストは保持し、高速は計算・門の形・設定ごとに別の記録へ保存します。

コピーの`supersonic`には最高M、M1・M2までの活動時間と計算上の時間、実測最大G、最低の中心高度と最下部の余裕、門ごとの区間時間・通過／失敗回数・最接近、燃料方式を保存します。表示のkやkmへ換算する前の位置・速度・記録はm・m/s・秒です。

## 調整のコツ

- **1回に変える設定は1つだけ**にします。2つ以上を同時に変えると、どれが効いたのか分からなくなります。
- 変えたら数回飛んで、記録（墜落回数・復帰補助の時間・最後の1回の時間）を比べます。
- 迷ったら、その項目の「初期値」または「変更前へ」で戻します。全体の初期化はほかの項目も戻すため、最後の手段にします。

## モードとHUDの読み方

| 遊び方・視点 | HUDに表示する情報 | 下部の操作 |
|---|---|---|
| 飛行機・従来視点／追尾3D | 左に速度、右に現在高度・目標高度と差・昇降・地面／失速の警告。中央は実進路と案内の輪。上側に視点切替。 | スロットル、AB、一時停止、持ち方合わせ、ヘルプ。画面操作は設定で選ぶ。 |
| 飛行機・操縦席 | 既存の速度・高度・昇降・方位の計器と目標高度。外視点用の小さい表示は重ねない。 | 同じ飛行操作。 |
| 探索 | 速度・高さ・目的地の高度情報。飛行の姿勢・昇降・出力・ABは出さない。 | 一時停止、持ち方合わせ／入力切替、ヘルプ。 |
| 高速空域・3視点 | それぞれの飛行HUDに実M・現在Gを追加。ALTは中心高度をk表示、距離とレーダーはkm。海面までの余裕は機体の実形状から判断。 | 同じスロットル・AB・停止・持ち方・ヘルプ。通常の入力方向とTHR位置を保つ。 |

通常プレイでは下部の傾きゲージ・詳しい姿勢数値・平常状態の説明を隠します。画面のスライダーで操縦する場合の入力パネルは、実際の操作に必要なので残します。v30では入力そのものと現在値をプレイ中へ、履歴や戻す詳細を設定へ分けます。`INPUT HOLD`は、計算できる新しい値がない時に前の入力を保持している表示です。

v29では横向きの入力欄の内部スクロールを許していましたが、後続の利用者指定により、v30の通常プレイでは全入力をスクロールなしで使う配置へ変更します。はみ出しを隠して操作不能にすることは合格としません。旧画面の検証結果とは分けて確認します。

## 各設定の説明

### 機首の上下（傾き＝角度方式）

画面の上辺を起こした角度に応じて、機首の**目標の角度**が決まり、機首がそれを追いかけます。

| 設定 | 初期値（範囲） | 上げると | 下げると |
|---|---|---|---|
| 機首の中立範囲 | 3°（0〜8°） | 少しの傾きでは機首が動かない。手ぶれに強いが、小さな修正が効きにくい | 小さな傾きにも反応する。細かく操作できるが、手ぶれも拾う |
| 機首が最大になるスマホの傾き | 25°（10〜30°） | 大きく傾けないと最大にならない。穏やかで正確。ただし画面が見づらくなる | 少しの傾きで最大になる。機敏だが、敏感になる |
| 機首の最大角度 | 15°（5〜35°） | 機首を大きく上下でき、上昇・下降が速い。上げすぎると失速しやすい（失速の始まりは翼に当たる風の角度20°） | 機首の動く幅が小さく、失速しにくい。上昇・下降は遅くなる |
| 機首が追いつく時間の目安 | 0.3秒（0.1〜1.0秒） | 機首がゆっくり追いかける。なめらかだが反応が遅い | 機首がすぐ追いかける。機敏だが、小刻みに動きやすい |

**注意**：機首を上げても、高度はすぐには変わりません。機首の向きが変わってから、進む向きが少しずつ変わるためです。

### 旋回

スマホをひねった（または回した）角度に応じて、**翼の傾き**が決まります。翼が傾くと、その方向へ曲がります。

| 方式 | 使う動き・選び方 |
|---|---|
| ひねる（標準） | 左右の端を上げ下げする。まず画面の端の傾きで試す場合はこちら |
| 回す（比較） | 画面の面内で、ハンドルのように回す |
| 手首（比較） | 構えた向きから腕の水平な向きを推定し、その向きのまわりの回転を使う。持つ角度による効き方の差を小さくして試す方式 |

スマホだけでは腕そのものの向きを測れないため、「手首」は構えた姿勢からの推定です。最初は従来の「ひねる」で、保存済みの選択はそのまま使います。設定で選ぶと保存し、有効なURL指定があればその訪問ではURLを優先します。新しいPWA起動URLでは方式を固定せず、保存値を使います。

手首用の感度は「おだやか30°／ふつう25°／機敏18°」を押したときだけ適用します。変更前の値へ戻すこともでき、同じ値を押しても履歴を増やしません。ほかの2方式の数値は変えません。上下操作は、手首の旋回成分を分けた残りから取り出します。固定表示の景色には、従来の画面の回し角度を使い続けます。

| 設定 | 初期値（範囲） | 上げると | 下げると |
|---|---|---|---|
| 旋回の中立範囲（ひねる） | 3°（0〜8°） | まっすぐ飛びやすい。小さな旋回はしにくい | 小さなひねりにも反応する |
| 旋回が最大になるひねり | 15°（5〜30°） | 大きくひねらないと最大にならない。穏やか。画面が見づらくなる | 少しのひねりで最大になる。中立範囲を引いた残りが実際に使える幅なので、下げすぎると極端に敏感になる |
| 旋回の中立範囲（回す） | 5°（0〜8°、最大入力より1°以上小さく補正） | 小さな回しを無視する | 小さな回しにも反応する |
| 旋回が最大になる回し | 20°（8〜40°） | 大きく回して操縦する | 少しの回しで最大になる |
| 旋回の中立範囲（手首） | 3°（0〜8°、最大入力より1°以上小さく補正） | 小さな動きを無視する | 小さな手首の動きにも反応する |
| 旋回が最大になる手首の角度 | 25°（5〜40°） | 大きく回すまで穏やかに効く | 小さな動きで最大になる |
| 旋回の効き方のカーブ | 1.0（1.0〜2.0） | 中立付近はゆるやかに、最大付近で急に効く。細かい修正がしやすい | 1.0で、ひねった分だけ比例して効く |
| 翼の最大角度 | 40°（5〜40°） | 最大で曲がったときに、鋭く曲がる | 曲がりがゆるくなる。安定する |
| 旋回の強さ | 9.8（3〜15） | 同じ翼の傾きで、実際の進路が鋭く曲がる | 穏やかに曲がる。揚力・落下・失速の重力3は変わらない |

**注意**：6m/sより速い範囲では、同じ翼の傾きなら遅いほど鋭く曲がります。6m/s以下では、それ以上鋭くならないよう上限を設けています。速度0では旋回せず、出力と姿勢を戻して速度を取り戻します。

記録とコピーには方式、手首の基準の持ち方と推定軸、合わせ直すごとの角度の振れ幅を入れます。持ち方は寝かせて0°・上辺を立てて90°が目安で、逆へ倒すと負の値です。振れ幅には自分の操作も含み、手ぶれだけの測定ではありません。探索では従来の入力を使い、手首用の2値は使いません。

Android/PCは画面が回っても操作を続け、基準を勝手に合わせ直しません。持ち方を変えた場合は「持ち方を合わせ直す」を使います。iPhoneは従来どおり、画面の向きが変わると一時停止します。Pixel 9aでの直感的な操作感と、旧ホーム画面アイコンへの起動URL更新の反映は未確認です。

### スピード感とABの設定

流線・視野・揺れは、速く感じるための見え方です。これらを変えても、飛ぶ速さや曲がり方、光を取れる範囲は変わりません。ABはゲージを使って実際の推力を増やす操作です。流線と速度の単位は探索でも使い、視野・揺れ・ABは飛行機だけに適用します。

| 設定（記録のキー） | 初期値（範囲） | 何が変わるか |
|---|---|---|
| 空気の流線の量（`streakAmount`） | 1.0（0〜2.0、0.1刻み） | 見失い対策で画面の周辺に出す線の量。速いほど増え、AB中は多く長くなる。0で非表示。中央の目標を避ける配置。 |
| 地面の模様の濃さ（`groundPatternStrength`） | 0.8（0〜1、0.1刻み） | 地面全体の16m・4mの目盛りの濃さ。0で消す。見失い対策で使用。飛ぶ力や接触判定は変えない。 |
| 速度による視野の広がり（`speedFov`） | 10°（0〜15°、1°刻み） | 基準の視野へ速度分を加える。10m/s以下は加算0、30m/sで設定した量。AB中は初期値でさらに3°（設定に比例）。0で通常・AB両方の加算を止める。 |
| 高速時の小さな揺れ（`highSpeedShake`） | オン | 高速時に視点をわずかに揺らす。操縦席では外から見る視点より弱い。オフで停止。 |
| 速度の単位（`speedUnit`） | km/h（m/s・km/h・kt） | 実際の速度を選んだ単位へ換算する。ktはノット。飛ぶ力や記録の元の単位は変えない。 |
| 大きな機首下げ入力でAB（`autoAfterburner`） | オフ | オンにした場合だけ、指定角以上の機首下げ入力を0.18秒続けるとABを要求する。ゲージが必要。機体が自然に下を向いただけでは発動しない。 |
| 自動ABの機首下げ入力（`autoAfterburnerAngle`） | 35°（25〜60°、1°刻み） | 上げると大きく傾ける必要があり、下げると入りやすい。設定角から5°戻すと自動要求が解除される。自動ABがオフの間は発動しない。 |

視野の加算後は上下115°を上限にします。「操縦席の上下の視野」の保存値は基準として保ち、速度でその値を書き換えません。例えば手動70°で飛んでも、AB後に保存値が広い値へ変わることはありません。酔いを感じる場合は、揺れオフ・視野の広がり0・流線0をそれぞれ試せます。Pixel 9aでの酔いにくさは未確認です。

### ABの使い方とゲージ

通常は50%で約10m/sの巡航です。ABは、先に光や低空飛行でためてから直線で使うと、速度とともに旋回の円も大きくなることを確かめられます。曲がり角の手前では出力を戻し、減速する距離を取ります。

1. 出力のつまみを**横に動かして110%**まで入れると、ゲージを使って点火します。目盛りの途中を触れただけでは値は飛びません。
2. **100%へ戻す**と解除します。110%から少し戻して105%でも発動を保ち、入り口付近で点火・解除を繰り返さないようにします。ゲージが空でも終了します。空のまま押し続けていても、後からためた分で突然点火しません。一度戻して入れ直します。
3. 一時停止中はABと消費を止め、残量は保持します。再開時も一度戻してから要求し直します。墜落後の出発は残量0・連続取得なしからです。コースの変更やクリア後の新しい試行は集計もリセットします。

| 条件 | 獲得・消費 |
|---|---|
| 開始時／最大 | 0／100 |
| 光を取得 | 25 |
| 前の光から飛行時間10秒以内に次を取得 | 基本25に追加5、次は10、以後15が上限。停止中の時間は含めない。 |
| 出口を通過 | 40。完了時の残量・獲得量へ反映。 |
| 地面から0m超〜12m未満、実速度6m/s以上で飛ぶ | 毎秒`4×(1−地面までの高さ÷12)`。6mなら毎秒2。停止・接地・ABを消費している時間は加算しない。 |
| AB使用 | 毎秒12。25なら約2.08秒、100なら約8.33秒。上限を超えて入らなかった分は獲得量に数えない。 |

通常の速度上限は30m/s（108km/h）。ゲージを消費しているAB中だけ追加推力と45m/s（162km/h）の上限を使います。点火でいきなり45m/sにはなりません。解除したときも30m/sへ急に切らず、残っている勢いを保ち、従来の空気抵抗で通常の速度域へ減速します。

SPDの10m/sは36km/h・約19.44kt、30m/sは108km/h・約58.32ktです。V/S（昇降速度）はm/sのままです。飛行機の記録・コピーの`afterburner`には使用回数`uses`、使用秒数`seconds`、実際にためた量`earned`、最高速度`maxSpeed`、残量`remainingFuel`、最後の出発分`lastLeg`が入ります。**最高速度の元の値`maxSpeed`は常にm/s**で、SPDの表示単位を変えても変わりません。墜落からの飛び直しは集計を保ち、最後の出発分も分けます。探索の記録にABの集計は加えません。

### 音と振動

「個別試聴」で1曲を選び、「試聴」を押すと、飛行を止めたまま聴けます。曲集の試聴はなく、旧3曲・クリア4曲・AB・比較も含む16曲を個別に選べます。試聴中の曲／音色変更は先頭から再開し、曲が終わった後は再び試聴を押して始めます。「停止」、設定を閉じる、飛行の再開、画面を離れると止まります。本編の曲選択・曲順・飛行回数・再生履歴には加えません。BGMオフでも明示操作で試聴でき、音全体がオフのときは先に音をオンにします。音量は現在の全体音量とBGM音量を使います。

| 設定 | 何を変えるか |
|---|---|
| 音量・BGM音量 | 全体と、BGMだけの大きさ |
| 効果音 | エンジン、風切り、警告、光の取得などの音のオン・オフ |
| バリオ | 上昇すると「ピッ、ピッ」と高く鳴る音のオン・オフ。上がっているか下がっているかを耳で分かるようにする |
| 近くを通る音（`passbySound`） | 初期オン。実速度12m/s以上で柱や現在の目標のそばを通ると短い風切り音。警告・取得音を優先し、後から鳴らし直さない。振動は追加しない。 |
| AB中の曲の盛り上がり（`abMusic`） | 初期オン。次の拍から打楽器を重ね、3秒以上保った後、小節の区切りで通常へ。設定だけをオフにしても主旋律は続く。一時停止・全体音オフでは本編も止める。 |
| 振動・振動の強さ | 振動のオン・オフと強さの倍率。振動する時間の倍率。モーターの強度を直接変えるものではなく、v0.1.22以降の細かな震えがセンサーへ与える影響は実機で未確認 |
| 通常飛行の震え | エンジン出力に応じた通常飛行とAB中の連続した震えのオン・オフ。失速の手前や警告・取得の振動はそのまま残る |

## 今の版で追加された表示・操作

- 目標高度の目印：初期値オン。現在高度、目標高度、差と取れる高さの帯を表示します。legacyでは表示しません。高さだけでなく進路も合わせます。
- 調整と画面練習のゲージは、横にずらして変更します。触れただけでは飛ばず、±でも変更できます。「変更前」の値は項目ごとに端末内へ保存します。
- 視野の「初期値」は自動に戻します。「変更前へ」で自動/手動のどちらも戻せます。
- 通常飛行の振動間隔：細かな震え/従来を選びます。失速・取得のパターンとの区別は端末で比較してください。
- 飛行中の曲：黒曜の翼・鋼翼の鼓動・黎明の航跡・嵐を越えて・Ignition Sky・Steel Advance・Overdrive Horizonの7曲から選びます。初期値は採用7曲を順番に再生。蒼穹突破・遺跡の閃光・勇進の航路は個別試聴に残します。古い指定を読み込んだ時も、その3曲を飛行中には使いません。
- BGMの音色：初期SCC。FMはドラム以外の旋律・和音・ベースを軽量FMへ切り替えます。ギターは歪んだエレキギター風の音色、打楽器は従来のPSGです。次の再生から反映し、試聴中だけ先頭から再開します。
- クリア時の曲：初期は既存「突破の凱歌」。新しい「凱旋の点火」「鋼の勝利」「閃光の帰還」も選べます。曲ごとに個別試聴できます。
- 区間時間：開始→各コースの光→出口を、光の数＋1区間で記録します。未完了は未完了、一時停止やセンサー待ちは除きます。
- 区間の最接近：目標までの最小距離と、15m以内へ近づき取得せず離れた回数を記録します。境目の往復を重複計上しないため、18m以上離れた時に1回と数えます。取得範囲を広げる機能ではありません。
- コースのタイム・自己ベスト：全区間を終えた活動時間を端末内に保存します。探索と飛行、配置の違うコースは別々です。コピーには今回の秒数・ベスト・更新有無・保存成否も入ります。各AB直線で実際にABを使った時間も残します。
- 中立範囲は最大入力より1°以上小さくなります。通常3コースの翼の最大角度は初期値40°が上限です。高速空域は最大Gから旋回の上限を別に求めます。

## 元の早見表から合わせ直した点

開始の3・2・1には同じ短い合図、実際の発進には高い合図を使います。「音」または「効果音」がオフなら鳴りません。音量は「全体の音量」で調整します。最初の3が欠ける報告を受け、音源準備待ちの目安を250msから1500msへ延ばし、その後も数字3の前に最低0.5秒待つ形へ変更しました。待機中は「開始の準備をしています」と表示します。全画面案内を待っている時間とは重ね、二重に足しません。取消や画面離脱で合図を止め、通常の一時停止から再開するときは数え直しません。準備が期限に間に合わない場合は無音で進み、遅れた合図を後から鳴らすことはしません。

v0.1.21の早見表を元に、項目別の履歴/初期化、視野の実際の上限、回す方式の個別範囲、6m/s以下の旋回上限、振動パターン変更後の未確認を補足しました。機首を上げるだけで上昇が保証されるわけではなく、出力と速度も関係します。

外視点では現在高度と目標高度・差を右側にまとめ、操縦席では既存の高度計と上部の目標高度を使います。目的物の印にも上下の差が出ます。出口が低く視野に入っていないときは、「下に○m」の表示を目安に高さを合わせます。
