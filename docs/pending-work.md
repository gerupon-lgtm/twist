# 受領済みの後続作業

2026-11-09。v0.1.35は公開220ファイル・21項目、紹介の5条件と保存版7つの各4項目まで確認を完了した。[公開版](https://twist.sikumilab.com/?v=0.1.35)、[検証記録](verification-v0135.md)。v36以降はcache内の候補準備で、まだ未実装・未実行・未公開。各版の開始時に現状と資料を照合し、確認済みの版と準備中の版を分けて知らせる。

1. **v0.1.34：主旋律のギターアレンジと開始音（公開完了）。** [受領内容](instruction-guitar-solo.md)。元資料で確認した5曲に、利用者が明示指定したIgnition Skyを加えた6曲の主旋律だけをSCCのギターソロ風にする。提供MIDIは参考に限り、直接採用しない。既存の伴奏・他10曲は保つ。初期音源セットと、約1.5秒のGO音を鳴らしてからBGMへ移る追加指定も含む。
2. **v0.1.35：画面デザインとステージ導入の音（公開完了）。** [受領内容](instruction-visual-refresh.md)。配色とゲームの方向性を活かし、タイトル・選択・地図・クリア・操作部をSIKUMI LABの作品として整える。コピーは **Tilt to Play.** に確定。導入の線と目標到達音、前後の短いジングルも追加する。待機時間は増やさず、スキップ・消音を守る。実画面で確認する。
3. **v0.1.36：第3の旋回方式「手首」。** [資料](instruction-wrist-steer.md)。持ち方から推定した水平軸まわりの角度を測る。従来2方式と保存値を保持し、初期選択は自動変更しない。縦横・機首操作の混ざり・記録も検証する。
4. **v0.1.37：シエラ縦断1/50・コースのみ。** [資料](instruction-sierra-course.md)。提供された推定座標からA〜FとGの出口を追加する。今回は山谷の地形や標高データの取得は行わず、平地コースと地面高さの差込口を作る。元の3コース・飛行・取得半径を保持し、変換再現・旋回可能性・実入力完走を検証する。

ギターをv34へ挿入したため、準備済みUI以下を一つずつ順送りした。UI依頼を取り消したわけではない。手首とシエラは「現在対応中のタスクが全て落ち着いたら」との指定を保持し、先行版へ混ぜない。各版で実装・必要な試験・公開を確認し、Pixel 9aの未確認項目を資料に残す。未指定事項は安全側の仮決めと理由をまとめて記録する。

独立したSMF書き出し・ZIP納品は、GitHubから取得できたとの利用者の指示により不要。v33以前の完了記録は各版の検証資料へ保持する。

ステージテーマ別のBGMと、FMでのギター・ロックベース等の個別音色割当ては後続の方向性として受領済み。今回のSCCアレンジへ混ぜず、対応表や具体的な音色は未確定として残す。
