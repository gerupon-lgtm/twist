# 受領済みの後続作業

2026-11-08。v0.1.33は公開157ファイル・21項目、保存版5つの各4項目まで確認を完了した。[公開版](https://twist.sikumilab.com/?v=0.1.33)、[検証記録](verification-v0133.md)。以下はまだ未実装・未公開。各版の開始時に現状と資料を照合し、確認済みの版と準備中の版を分けて知らせる。

1. **v0.1.34：リードのエレキギターだけのアレンジ。** [受領内容](instruction-guitar-solo.md)。利用者がv33デプロイ後と指定した追加依頼を、次の公開単位に置く。ディストーションギターのソロ、チョーキング・ビブラート等を取り入れ、エレキギター以外は保持する。役割名leadだけで楽器を決めず、元の作曲資料で対象を確認する。
2. **v0.1.35：画面デザインとステージ導入の音。** [受領内容](instruction-visual-refresh.md)。配色とゲームの方向性を活かし、タイトル・選択・地図・クリア・操作部をSIKUMI LABの作品として整える。コピーは **Tilt to Play.** に確定。導入の線と目標到達音、前後の短いジングルも追加する。待機時間は増やさず、スキップ・消音を守る。実画面で確認する。
3. **v0.1.36：第3の旋回方式「手首」。** [資料](instruction-wrist-steer.md)。持ち方から推定した水平軸まわりの角度を測る。従来2方式と保存値を保持し、初期選択は自動変更しない。縦横・機首操作の混ざり・記録も検証する。
4. **v0.1.37：シエラ縦断1/50・コースのみ。** [資料](instruction-sierra-course.md)。提供された推定座標からA〜FとGの出口を追加する。今回は山谷の地形や標高データの取得は行わず、平地コースと地面高さの差込口を作る。元の3コース・飛行・取得半径を保持し、変換再現・旋回可能性・実入力完走を検証する。

ギターをv34へ挿入したため、準備済みUI以下を一つずつ順送りした。UI依頼を取り消したわけではない。手首とシエラは「現在対応中のタスクが全て落ち着いたら」との指定を保持し、先行版へ混ぜない。各版で実装・必要な試験・公開を確認し、Pixel 9aの未確認項目を資料に残す。未指定事項は安全側の仮決めと理由をまとめて記録する。

独立したSMF書き出し・ZIP納品は、GitHubから取得できたとの利用者の指示により不要。v33以前の完了記録は各版の検証資料へ保持する。
