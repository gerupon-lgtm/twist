# v0.1.53 変更内容

画面案の確認で確定したHUDと後方カメラを実装する。方位と上部の高度案内を画面中央へ揃え、レーダーは100×100のまま一段下の左側に置く。後方・操縦席で計器の位置を共通化し、速度・高度計は下寄りに配置する。短い縦画面と横画面では、実際の入力パネルと重ならない位置へ収める。

- 緑の数値、大きい文字の1px・小さい目盛の0.9pxの濃い縁取り、数値部分の白系20%の面、項目名と補助値の連続した濃色64%の帯を採用。A/B/Cを残し、円形は丸い面を維持する。
- 上部高度案内の内容は保持する。操縦席の現在高度と目標高度、後方視点の目標高度・高度差の案内を、方位と同じ中心に揃える。
- 後方の機体はカメラの表示方向を10度調整して下げる。縦画面では概ね上から6割の位置。旋回しても左右に流れないよう、機体の姿勢ではなくカメラ座標で調整する。機体を囲む薄い輪も追従する。
- 飛行中の視点ボタンは下部中央の「後方 ↔ 操縦席」。外から視点は開始時だけ選ぶ独立したモードとし、途中の切り替え対象から外す。画面操作のボタンが増える狭い画面では、視点ボタンを空いている下部領域へ収める。
- 横画面では後方カメラの高さも調整し、前方の案内の輪が上部の計器に隠れないようにする。横画面のB配置で画面操作を使う場合は、下端に計器を一列にまとめ、入力パネルと視点ボタンを避ける。小さい縦画面のB配置では計器を縮め、凡例をレーダーの右へ移す。
- 上部のナビゲーションは、案内の輪が表示可能かどうかに依存せず、共通の位置・大きさに保つ。小さい画面のシエラ1/50で、輪を置けない→上部案内が下がる→計器の場所が足りなくなる連鎖を解消する。
- 押下音の波形は維持する。古い押下音が残る期限を600msから、再生中の処理では200ms、休止からの再開では300msへ短縮。4音まで短く重ねて鳴らせるようにし、70msの音の途中の次のタップを捨てない。音の終了後は1.2秒待機してから音声処理を休止する。
- 初回のタップ前に無音で音声処理と波形の準備をする。再生の再開は実際の押下時だけ行う。タップ・キーの押下時に要求し、その後のclickで二重に鳴らさない。消音時は準備しない。
- BGMの試聴開始・終了を待ってから押下音を鳴らす経路を廃止。試聴と独立したゲーム側の処理で鳴らし、画面遷移や試聴終了で押下音の途中を切らない。消音・ページ非表示・破棄時は停止する。
- FMの出力だけを20%下げる。FMの音色の歪み・厚み・パート間の比率、演奏データは変更しない。PSGドラム、SCC側の音量は変更しない。

版・キャッシュ更新番号を0.1.53へ更新。公開確認済み0.1.52の本編33ファイルを、バイトを変えずに保存版へ追加する。
