# v0.1.23 実装範囲

v0.1.22（目標高度C・細かな振動・勇進の航路・保持した傾き・調整の履歴）は公開/検証済み。次の版として、続けて届いた依頼をまとめる。

1. 操縦席の見失い対策HUDに、次の目的物と位置が一致する中空の印、名前・距離・高さ差を組み込む。HUD表示域の外や後方は端の矢印で追う。旋回や機首の自動操作は加えない。ほかの視点とlegacyは既存の目標表示を保つ。
2. `instruction-exit-help.md`に従い、出口を黄色/白の交差する輪・遠距離の輪・地面からの柱で目立たせる。3個取得時の出口開放だけ新しい短い合図と表示を加える。位置と半径、既存の音/振動は保ち、legacyは元の出口を保つ。
3. 各調整項目の短い説明、困ったときの逆引き、初期値との差と変更一覧を加える。v0.1.22の項目別初期化/履歴は重複実装しない。Downloadsの`twist-settings-guide.md`も確認し、現行仕様に合わせた`docs/settings-guide.md`と画面から読める早見表を用意する。
4. 後から届いた直接依頼を優先し、既存曲を変えずにハードロック調の別曲を追加する。細かな刻みを減らし、ギター風のリード、伸ばす音、音程の揺れ、太い伴奏とドラムを使うオリジナル。従来曲/勇進/ロック/全曲を選択・記録できるようにする。SCC/PSGの計算とMIDI再生規則は変更しない。
5. 開始→光1、光1→光2、光2→光3、光3→出口の区間時間を記録/コピーへ含める。1回のルートごとに区切り、停止/センサー待ちは数えず、未完了の区間は未完了とする。最後の区間を出口の比較に使えるよう、結果にも表示する。
6. 大きな傾きで一時停止する制限を外す。最大入力を超える操作量は従来どおり制限し、読み取りにくい姿勢では直前入力を保持、戻せばそのまま追従する。無効なセンサー値・非表示・実際の画面回転の停止は継続する。
7. 現在高度の分かりにくさにも対応し、現在/目標/上下差を並べ、数字を大きくする。目的物が視野に入っていなくても、どれだけ上/下かを読めるようにする。

資料の停止/再開0という記述に対し、既に利用者が明示的に選んだ「停止0、手動再開50%・6m/s」を継続する。センサー許可、速度/高さの物理、取得判定、端末外への送信は変えない。今回の図は見え方の参考で、画像自体は公開物へ含めない。

版番号/キャッシュを更新し、位置投影/設定差分/曲の単体検証、3視点の出口、HUDと各画面寸法、開放の合図/目標切替、説明/逆引き/設定コピー、既存の回帰、本番ファイル/PWA/公開画面を確認する。実機の見つけやすさ・説明・曲の印象は未確認として残す。
