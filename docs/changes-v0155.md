# v0.1.55 変更内容

Overdrive HorizonのFM版の2パートの音色を変更する。

- 16分音符のシーケンスをパイプオルガン風へ変更。音の強さと倍音の変化を抑え、1オクターブ上の響きを重ねて、連続するフレーズに音の芯を持たせる。
- リードを厚みのあるブラス系シンセへ変更。発音の初めに明るい倍音を出し、軽い歪みと少し音程をずらした音を重ねて、割れるような質感を作る。
- 2つの専用FM音色を追加し、この曲の該当パートだけに割り当てる。音色割り当ての生成処理も同じ指定へ更新。
- 演奏データ、テンポ、音符・装飾、他曲の音色、ベース・和音・ドラム、SCC版、PSG、全体の音量設定は変更しない。

画面の版表示とキャッシュ更新番号を0.1.55へ更新。公開確認済み0.1.54の本編33ファイルを、同じバイトのまま保存版へ追加する。
