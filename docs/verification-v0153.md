## 確認した再現条件

- 修正前の押下音で、40ms間隔の2回目が無音になる、250ms遅れた再開後に鳴る、音の直後に毎回音声処理を休止する、の3条件を単体テストで再現した。
- ブラウザーの初回準備にも時間がかかるため、無音での準備を先に行う。再生中は200ms、休止からの再開は300msを超えた要求を再生しない。Windowsのブラウザー検証では、初回の再開が約170〜210msの場合があった。実機の可聴遅れは別途確認する。
- HUDの旧検証の「文字ごとの濃い下地を7以上の明暗差で読む」は、承認された新デザインでは変更した。数値は濃い輪郭と明るい文字の差、項目名などは連続した濃色帯との明暗差を検査する。面の透明度・文字の収まり・描画順の検査も維持する。
- 試聴開始ボタンで発音中の押下音を取り消す経路を、実ブラウザーの停止呼び出しで再現して修正。終了通知の時刻だけに依存せず、途中停止の呼び出しがないことも確認する。
- 小さい縦画面のシエラ1/50で、案内の輪が非表示になると上部ナビが下がり、レーダーと速度計が重なる条件を再現。上部ナビの位置・文字・ロゴの大きさを輪の表示可否から独立させた。

## レビュー

### Standards

仕様との一致とは別に、実装の不具合を確認。試聴開始で押下音を停止する経路、上部ナビの文字などの小型化条件の残りを指摘。修正後の読み取り再確認で、未解消の指摘なし。消音時に試聴側まで休止させる回帰も検証中に修正した。

### Spec

承認された配置・二択の視点切り替え・音量の変更範囲と比較。押下音の途切れと、ディレクター無効時の共通配置の不足を指摘し、修正後に解消を確認。仕様逸脱・未解消の指摘なし。実機での読みやすさや音量の好みは未確認のまま残す。

## Pixel 9aで確認してほしい点

- [ ] 後方視点の機体位置が下がり、前方の目標を追いやすくなったか。
- [ ] 後方・操縦席を切り替えても、方位・高度案内・レーダー・速度と高度の位置に違和感がないか。
- [ ] レーダーのサイズを保ち、照準の左右や地面が見やすいか。A/B/Cそれぞれで文字を読めるか。
- [ ] 下部の視点ボタンを押しやすく、ほかのボタンを誤って押さないか。
- [ ] 横持ちで、画面の上下に対応する上昇・下降、左右に対応する旋回が自然か。縦横を切り替えても向きがずれず、必要なら「持ち方」で合わせ直せるか。
- [ ] 最初の押下、短い連続押下、設定の開閉、BGMの試聴開始・停止で、押下音の遅れや途切れが改善したか。
- [ ] 消音・別アプリへの移動時に音が残らず、カウントダウンの3・2・1・開始音が鳴るか。
- [ ] FMの音量がPSGドラムに対して適切になったか。SCC側の音量に変化を感じないか。

端末のスピーカーやBluetooth経路で聞こえる遅れ、実際の音量の好みは、ブラウザーや計算上の検証とは分けて確認する。
