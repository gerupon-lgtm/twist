# v0.1.58 変更内容

Overdrive Horizonの68小節目を、承認済みの試聴と楽譜に合わせる。

- リードはA→G♯を各2拍。途中のEや短い追加音を残さず、2つの長い音にする。FM版のリードだけを1オクターブ下げる既存設定は維持する。
- 低音は1小節を通してE。元の8分音符の刻み・強さを保つ。伴奏は前半2拍Am/E、後半2拍Eとし、オルガンも同じ和音の構成音に合わせる。
- 曲の変更は共通のMIDIへ反映するため、SCC/FM両方に適用される。他の小節・ドラム・音色・テンポ・曲全体の長さは保つ。68小節目の変更は、曲全体の最後である72小節目への変更ではない。
- 1ファイルだけを書き込む入口と、元データから再生成して照合する処理を追加。未確認の編集を上書きせず、保存版への書き込みも拒否する。

画面の版表示とキャッシュ更新番号を0.1.58へ更新。公開確認済み0.1.57の本編33ファイルを、同じバイトのまま保存版へ追加する。
