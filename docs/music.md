# 曲と音源の設定

v0.1.33の仕様。確認・公開の進捗は[検証記録](verification-v0133.md)を参照してください。MIDIは音符・長さ・強さ・テンポの演奏データで、録音された音声ではありません。音色・音量・ループは `public/music/tracks.json` で決めます。

## 飛行中の曲と個別試聴

飛行中は黒曜の翼（rock）、鋼翼の鼓動（steel）、黎明の航跡（horizon）、嵐を越えて（storm）、Ignition Sky（ignition）、Steel Advance（advance）、Overdrive Horizon（overdrive）の7曲を採用します。ファイル名は各ID＋.midです。v34から初期選択はIgnition Skyです。「採用7曲を順番に」を選んだ場合は、飛び直しで次の曲へ進みます。一時停止からの再開は同じ曲の先頭からです。既に保存した明示選択とURL指定を優先します。

蒼穹突破（flight.mid）、遺跡の閃光（flight2.mid）、勇進の航路（brave.mid）は削除せず、個別試聴に残します。古い保存値やURLで指定しても、飛行中は採用7曲へ解決します。読み込むだけでは保存を書き換えません。

「個別試聴」はBGM10・クリア4・AB Pulse・比較の16曲を1曲ずつ選びます。曲集の試聴項目はありません。試聴の選択は別保存で、本編の曲選択・曲順・飛行時計・記録を変えません。音全体をオンにし、明示的に試聴します。BGM設定はオフのままでも聴け、全体音量とBGM音量を使います。

試聴中の曲／音源変更は先頭から再開します。クリア・AB・比較の試聴は1回で終わり、終了後の選択だけでは再生しません。停止・設定を閉じる・飛行再開・画面離脱で止まり、準備中の古い曲が後から鳴り出さないよう取消します。

## SCCとFM

初期値はSCC。FMを選ぶと、旋律・和音の明示パートだけを軽量な2オペレーター方式へ切り替えます。音を出す発振器と音色を変える発振器を組み合わせる方式です。低音SCC・打楽器PSG、MIDI・音符・テンポ・曲順・ABの拍は保ちます。次の再生から反映し、試聴中だけ先頭から再開します。

partsは1始まりのチャンネル番号です。roleはlead／chords／bass／drums、上物のfmPresetはlead／chords、低音・打楽器はnullです。曲ごとに宣言し、「4番は常に低音」とは扱いません。1〜8が旋律、10がPSGドラム。10を誤って上物にしてもPSGを保ちます。役割や音色のない旧自作曲はSCCへ戻し、理由を診断へ残します。

waveformはSCC用で0=矩形、1=のこぎり、2=三角、3=正弦、4=短いパルス。volumeは0〜127。MIDIの強さ、CC7音量、ノート開始・終了、±2半音の音高変更、CC120/123の即時停止を扱い、音量倍率を二度掛けません。プログラム変更・サステインは従来どおり解釈しません。

SCCは旋律を合計5音まで扱い、4番／5番が波形の置き場所を共有する制限も保ちます。FMは保持中の音と短い余韻が重なる数を再生前に調べ、実際の音声周波数と処理ブロックの余裕を含めて必要数を確保します。音符を削ったり、必要な音を黙って切ったりして収めません。

サエズリズムで確認した一般的な方式・停止管理・高音の変調抑制を参考にし、コード・音色表・数値はコピーせず独立実装しました。参照の固定コミットと範囲は[受領資料](instruction-bgm-fm.md)へ残します。技術上の発音確認と、実機で聴いた好みの確認は別です。

## クリア曲とAB

初期クリア曲「突破の凱歌」（clear.mid）を残し、新3曲を加えた4曲の明示選択です。

|曲名|ファイル|公称テンポ|長さ|
|---|---|---:|---:|
|凱旋の点火|clear-ignition.mid|165 BPM|約2.91秒|
|鋼の勝利|clear-advance.mid|145 BPM|約3.31秒|
|閃光の帰還|clear-overdrive.mid|175 BPM|約2.74秒|

少数の主旋律と長い終音を使う新作です。既存の旋律・リフ・MML列は抜き出さず、勇敢に開く・重い打点・速い帰還の違いを作ります。クリア曲は音＋効果音の許可を使い、BGMオフでも鳴ります。

AB Pulse（afterburner.mid）はAB中だけ次の拍から重なる追加打楽器。3秒以上保って小節の区切りで戻り、本編の曲は進め続けます。ひかりの航路（flight-legacy.mid）は比較用です。通常採用へ昇格せず、両方とも単曲試聴できます。

## MIDIを差し替えるとき

SMF形式0／1、四分音符あたりのtick（例480）で書き出します。SMPTEは非対応。旋律はチャンネル1〜8、打楽器は10のGM配置35〜81を既存のPSG音へ割り当てます。

同じ役割・長さ・ループ位置なら該当.midを差し替え、長さが変わる場合はtracks.jsonのloop.start/endも直します。開始を含み終わりの直前まで繰り返し、途中から始まる音・音量・音高は復元します。安全なmusic内の相対.midパスを使い、外部URL・絶対パス・../は使えません。日本語名と相対サブフォルダーは従来どおり扱います。

catalog.flight／preview／clear／afterburner／comparisonが用途の許可表です。旧flightPlaylist／flightSetsは保存値変換用で、新しい許可表より優先しません。catalogを持たない旧自作設定だけは、明示した旧曲順を読む互換処理を使います。壊れた新catalogを互換処理へ逃がしません。

元のMIDIは保存版v33へ保持します。v34の専用アレンジは `node tools/arrange-guitar-leads.mjs --check`／`--write` を使い、原本のハッシュを確認して許可した6曲の主旋律トラックだけを差し替えます。保存版への書込は拒否します。現行の他10ファイルと6曲内の伴奏トラックは原本のままです。

新3クリア曲の生成は `node tools/generate-clear-jingles.mjs --check`／`--write` だけを使い、許可した3ファイル以外へ書きません。通常buildは曲を生成しません。旧 `tools/generate-music.mjs` は13曲と旧設定を一括生成する歴史上の入口なので、現行設定へ不用意に実行しないでください。独立したSMF書出し・ZIP納品は、利用者がGitHubから取得できたため不要となりました。

## v34のギター表現と開始音

黒曜の翼・鋼翼の鼓動・黎明の航跡・嵐を越えて・Overdrive Horizonに、利用者が追加指定したIgnition Skyを加えた6曲の主旋律を対象にします。元のメロディーの弾き始めの音程を保ち、伸ばす音のチョーキングと狭い揺れ、短い独自の応答音を加えます。Ignition Skyの18小節目は、一つの持続音でC#5からE5へ上げます。提供された参考MIDIの音符や演奏データをそのまま採用していません。

SCCでは対象曲のpart1だけに `sccTimbre: "distortion-guitar-v1"` を付けます。従来の波形番号、音量、FM音色、他のパートは保ちます。4番／5番の物理的な発音場所は波形を共有するため、伴奏と場所を共有するときだけギター側を元の波形へ戻します。伴奏の波形や発音を変えてギターを優先する動作にはしません。SCCの音色表現であり、実物のギターやアンプを再現したものではありません。音色・奏法の好みは実機での聴取が必要です。

FMの既存音色定義は今回変えていません。FMでも同じ曲げ方の譜面を使いますが、楽器ごとの音色割当てとステージ別の選曲は後続の検討です。

個別試聴の初期選択は「閃光の帰還」、クリア曲は「突破の凱歌」。AB音楽とすれ違う音はオンです。開始の最後のGO音を約1.5秒鳴らし、実際に音が終わった後にBGMを始めます。飛行と記録はGOで始まり、3・2・1の間隔も保ちます。消音や効果音オフ、音を再生できないときは、聞こえない開始音のための待機は加えません。
