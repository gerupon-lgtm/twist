# MIDIの差し替え

曲は標準MIDIファイルなので、DAWで書き出したものへ差し替えられます。音色はMIDIの楽器番号ではなく、ひとつの設定ファイルで決めます。

## ファイルと設定

- 飛行中：public/music/flight.mid と flight2.mid（飛び直しごとに交互）
- 別案：public/music/brave.mid「勇進の航路」（設定で選択）
- 旧曲の比較：public/music/flight-legacy.mid
- ゴール：public/music/clear.mid
- 曲名・ファイル名・音色・音量・ループ：public/music/tracks.json

同じ長さ/ループ位置ならmidファイルだけ置き換えます。長さや繰り返す区間を変えるときはtracks.jsonも変更し、ビルド・版番号更新・公開を行います。画面の「計測」に表示される曲名と、設定/結果コピーのfeedback.musicで確認できます。設定ファイルや曲が見つからない/壊れた場合はBGMなしで遊べます。ゴール用MIDIも使えなければ、従来のPSGファンファーレへ戻ります。

ファイル名はmusicフォルダー内の相対パスにします。外部サイトのURLは使えません。flight/clearの両方を残してください。複数曲を使うときは、同じ形のflight2などを加え、最上位の `"flightPlaylist":["flight","flight2"]` で順番を指定します。省略すると従来どおりflightだけです。1〜8曲の範囲で、壊れた曲は順番から外して残る曲を使います。旧曲の比較は `"flightPlaylist":["comparison"]` に変えるだけです。自作曲の書き出し条件は共通です。loop.start/endは秒で、開始を含み終了の手前までを繰り返します。0.1秒以上、終了は最大3600秒。終了位置で音を止め、区間の先頭へ戻ります。開始が音の途中ならその音と音量/ベンドを復元します。最後の音の後の無音も、指定した終了秒まで含められます。

## DAWでの書き出し

SMF形式0または1、時間の単位は四分音符あたりのtick（例：480）で書き出します。SMPTE形式は非対応です。テンポ変更を含められます。

| MIDIチャンネル | 用途 |
|---|---|
| 1〜8 | SCCのパート1〜8 |
| 10 | PSGのGMドラム |
| 9・11〜16 | 鳴りません |

SCCは全パート合計で同時に5音までです。空きがなければ古い音から止めます。SCCの4番/5番の音は波形の置き場所を共有するため、異なる音色を5種類同時には鳴らせません。旧曲は最大4音。新曲はメロディ、分散和音、短い和音の音、ベース、遅らせたエコーの各1音で最大5音です。SCCの波形共有の制限はそのままで、新曲のベース/エコーは同じのこぎり波を基本にしています。PSGドラムは別の3音を使い回します。

partsのキーは1〜8と10です。waveformは0＝矩形波、1＝のこぎり波、2＝三角波、3＝正弦波、4＝短いパルス波。volumeは0〜127。MIDIのCC7音量を、この設定値に対する割合として使います。ベロシティ、ノートのオン/オフ、CC7、CC120/123、±2半音のピッチベンドを扱います。プログラムチェンジ/サステインペダルなどは使いません。チャンネル10ではwaveformを使いません。

例："1":{"waveform":4,"volume":96} は、パート1を短いパルス波・音量96にします。

## ドラム（チャンネル10）

| ノート番号 | 音 |
|---|---|
| 35・36 | バスドラム |
| 38・40 | スネア |
| 42 | 閉じたハイハット |
| 44・46 | ペダル・開いたハイハット |
| 49・57 | クラッシュ |
| 41・43・45・47・48・50 | 低い順のタム |

35〜81をGMの配置で扱い、近い音へ割り当てます。全対応はsrc/vendor/scc/engine/psg-drums.jsのDRUM_MAPにあります。ノートオフは使わず自然に減衰します。音程3音/ノイズの高さ1つを共有するMSX風の制限があるため、重なるドラムは最後の設定の影響を受けます。効果音は別PSGなので、効果音によるドラムの打ち切りやノイズの取り合いはありません。

## オリジナル曲と生成元

v0.1.20は「蒼穹突破」（160BPM・イ短調を基調・48小節・72秒）と「遺跡の閃光」（168BPM・ニ短調を基調・48小節・約68.57秒）。イントロ4小節、主題12、展開8、サビ16、静かな区間8です。リズム/音域/分散和音の密度/ドラムを区間ごとに変え、区切りにフィルを入れます。ゴールは「突破の凱歌」（160BPM・3秒）。手で書いた独自のフレーズで、既存曲の採譜/録音/特定作品の模倣は使いません。

飛び直した1回目は1曲目、2回目は2曲目、3回目は1曲目に戻ります。一時停止、持ち方の合わせ直し、画面操作/センサー切替では同じ回なので曲は変えません。新しい挑戦のリセットは1曲目へ戻ります。再開は同じ曲の先頭からです。再生した曲名/利用できた曲/飛行の回数はfeedback.musicへ残します。

v0.1.22では別案「勇進の航路」を追加しました。ホ短調・170BPM・48小節・67.764672秒。イントロ4小節、主題12、展開8、高い音域のサビ16、次へつなぐ8小節で、最後の区間でも低音の16分刻みを保ちます。音の切れ目、強弱、CC7による短い音量の減衰を加えています。添付された他者のMMLは、速い刻み・休符・短音と持続音・声部の重ね方といった一般的な構成の参考だけに使い、音符列・旋律・波形・設定値・MML自体は含めていません。従来の4曲は同じバイト列を保ちます。

「音と振動」→「飛行中の曲」は「これまでの2曲」（初期値）、「別案：勇進の航路」、「3曲を順番に」。選択を端末内に保存し、設定/結果コピーのfeedback.settings.musicSetとfeedback.music.musicSetへ記録します。`?music=brave`、`?music=current`、`?music=all`でその起動だけ指定できます。画面で選び直した場合は保存し、URLも更新します。曲名と実際に再生した名前は従来どおり記録します。

従来曲の順番・差し替えはflightPlaylistのままで変わりません。新しい任意設定 `"flightSets":{"brave":["brave"],"all":["flight","flight2","brave"]}` は別案・全曲のリストです。各リストは1〜8曲、曲の項目は今までと同じ形です。省略した古いtracks.jsonでもflightPlaylistを使います。別案が読めない場合は従来の利用可能な曲へ戻り、すべて読めなくてもゲームは続けられます。比較曲を従来側にするには、これまでどおり `"flightPlaylist":["comparison"]` だけを変えれば使えます。

旧「ひかりの航路」は比較用に45秒のまま残しました。元データはtools/generate-music.mjs。`node tools/generate-music.mjs` を明示実行すると5つのMIDIと初期tracks.jsonを再生成するため、自作曲へ置き換えた後は不用意に実行しないでください。通常のビルドではMIDI/音楽設定を上書きしません。

一時停止で曲を止め、手動再開で先頭から再生します。休止後の出発を分かりやすくするための判断です。接地/ゴールでも飛行曲を止め、接地音/ゴール曲を目立たせます。ゴール曲は効果音のオン/オフに従い、BGM用音源とBGM音量を使います。飛行BGMをオフにしてもゴールの通知は残ります。全体の音量/音のオフは両方に効きます。

Pixel 9aでの曲の聞こえ方、効果音との釣り合い、3D描画と同時の重さは未確認です。公開版での実機確認をお願いします。
