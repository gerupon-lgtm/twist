# v0.1.54 検証記録

公開前の検証中。実機の聞こえ方は未確認。

- 最終ソースの全単体861件が成功（129ファイル、最大5ファイルずつ26組）。

- 波形を生成する本物の処理で、44.1kHz・48kHzの両方について「6ms以内に最大値の80%へ到達する」を検査。修正前は2件とも失敗、修正後は成功。終了部分の静かさ・最大音量・長さの確認も維持。
- 修正後の関連単体11件、実ブラウザー7件が成功。ブラウザーに渡す実際の波形でも立ち上がりを検査し、初回と連続押下、消音、試聴の準備・終了、カウントダウンへの遷移を確認。
- 波形上の80%到達は約24.8ms→約1.5ms、最大値は約34.6ms→約3.8ms。これは音の立ち上がりの計測であり、タップからスピーカーが鳴るまでの時間ではない。
- 高度案内の本物の表示関数で、両視点の内容・現在高度・目標高度・高度差が同じになることを検査。修正前は失敗、修正後は成功。文字の見た目や収まりはブラウザーでも確認する。
- 開発版のHUD15件が成功。縦横3サイズ、A/B/C、後方・操縦席、シエラ、案内の無効時、数値2,592通りを含む。高度案内の内容が同じことに加え、現在高度が実際に見えること、両視点で字体・大きさが同じことを確認。
