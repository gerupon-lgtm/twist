# twist 次の版の指示：旋回が最大になるスマホの角度を、機首とは別に調整できるようにする

v0.1.16の作業中であれば、同じ版に含めて構いません。v0.1.16が公開済みであれば、v0.1.17として出してください。

## 背景（なぜ変えるか）

実機で操作した発案者から、次の報告がありました。

> かなりひねらないと最大の旋回が得られず、画面が見えづらくなる。少ないひねりで最大の旋回を入力したい。

今の作り（コードで確認済み）は次のとおりです。

- `steer=tilt`（ひねる）の旋回は、`flightRates` の中で、機首の上下と**同じ設定** `maxTilt`（初期値25度）を使っています。そのため、旋回だけを小さな角度で最大にすることができません。調整パネルで `maxTilt` を下げると、機首の上下まで敏感になってしまいます。
- `steer=twist`（回す）の旋回は、`CONTROL_LIMITS.twistMaximum`（32度）で固定されていて、調整パネルから変えられません。
- スマホを左右にひねると、画面を見る角度も変わります。ひねる量が大きいほど画面は見えづらくなります。

## やること

### 1. 旋回専用の設定を追加する

調整パネルに、次の設定を追加します。

| 設定 | 意味 | 初期値 | 範囲 |
|---|---|---|---|
| 旋回が最大になるひねり（`maxSteerTilt`） | `steer=tilt` で、翼が最大角度になるスマホの左右の傾き | **15度** | 5〜30度 |
| 旋回が最大になる回し（`maxSteerTwist`） | `steer=twist` で、翼が最大角度になる面内の回転 | **20度** | 8〜40度 |
| 旋回の中立範囲（`steerDeadzone`） | 旋回だけの中立範囲 | 3度（ひねる）／5度（回す）の今の値 | 0〜8度 |

- 既存の `maxTilt` は、**機首の上下専用**にします。表示名を「機首が最大になるスマホの傾き」などに変えて、旋回には使わないことが分かるようにしてください。
- 中立範囲の設定を旋回用に分けるかどうかは、パネルが分かりにくくならない範囲で判断して構いません。分けない場合は、理由を記録してください。
- 端末に保存済みの古い設定を読み込んだときは、新しい項目を初期値で補ってください。

### 2. 小さな角度でも細かく操作できる工夫（任意の設定）

最大の角度を小さくすると、中立付近の細かい調整が難しくなる可能性があります（推測）。そのため、効き方の曲がり具合を選べる設定を加えます。

- 「旋回の効き方のカーブ」（`steerCurve`）：初期値1.0（今と同じ直線）、範囲1.0〜2.0です。
- 値を大きくすると、中立付近はゆるやかに、最大付近で急に効くようになります。
- 初期値では今の直線と同じ動きになるようにしてください。

### 3. 記録

- 記録とコピーに、新しい設定を含めます。
- 選んでいない旋回方式の設定（`steer=tilt` のときの `maxSteerTwist` など）は、`inactiveSettings` に入れます。

### 4. 版番号・記録

- README、`docs/verification-v01xx.md` に、「旋回と機首の最大角度を分けた理由」を記録します。

## 変えないもの

- 機首の上下の動き（`maxTilt` の初期値25度、`maxPitch`、追従の時定数）。
- 翼の最大角度（`maxBank`）と、翼の傾きから旋回の速さを決める計算。
- 物理計算、表示モード、視点、レーダー、探索モード。

**補足**：最大までひねっても旋回がゆるいと感じる場合は、入力の角度ではなく、旋回の強さ（翼の最大角度や旋回の計算）の問題です。今回は入力の角度だけを変え、旋回の強さは変えません。必要になったら別の版で扱います。

## テスト

- 単体テスト：
  - `maxSteerTilt` を15度にすると、左右の傾き15度で翼が最大になり、機首の上下は `maxTilt`（25度）のままであること。
  - `maxSteerTwist` が `steer=twist` に効くこと。
  - `steerCurve=1.0` で従来の直線と一致すること。
  - 古い保存設定を読み込んでも、新しい項目が初期値で補われること。
- ブラウザーテスト：調整パネルで新しい設定が変えられ、保存・初期化・コピーに反映されること。
- 既存のテストはすべて通ること。
- スマホ実機での操作感は「未確認」として記録に残してください。

## 判断の範囲

**発案者（田中）の指示で変えてよいもの**
- 初期値、範囲、設定名、パネルでの並び順、カーブの計算方法。

**変えないもの（指示があっても確認してから）**
- 端末の外へ情報を送る処理の追加（設定と記録は端末内だけで扱う）。
- センサーの許可の取り方と、停止・再開時に速度と出力を0へ戻す安全側の動作。

分からない点や、この指示どおりでは難しい点があれば、勝手に範囲を狭めずに、理由を書いて質問してください。
