# twist 次の版の指示：出口を見つけやすくする／調整パネルに説明を付ける

「C. 次の目標の高さを示す目印」の作業とは別の指示です。Cが終わってから、その次の版として出してください。

## 背景（なぜ直すか）

発案者の実機での感想は、次の2点です。

1. 「出口が視覚的に見つけづらく、何度も通り過ぎてしまった」。その回は、最後の1回に約455秒かかり、復帰補助も約21秒働いていました。出口を探して低い高度で旋回を繰り返し、失速しかけたと見ています（推測）。
2. 「かなり遊びやすくなった。ただ調整が細かいので、どの部分をどうすればどうなるかが分かると嬉しい」。

### 出口の今の作り（コードで確認済み）

- `stage.js` の `exitGroup` は、細い輪（`TorusGeometry(3.1, 0.15)`）が1つあるだけです。
- 色は青緑（有効時 `guide` = `0x117f97`、無効時 `dimGuide` = `0x8ebfc5`）で、空の水色に溶けやすい色です。
- 光（目標）に入れた見やすさの対策（v0.1.15：目立つ色、画面上で小さくなりすぎない光の輪、地面から立つ光の柱）が、出口には入っていません。
- 輪は一方向を向いています。横や斜めから見ると細い線に見えます。取れる判定は半径4mの球（`EXIT_RADIUS`）なので、輪の向きとは関係なく通れます。
- 高さは7mと低く、地面の模様にも紛れやすい位置です。

## やること

### 1. 出口を見つけやすくする（`view=assisted` のとき）

- **色**：光のマゼンタ系とは区別できて、空の水色・地面の茶色・遠景とも混ざらない色にします（例：明るい黄色や白に近い色）。
- **どの方向からも見える形**：輪を2〜3枚交差させた形、または遺跡の門の形にします。今後の浮島と遺跡の世界にも合わせられる見た目が望ましいです。
- **遠くでも見える工夫**：光と同じように、画面上で小さくなりすぎない光の輪と、地面から立つ光の柱を付けます。
- **出口が開いたことの合図**：3つ目の光を取った瞬間に、出口の見た目をはっきり変え（光る・脈打つなど）、短い音と画面の表示で「出口が開いた」と知らせます。
- **画面端の目標マーク・レーダー**：出口が次の目標のときも、光と同じくらい目立つ表示にします。
- 取れる判定（`EXIT_RADIUS`）と出口の位置は変えません。
- `view=legacy` の出口は、従来のまま残します。

### 2. 調整パネルに説明を付ける

発案者向けの早見表（添付の `twist-settings-guide.md`）を、リポジトリの `docs/settings-guide.md` として置き、画面からも読めるようにします。

- **各設定の短い説明**：調整パネルの各スライダーに、「上げると〜／下げると〜」を1〜2行で表示します（タップで開く、または常に小さく表示）。文言は早見表の表を元に、画面の幅に合わせて短くして構いません。
- **困ったときの逆引き**：調整パネルの中に「こう感じたら」の一覧を開けるようにします。項目をタップすると、該当するスライダーへ移動して強調します。
- **初期値との差**：初期値と違う値になっている設定には、印と初期値を表示します（例：「初期値 15°」）。1つだけ初期値に戻せるボタンもあると便利です。
- **1つずつ変える案内**：調整パネルの冒頭に「1回に変える設定は1つだけにすると、効果を比べやすい」と短く表示します。
- 早見表の内容が実装とずれている箇所があれば、実装に合わせて早見表を直し、直した点を記録してください。

### 3. 記録

- 記録とコピーに、初期値と違う設定の一覧（例：`"changedSettings":["maxSteerTilt","maxBank"]`）を追加します。どの設定を変えた記録かを、ひと目で分かるようにするためです。

### 4. 版番号・記録

- 版番号を上げ、README と `docs/verification-v01xx.md` を更新します。

## 変えないもの

- 出口の位置と取れる判定、光の位置と取れる判定。
- 操縦の入力、物理計算、各設定の初期値と範囲。
- 音・振動・BGMの内容。

## テスト

- 単体テスト：初期値との差の判定、`changedSettings` の作成、1つだけ初期値に戻す処理。
- ブラウザーテスト：
  - 3つ目の光を取ると、出口の見た目が変わり、合図の音と表示が出ること。
  - 出口が横・斜め・遠くから見えること（3つの視点で確認）。
  - `view=legacy` では出口が従来のままであること。
  - 説明の表示、逆引きからスライダーへの移動、初期値の表示と戻すボタン。
  - 390×844・360×640・844×390で、説明が切れたり、ほかの表示と重なったりしないこと。
- 既存のテストはすべて通ること。
- 実機での出口の見つけやすさと、説明の分かりやすさは、Pixel 9aでの確認を「未確認」として記録に残してください。

## 判断の範囲

**発案者（田中）の指示で変えてよいもの**
- 出口の色・形・大きさ・光り方、合図の音と表示。
- 説明の文言、表示のしかた（常時・タップで開く）、逆引きの項目と並び。
- 実装方法（より良い方法があれば、理由を記録して採用してください）。

**変えないもの（指示があっても確認してから）**
- 出口・光の位置と、取れる判定の大きさ。
- 端末の外へ情報を送る処理の追加（設定と記録は端末内だけで扱う）。
- 開始ボタンを押す前に音や振動を出すこと。
- センサーの許可の取り方と、停止・再開時に速度と出力を0へ戻す安全側の動作。

分からない点や、この指示どおりでは難しい点があれば、勝手に範囲を狭めずに、理由を書いて質問してください。
