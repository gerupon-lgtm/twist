# v0.1.11 旋回表示と急落報告の確認

2026-11-07。ユーザーから左右旋回中の急落と、機体表示が逆方向を向く報告。飛行機の表示について「右旋回なら右へ傾く」へ変更する回答を得た。従来の物理的な向き固定は飛行機では変更し、探索に残す。

## 確認済み・未確認

- 表示の逆向きは再現済み。右への旋回入力に面内回転も混ざると、旧表示はスマホ回転の逆補正で機首が画面左へ向いた。ブラウザーの新試験は修正前に機首の横方向成分-0.321で失敗し、修正後は旋回側へ向く。
- 実ステージで出力50%、前後入力なし、翼20度/40度を20秒継続したが急落しなかった。40度の例は高さ7mから約3mへ徐々に下降し、最大下降は約0.265m/sだった。軽い高度低下は飛行計算で起きる。
- 翼40度に前倒し約5度相当の入力を重ねると、機首が下がり続け約6.9秒で接地した。手前への約5度相当を継続する別条件では、上向きにした後に速度を失って下降し、表示の俯仰変化が最大約39度/秒に達した。これらはPCで作った条件であり、今回の実機操作だったとは断定しない。
- 急落そのものの実機原因は未特定。確認範囲から外さず、次回の直前状態を読めるようにする。

## 変更

- 飛行機の描画は実際の翼の傾きを使い、右旋回で右へ、左旋回で左へ傾く。スマホの逆回転補正は探索だけに使う。飛行機の入力と表示の基準が異なる点を説明文へ反映。
- 表示の目標と実際の表示を分け、回転を毎秒30度、表示位置の変化を毎秒3m以内に制限。初期化・リセットだけ目標へ直接合わせ、休止時には表示を保持する。
- 接地直前の最後の飛行フレームの出力・機首・下降速度・前後入力を、停止でゼロにする前に記録。停止画面に表示する。前後入力が中立でも、保持されている機首角度で下降し得ることを読み取れる。
- 飛行の力の計算は今回変更しない。原因未確認のまま自動高度維持を加えたことにはしない。接地0mと地面を見る補助は継続。
- 版番号・favicon・設定URL・package版を0.1.11へ更新。
