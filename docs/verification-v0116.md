# v0.1.16 視点・操縦席HUD・オリジナル機体

2026-11-07。[提供指示](instruction-v0116.md) と作業中の[追加指示](instruction-steer-angle.md) に基づく。追加指示により、旋回の入力角度は従来維持から変更。機首angle標準・rate比較、bank/fixed併存、飛行物理・復帰補助・探索・レーダー・光・legacyは継続する。停止/再開は前回の明示回答を優先し、停止0・手動再開50%/6m/sを維持する。

## 実装判断

- `camera=overlay|chase|cockpit`。未指定はoverlay。開始・休止時に切替可能。切替は飛行の位置・姿勢・速度・出力・進捗を変更しない。探索は選択を保持しても有効視点はoverlay。
- overlayは従来の世界変換と視点補助を保持。旧bankのv0.1.13比較データとも一致する。飛行機の上面模型だけ新形状へ変更し、探索の旧模型は保持。
- chaseは実際の世界内に機体を配置。機体基準で後ろ25m・上9mの見る位置を、上下/左右の向きだけ指数的に追従。初期0.15秒、0〜0.5秒。半回転境界は短い方へ。見る位置の高さは地面上1.2m以上に制限し、低空/下降の従来補助の強さに応じて上へ2m補う。物理的な位置には制限を追加しない。
- bankでは実姿勢の模型、fixedではカメラから見た機首方向を保ちつつ模型の画面内ロールを取り除き、実bankを景色へ入れる。さらに既存の本体回転/画面方向の補正を適用。操縦入力のならしは追加しない。
- cockpitは機体から上0.3m・前0.8mの見る位置で実姿勢を使用。模型は両場面で非表示、地面の視点補助0。fixedのスマホ面内補正は引き継ぐ。地平線/5度線/進行方向は実描画のworldとcameraの回転、実FOVから透視投影する。速度/高度/方位/出力/警告/ボタン/レーダーは画面固定。
- 有限の床の終端を地平線と取り違えないよう、新2視点だけ眼の周囲に下半球の地面色背景を描く。地平線は世界の水平面の消失線と一致する。overlay/探索の世界は変更しない。接触と境界は従来どおり。
- HUDは緑・暗い縁。中央の表示域は上のナビ/方位、左右の速度/高度、下の出力/操作を除外。画面端マークの周囲も切り抜く。下の旧入力角度は省略し、出力スライダーとボタンを保持。説明トーストは操縦席では視覚表示を透過させ、警告/復帰はHUDへ集約する。進行方向が画面外/背後なら内側の縁に「進行」と表示。極小速度では進行方向印を出さない。
- 双発・外傾双尾翼・張り出し・長い機首・泡状キャノピー・後退翼・水平尾翼を基本形状から生成したオリジナル。上面/立体で同じ生成処理。明灰/暗紺、2つの青白い噴射は出力で長さ/明るさ変化、0で消灯。外部模型・実在名称/標章/番号なし。
- `camera`と`chaseTimeConstant`をコピーに追加。追尾以外は未使用。既存端末設定を保持して新値だけ補完。新しい通信/計測送信を追加しない。版・favicon・package・URLを0.1.16、JS/CSSは内容ハッシュで更新。

## 旋回入力の追加指示

- v0.1.16公開前に受領したため同じ版に含める。大きく左右を倒すと画面を見づらい、という本人報告から、機首の最大入力角度maxTilt初期25を旋回から切り離す。maxSteerTilt初期15（5〜30）、maxSteerTwist初期20（8〜40）。翼の最大角度とbank→旋回の計算、飛行の力、表示、探索は変更しない。
- 中立は機首からも分離。ひねる3・回す5という既存の初期値を同時に保つため、単一steerDeadzoneの代わりにsteerTiltDeadzone/steerTwistDeadzoneを別保存（各0〜8）。調整パネルには選択方式の2項目のみ表示して項目数を抑える。中立が最大角度以上になる矛盾は、最大入力角度を優先し中立を最大−1度へ補正し、実際の補正後の値を表示/保存/コピーする。
- steerCurve初期1、1〜2。中立を引いた0〜1の入力の絶対値をこの指数で曲げ、符号と最大翼角を保つ。1は同じ直線、2は中立近くを細かくする。入力メーターも新しい最大値を使う。未選択方式の最大値/中立はinactiveSettings、探索は全飛行設定を未使用にする。旧保存値は保持し、新項目のみ初期値を補完。
- 過去の入力応答テストは旧最大角度25/32を明示して継続し、新初期値15/20・独立性・カーブ・移行は追加試験で確認する。
