# v0.1.1 検証記録

2026-11-07。新しい操作と自機の向きの補正、空中の目印を対象にする。
仕様・ユーザーの選択・実装判断は [操作改訂](control-update-v011.md) を参照。

## 確認済み

- Node.jsの計算テスト18件が成功。任意の開始姿勢・平面・ほぼ垂直・複合回転・画面の縦横で、端末姿勢と自機補正の積が開始姿勢と一致する。
- 加速・中立での速度維持・ブレーキで0へ減速・上限速度・後退しないことを確認。前後と左右・ひねりの同時入力を含む。
- Edgeのブラウザーテスト10項目が成功。新しい操作を画面つまみ・PCキー・疑似センサー通知で確認。
- 実際の描画グループへ、回転を打ち消す値が渡ることを確認。カメラと自機の中心位置は固定し、周囲の移動・旋回を継続。
- 一時停止・再開・基準合わせ待ちの取消・データ欠落・データ停止・画面の縦横変更・非表示での停止を確認。再開時に以前の速度は復元されない。
- 高さ10m・18m・12mの収集物を順に取得し、出口へ到達できることを確認。
- 390×844・360×640・844×390で開始ボタンと横はみ出しを確認。
- ビルド成功。画面とpackageの版は0.1.1、JS/CSSは変更内容ごとのハッシュ付きファイル名。ホームURLとアイコンにも版を付与。

実画面の確認で、近い立体の道しるべが大きくなり目的物を隠すことが分かった。画面上4pxの点に変え、周囲の六角輪を薄く細くして目的物との区別を保つ。

## 実機で確認すること（未確認）

疑似入力での成功を実機確認として扱わない。下記も検証範囲に残す。

| 操作 | 確認点 |
|---|---|
| 自然な持ち方で開始 | 許可・基準合わせができ、自機の基準となる上向きが意図に合うか |
| スマホを左・右・平面で回す | 人から見た自機の上向きが保たれるか |
| 上部を下へ倒す | 徐々に加速し、倒し量で強さが変わるか |
| 前後を基準へ戻す | 速さを保ち、手ぶれで加速・制動しないか |
| 上部を上へ起こす | 制動し、0になっても後退しないか |
| 左右傾き・ひねりを同時に使う | 左右・上下の進路と速度を扱いやすいか |
| 空中を旋回・探索 | 目印で高さ・奥行き・位置を把握しやすいか |
| 持ち直し・別アプリ・縦横回転 | 停止して新しい基準から再開できるか |
| 数分間遊ぶ | 方角のずれ・酔いやすさ・実機の描画速度・発熱 |
