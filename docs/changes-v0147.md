# v0.1.47 変更内容

## 機体とタイトル

参考写真の細い胴体、尖った機首、後退翼、双発エンジン、双尾翼、青と灰色の塗り分けをゲーム用の手続き形状へ反映した。タイトルはv0.1.46の生成画像を保持する。[画像と生成指示の記録](title-aircraft-v0146.md)。今回のゲーム内モデルとタイトルの目標・出口はコードで描画する。

- 機体は1184個の固体頂点。排気口を黒い奥面で閉じ、左右のエンジンと炎の中心を揃えた。
- 固体の新しい形から44点の凸形状を作り直した。接触用IDはsolid-hull-v2。外形の最大幅・長さ・高さは従来と同じ範囲。128姿勢で表示頂点と地面への最接近位置が一致する。
- タイトルの目標は、淡い輪・ひし形・中心の光で表現。出口は奥行きのある金色の二重の門にした。

## 開始音とボタン音

「3」の直前に小さな音がするとの報告を、初回・取消後・飛行後で調査した。旧版のゲーム音声処理の準備区間は全て無音だった。一方、数字をDOMへ書いた直後、画面の描画機会より約21～26ms早く開始音を要求していた。これは要求順序の確認であり、実機で聞こえた音の原因を確定するものではない。

数字を表示し、2回の描画予約と次の処理機会を経てから音を要求する。取消・非表示・次の数字に進んだ場合は古い音を捨てる。3秒のカウント、開始後の約1.5秒のGO音、実際のGO音終了後にBGMを始める流れは保つ。

ボタンには約70msの柔らかいPSG音を追加。音量は全体音量に従い、効果音オフ・全体消音・音量0では鳴らない。実際のタップ／キーボード押下だけで鳴らし、内部処理によるclick、調整ゲージ、選択欄の変更では鳴らさない。連打は重ねず、音声起動が600msを超えた音は後から再生しない。実測では初回の音声起動と画面処理に約421msかかる条件があり、それを含めた上限としている。

ボタン自身が押下直後に無効になる場合も、押す前の有効状態で判定する。実際の音声再開はボタン処理の後、同じ操作イベント中に行う。開始ボタンの音は「3」より300ms以上前に終了することを別途確認した。

前提の変更：音の利用を許可する操作が、飛行開始だけでなく実際のメニューボタンにも広がる。ユーザーのボタン効果音追加の指示による変更。飛行音と同じAudioContextを使い、別の音声コンテキストは増やさない。PSG本体、BGM演奏データ、SCC/FMの音色は変更しない。

## 音速前の白い霞

画面端の四角い面が白い帯に見えるため、音速前の霞を薄くし、内側から外側へなめらかに濃くなる描き方へ変更した。音速突破時の二重の波・中央を避けた霧・後方の炎は保つ。中央の視界を空ける範囲も保つ。

機体の形に合わせた接触形状以外は、速度・旋回・入力・コースの条件を変えていない。

接触形状も自己ベストの条件に含める既存の規則により、高速空域とシエラ1/10の自己ベストは新しい条件で集計される。以前の条件のデータは保存したままで、通常コースの記録は変わらない。
