## 修正前の再現

`npx playwright test --grep 'layout-only|recentering the controls' --reporter=line` で画面角だけの変更によりrunning→paused、速度0となることを確認した。
再中立後の検証では描画の反映を待つようにしたうえで `npx playwright test --grep 'recentering the controls' --reporter=line` を実行し、自機補正のz成分が期待値-0.258819ではなく0へ戻る失敗を確認した。

旧版の単独回転後の傾き判定は既に自機基準の一部を満たす。複合傾きの差と基準の消去を対象に修正しており、実機での原因すべてを特定したという意味ではない。

## 計算の確認

- Node.jsのテスト30件が成功。
- 平面0/±45/±90/180/360度、斜め・任意の開始姿勢で、見える先端側・逆側・左右を下げる操作を確認。
- 複合傾きから見える先端側へさらに10度倒すと、その方向の傾きが10度変わることを確認。
- 自機の描画基準と、操作の中立基準を分けた状態、画面角だけの変更、無効値・真横・裏向きの停止用結果を確認。
- 半回転の境界でひねりの上下旋回が急反転せず、半回転・一回転で中立となることを確認。通常の小さいひねりの反応は維持。

## ブラウザーと公開の確認

- Edgeのブラウザーテスト15項目が成功。修正前に失敗した縦横切替と再中立の2項目も成功へ変わった。
