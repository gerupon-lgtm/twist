# v0.1.4 加減速調整と検証記録

2026-11-07。ユーザーの「探索も同じで、加減速の強さが最大になるまでの動きを小さくしたい」という依頼を受け、両モードとも12度で試す。中立で自動ブレーキをかける変更ではない。

## 今回の仕様

| 項目 | 探索モード | 飛行機モード |
| --- | --- | --- |
| 加減速の操作 | 自機の先端側へ倒すと加速、逆側で制動 | 右ひねりで加速、左で制動 |
| 最大の強さに達する角度 | 25度 → 12度 | 32度 → 12度 |
| 加減速しない中立範囲 | 前後の各3度以内を維持 | ひねりの左右各5度以内を維持 |

中立範囲を出てから12度まで、角度に応じて加減速を強くする。12度以上でも上限を超えない。12度は加速・制動の強さが最大になる角度で、最高速度に即座に達する意味ではない。

最高速度10m/s、最大加速3.5m/s²・最大制動6.5m/s²を維持する。中立で今の速度を保ち、反対側へ操作すると制動して0で止まる。後退はしない。機首・旋回の感度、飛行機の手動開始・再開時6m/s、停止時0も継続する。

## 確認済みの前提と未確認の原因

[controls.js](../src/controls.js) の読取で、既存の計算は中立で加速量・制動量とも0となり、現在速度を保つことを確認した。制動は反対側の入力から計算される。

実機で、中立へ戻す操作に伴う減速が起きているかどうかは未確認。もし起きる場合、戻す途中で反対側の制動範囲へ越える可能性は仮説であり、原因と断定しない。今回の角度調整だけで、その現象が解消したとも扱わない。

- 既存の自機基準、画面回転、姿勢の取り直し、安全停止、飛行機の旋回、空中目標と出口、縦横のスマホ寸法も成功。案内と両モードの12度入力時の画面を画像で確認。

- 読取レビューでも、12度の適用対象・中立・方向・メーター・版情報に確実なP1/P2の指摘はなかった。

上記はPC上の計算・疑似入力の結果。スマホ実機の感触を確認したものではない。

確認する内容:

- 両モードの加速・制動が12度で最大、途中では段階的に増え、12度を超えても上限を保つこと。
- 中立範囲で加速・制動とも0となり速度を維持し、反対側で制動しても後退しないこと。
- 最高速度・最大加速・最大制動、機首・旋回の反応が従来どおりであること。
- モード切替、開始・再開、停止、操作案内と表示、空中目標・出口への到達。
