# v0.1.38 手首設定の反応表示・FM全旋律化

2026-11-09。公開済みv37（605e90a）を基準に作業。公開確認はまだ未完了。

手首感度の3ボタンは数値を変更していたが、選択状態を表示していなかった。タッチ後の値・保存・項目ごとの履歴を保持し、選択中のボタンを青緑にし、現在の感度名と最大入力角度を表示する。手動角度が3候補と異なる場合は「カスタム」と表示する。同値を押して履歴を増やさない既存動作は保持した。

FMは従来、旋律と和音だけを鳴らし、ベースをSCCへ残していた。今回は全16曲のドラム以外をFMへ送る。チャンネル10のドラムは従来のPSGを保持する。6曲の既存ギター主旋律には専用のdistortion-guitar、ベースにはbassを割り当てる。ほかのリード・和音のFM音色は保持する。2つの発振器による音色に緩やかな歪みと高音を整える処理を加えた、エレキギター風の音であり、生楽器の再現性や実機の聴感まで数値試験で保証しない。

FMの保持音・余韻数は再生前に全パート分を数え、128音を超えた場合に黙って音を奪う方式へ変更しない。採用全16曲に必要な全音符がFMへ届くこと、ドラムが元経路へ届くことを別試験で照合する。MIDI・テンポ・音符・曲順・SCC設定・飛行・コース・入力計算は変更しない。SCCモードが初期値であることも保持する。

割当ての生成は `node tools/assign-fm-voices.mjs`。クリア曲の生成器でもベースをbassへ統一した。設定の説明・公開ガイドを新しい範囲へ訂正する。版・HTMLのリンク・画面表示・PWA・公開versionをv38へ更新する。v37の公開済みルート32ファイルを当時の公開応答とSHA照合済みの原本から保存版へ追加し、既存保存版は書き換えない。

コース説明は今回3つの画像案を作成した。[構図案と前提](design/briefing-20261109/README.md)、[生成プロンプト](design/briefing-20261109/prompts.json)。初回案は派手すぎるとの指定を受け、Aの方向を基本に、現行地図のパーツ拡大と機体の順路通過へ絞った独立の動く見本を追加した。`previews/briefing-simple.html`へ置き、本編の説明画面・タイトル・クリアは変更しない。見本は実Sierra50の地点・高度を使い、一様な拡大率でルート形状を保つ。再生成は`node tools/build-briefing-preview.mjs`。最後のbuildは本編32ファイルが追加前と完全一致し、見本HTML1ファイルだけが増えた33ファイルである。音声/負荷測定を新しい音源へ差し替えて偽るものではなく、同じ32バイトの証拠と、追加ページの試験を分ける。

確認済みと実機での未確認項目は[検証記録](verification-v0138.md)に分ける。
