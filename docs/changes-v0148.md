# v0.1.48 変更内容

## 音速突破の振動

Androidの振動機能は振動する時間と間隔を指定する仕組みで、モーターの強さそのものを数値指定できない。Pixel 9aで衝撃を感じやすくするため、音速を上向きに超えた際を「280ms振動・45ms休止・200ms振動」の計525msへ変更した。振動の設定倍率は引き続き反映する。音速を下回る際と爆発音の長さは従来通り。

光の取得直後でも突破の衝撃を鳴らし、直後の取得振動で途中終了しないよう優先順位を調整。地面・失速などの警告とクリア・衝突は引き続き優先する。停止・画面非表示・振動オフで取り消す。

参考：[W3C Vibration API](https://www.w3.org/TR/vibration/)。ブラウザーからの要求と、実際の端末で感じる強さは別に確認する。

## 継続する風

高速空域とシエラ1/10に、画面の外周を長く流れる風を追加。従来の放射状の線も太さと本数を増やし、最大48本のうち16本が長い風になる。淡い青から白へ変化し、中央の視界を空ける。シエラ1/10は少し控えめな強さにする。

音速前から増え、音速を超えて680m/sに向かう間も強まる。速度が変わっても線が飛ばないよう、経過時間とその時点の流速を足し合わせて移動させる。長時間飛行後の加速でも同じ動きになる。描画用の領域を使い回し、フレームごとの形状追加はしない。動きを抑える設定は維持する。v47で薄くした音速前の霞や突破時の衝撃波は保つ。

## 速度・加速のSE

BGMを残したまま、速度に合わせて高さと脈動が変わるPSGのエンジン風SEを追加。加速中は実際の速度変化から滑らかにせり上がり、一定速では落ち着く。最初の速度や停止からの再開を加速と取り違えない。

設定に「速度・加速のSE」を追加し、初期状態はオン。以前の音量・BGM・振動などの保存設定は保持する。警告・取得・音速突破・すれ違い・案内・開始音などを優先し、上昇下降の音が鳴る間も小さくする。BGMとは別の音声チャンネルを使い、曲・音色・SCC/PSGの本体は変更しない。

設定変更後に飛行を再開すると以前の音設定を送り直す可能性があったため、再開用に保持する設定も更新する。効果音オフ・消音・停止時に古い設定で再開しない。

全体検証で追加SEの鳴り始めにABの低い音を弱める組み合わせを確認し、ABの音量を下限にして修正。従来のAB音と減衰は追加SEオフで保持を検証し、オンでも鳴り始めとAB終了時に既存の音量を落とさない別検証を追加した。追加SEオンでは、ABを切った後も速度に応じた音は続く。

## 開発環境と版

開発用サーバーが生成した検証ページや保存版まで広く探索し、初回のHTTP応答が止まる状態を確認した。該当する2個の開発用Nodeプロセスだけを確認して終了。探索の入口を本編のindex.htmlへ限定し、検証用キャッシュと保存版の変更監視を除外した。標準の起動コマンドで約287msの起動表示とHTML取得を確認した。ユーザーのファイルは削除していない。

画面の版・manifest・更新確認・生成ページを0.1.48へ更新。公開済み0.1.47の本編33ファイルを変更せず保存版へ追加。飛行の速度・旋回・入力・機体・コース・記録条件・BGM演奏データは変更しない。
