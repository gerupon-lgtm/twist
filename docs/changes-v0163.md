# v0.1.63 音速前後の音と振動

2026-11-13。BGMと計器の合図を残し、音速突破後の外の音を抑えるゲーム演出。

- マッハ1以上では風・通常エンジン・ABの連続音をほぼ静かにし、速度・加速のSEとすれ違い音を停止。マッハ1未満へ戻ると従来の音へ戻す。後方・操縦席を含む全視点で共通。
- BGMは継続する。曲・演奏・SCC/FM音色・音量設定は変更しない。バリオ、方向案内、失速・接地などの警告、取得・ゲート・クリアの合図も維持する。
- 突破瞬間の爆発音と振動、映像は維持。爆発の余韻が終わった後は静かな環境音になる。爆発時だけ従来どおりBGMを短く下げる。
- マッハ0.85から1未満まで、近づくほど振動している時間を増やす。細かな震えは最長54ms/60ms、従来の間隔は最長360ms/400msが強さ1倍の基準。通常飛行の震え・振動オフ・強さ0・警告の優先を守る。
- 端末の振動モーターの出力自体はブラウザーから指定できないため、震える時間を増やして強く感じるようにする。Pixel 9aでの体感は未確認。

実際の機内が音速突破で無音になるという物理再現ではない。超音速でも機内騒音を測定している[NASAの調査](https://ntrs.nasa.gov/api/citations/19690028628/downloads/19690028628.pdf)とは区別し、今回はユーザーが求める静けさを演出として採用する。
