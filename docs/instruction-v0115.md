# twist v0.1.15 指示：レーダー表示・光の見やすさ・記録の区切り

## 前提の確定（v0.1.14の実機結果）

- 機首は `pitch=angle` を標準、`pitch=rate` を比較用として残します（変更なし）。
- `display=fixed` で、自機は人から見て上を向いたままに見え、問題はありませんでした。`display=bank` と `fixed` は、どちらも残します。標準をどちらにするかは、まだ決めません。
- 発案者の感想は「遊びの感触はかなりよくなった」です。
- 実機の記録（1人分）
  - bank：約259秒でクリア。記録上の墜落は1回、復帰補助は4.4秒。
  - fixed：約190秒で墜落。復帰補助は9.9秒。

## 実機で見つかった課題

1. **光の位置が分かりにくい**
   - 光（収集する目標）は金色（`0xe3a139`）です。v0.1.9で地面を茶色・黄土色にしたため、地面と同じ系統の色になり、離れると見分けられません。
2. **全体の位置関係がつかみにくい**
   - 光の位置を平面で見られる、レーダーのような表示がほしい、という要望です。
3. **記録が分かりにくい**
   - クリアした挑戦で墜落していないのに、記録に「墜落1回」と出ました。原因はコードで確認済みです。v0.1.13の指示どおり、「最初から飛び直す」の前の墜落も同じ挑戦として数え続けているためです。不具合ではありませんが、最後の1回の結果が読み取れないので、記録を区切ります。

## やること

### 1. レーダー表示を追加する（`view=assisted` のとき）

- 画面の隅に、真上から見た円形のレーダーを表示します。既存の表示や操作ボタンと重ならない場所を選んでください。大きさの目安は、直径90〜110px程度です。
- **向き**：自機の進行方向を上にします（自機が右へ旋回すると、レーダーの中身は左へ回る）。
- **中心**：自機を三角形などで示します。
- **表示するもの**
  - 次に取る光：大きく、目立つ色で示します。
  - その後の光：小さく、控えめに示します。取った光は消します。
  - 出口：出口が有効になったら、光とは違う形で示します。
- **高さの差**：目標が自機より上か下かを、▲▼や小さな数字など、ひと目で分かる形で添えます。
- **距離の範囲**：初期値は半径60m程度です。範囲外の目標は円の縁に留めて表示し、方向が分かるようにします。範囲は調整パネルで変えられるようにしてください。
- `display=fixed` のときも、レーダーは他の文字やメーターと同じく回さず、画面の縦横に沿って表示します。
- 飛行機モードと探索モードの両方で表示します。
- `view=legacy`（従来）では表示しません。比較用として、従来の見え方を保ちます。

### 2. 光を見やすくする（`view=assisted` のとき）

- **色**：光の色を、空の水色とも地面の茶色・黄土色とも違う色に変えます。候補は、明るいマゼンタ・ピンク系の芯に、白っぽい光の輪を付ける形です。より見分けやすい色があれば、理由を記録して選んでください。
- **遠くでも見える工夫**：距離が離れても、画面上で一定以上の大きさに見える光の輪（画面上の大きさが小さくなりすぎない表示）を付けます。
- **縦の光の柱**：次に取る光から地面まで、細い光の柱を立てます。遠くからでも位置が分かるようにするためです。
- 「金色の光」と書いている文言は、新しい色に合わせて直してください（`view=legacy` 側の文言は従来どおりで構いません）。
- 画面端の目標マーク（`visibility.js`）の色も、新しい光の色に合わせます。
- `view=legacy` の光は金色のまま残します。

### 3. 記録を区切る

- 今の合計（挑戦全体の経過時間・墜落回数・復帰補助時間）は残します。
- それに加えて、**最後の1回**（直近の「最初から飛び直す」から、クリアまたは墜落まで）の記録を追加します。例：
  ```json
  "stats": { "elapsedSeconds": 259.2, "groundContacts": 1, "recoverySeconds": 4.4, "legs": 2 },
  "lastLeg": { "elapsedSeconds": 210.5, "groundContacts": 0, "recoverySeconds": 0.0 }
  ```
  - `legs`：飛び直しを含めた回数です。
  - 項目名は、分かりやすければ変えて構いません。
- 結果画面でも、「この挑戦の合計」と「最後の1回」を分けて表示します。

### 4. 版番号・記録

- 版番号をv0.1.15へ上げます。README、公開URL、`docs/verification-v0115.md` も更新します。

## 変えないもの

- 操縦の入力、物理計算、失速からの復帰補助です。
- `display=bank` と `fixed` の見え方（レーダーと光の色以外）です。
- `view=legacy` の見え方です。

## テスト

- 単体テスト：
  - レーダー上の位置計算（自機の向きで回る、範囲外は縁に留まる、高さの上下の判定）。
  - 最後の1回の記録が、飛び直しで区切られること。合計は区切られないこと。
- ブラウザーテスト：
  - `assisted` でレーダーが表示され、`legacy` では表示されないこと。
  - 旋回するとレーダーの中身が回ること。`fixed` でスマホを面内で回しても、レーダーは画面に沿ったままであること。
  - 光を取るとレーダーから消え、次の目標が強調されること。
  - 光の色が `assisted` と `legacy` で切り替わること。
  - 390×844・360×640・844×390で、レーダーが他の表示と重ならないこと。
- 既存のテストはすべて通ること。
- スマホ実機での見やすさは「未確認」として記録に残してください。PCでの確認を、実機確認の代わりにしないでください。

## 判断の範囲

**発案者（田中）の指示で変えてよいもの**
- レーダーの位置・大きさ・範囲・記号の形、光の色、柱の太さ、文言。
- レーダーの向き（進行方向を上にするか、北を上にするか）。必要なら切替を付けても構いません。
- 実装方法（より良い方法があれば、理由を記録して採用してください）。

**変えないもの（指示があっても確認してから）**
- 端末の外へ情報を送る処理は追加しません（設定と記録は端末内だけで扱う）。
- センサーの許可の取り方と、停止・再開時に速度と出力を0へ戻す安全側の動作は維持します。

分からない点や、この指示どおりでは難しい点があれば、勝手に範囲を狭めずに、理由を書いて質問してください。
