# v0.1.18 SCC＋PSGのオリジナルMIDI BGM

v0.1.17の公開確認後に着手。指示は[instruction-bgm.md](instruction-bgm.md)。チップ計算と既存の振動/効果音/操縦/表示は変更しない。BGM追加後の再開も、過去の明示回答の停止0・手動再開50%/6m/sを維持。

## 判断

- 指定コミットのSmfPlayer、Synth、VoiceAllocator、PsgDrums、SMF parserを変更せず追加同梱し、SHA-256をsource.jsonへ追加。MIDI1〜8はSCC、10はPSGドラム、9/11〜16は非発音、SCC5音と共有波形、GM35〜81等の取り決めはそのまま。MGSDRVなし。
- 曲と音色/音量/ループはpublic/music/tracks.json。各midを同梱し、版付きURLで同じサイトから取得する。外部URLは拒否。差し替え手順はdocs/music.md。欠損/破損/無効設定はBGMなしでゲーム継続し、ゴールMIDI不可なら従来のPSGファンファーレにフォールバックする。
- 独自の手書きフレーズからtools/generate-music.mjsで生成。飛行は128BPM/24小節/45秒/ニ長調、SCC最大4音＋PSGドラム。ゴールは150BPM/2.4秒。既存曲/録音を参照・採譜しない。生成元とMIDIを保存し再生成一致を試験する。
- コピーしたSmfPlayerの後処理待ちで繰り返すと区間に無音が入るため、twist側で次の区間を先にイベント列へ加え、元プレイヤーに同じ時刻のまま流す。処理済みの古い部分は削除してメモリーを抑える。先頭のコントローラー/音、終端の全音停止を補う。公開設定のループ終端に無音を含めることもできる。
- レジスタの先渡しは元と同じ128サンプル単位、効果音と別のmusicRegメッセージ/キューに限定。PSGのドラム/ノイズも専用。SCC＋BGM-PSGと効果音PSGのゲインだけ混合する。音声処理のループ内ではキュー/レジスタ領域を再利用。
- 一時停止はBGMを停止し、手動再開で先頭から。接地で曲を停止してノイズ音、ゴールで停止してBGM側のMIDIジングル。ゴールは効果音オンに従い、BGMオフでも通知を残す。音量は全体25%と別にBGM50%を初期値として保存。
- 記録にBGM設定と実際に開始した曲名/既知のゴール曲名/再生状態を含む。計測の音源負荷はSCC＋PSG2台を含み、描画・操作CPU時間も並べる。全端末/GPUの総負荷を測ったとは扱わない。

## 確認

更新中。新単体7件（音/振動の既存8件も成功）、新BGMブラウザー4件（既存音/振動4件も成功）。別MIDIへの差し替え、途中からのループ、曲欠損時の継続、音量/保存/記録、効果音オフでもBGM音声出力>0、休止停止を確認。全体試験・レビュー・ビルド/公開確認後に追記する。
