# v0.1.29 設定画面のBGM試聴

試聴でも本編の音源を使うと、曲の履歴や音源負荷の記録が混ざります。そのため、試聴ボタンを押した時だけ専用の音声処理と曲プレイヤーを作り、停止時に閉じます。本編の飛行と音源は停止したままです。

## 操作と実装

- 一時停止中の調整パネルで「飛行中の曲」の直後に「▶ 試聴」「■ 停止」と試聴中の曲名を表示します。
- 明示的な試聴クリックからだけ音源を準備し、選んだ曲・曲集の先頭を、現在の全体音量とBGM音量で再生します。
- BGMがオフでも試聴できます。保存済みのBGMオン・オフを変更しません。全体の「音」がオフの時は試聴ボタンを無効にし、オンにする案内を表示します。
- 試聴中に曲の選択を変えると、同じ試聴操作の続きとして新しい選択の先頭を再生します。
- 停止、調整を閉じる、ゲーム再開、コース・モード切替、画面を離れる処理で、読み込み待ちも取り消します。閉じ終わる前に次を開始する操作では、前の音源が閉じるまで待ちます。
- 本編の飛行回数、曲順、再生した曲の一覧、区間時計、接近記録、振動、効果音を試聴では進めません。ABの打楽器の試聴と曲集の全曲自動巡回は追加していません。

## 検証

2026-11-08、`tests/music-preview.spec.js` の2件を、実際のEdgeの音声時計とAudioWorklet（音声を処理する仕組み）で確認しました。効果音の同フレーム優先1件を合わせ、3件すべて成功しました（24.3秒）。

- 開始クリック前の無音、本編BGMオフのままの試聴、試聴曲変更、音量、停止。
- 本編の位置・時計・再生履歴・振動が変わらないこと。
- 調整を閉じる、コース切替、再開、ページ終了通知による停止。
- MIDI読み込み中の曲変更と調整を閉じる競合、連続した停止→試聴、音源の閉鎖。
- 390×844・360×640・844×390の試聴操作と曲名。

35%のBGM音量が実際のWorkletへ0.35として送られ、試聴側は効果音オフ・BGMオンで動き、本編の保存値はBGMオフのままであることを確認しました。曲を変えても試聴用の音源は使い回し、閉じた後の再試聴では前の音源が閉じるのを待ちます。検証中の動作中AudioContextは最大1個、全試聴を停止した後に残ったのは一時停止中の本編用1個だけでした。
