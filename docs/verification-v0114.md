# v0.1.14 自機固定と景色が回る表示

2026-11-07。[依頼元の指示](instruction-v0114.md) と、既存の停止・再開に関するユーザー回答を反映する。

## 前提と仕組み

資料のv0.1.13実機結果はユーザーからの1人分の報告。angleを標準にする方針は確定し、rateを比較用に残す。新しいfixedの実機感触を確認したことにはしない。再開は前回の明示回答に従い、停止時0・手動再開50%/6m/sを維持する。

- `display=bank`が標準、`fixed`が比較。表示切替は見え方切替と同じ扱いで、物理状態を維持する。探索には適用しない。
- fixedは、模型を常に正面・無バンクとし、景色と模型それぞれのカメラを視線軸で同じ角度に回す。CSSでキャンバスを回さず、画面全域を3Dで再描画する。HUDは回さない。
- phoneの正の面内回転（時計回り）に対して、カメラはZ軸へ負の回転を持ち、その逆変換で画面上の自機と景色は反時計回りになる。物理的にスマホを回した分と打ち消し合う。
- fixedの景色は、翼の傾きを含まない地面用視点へ、実際の翼の傾きを画面の軸で後から加える。補助の視点に生じる面内傾きは除くため、低空でも15度へ縮めず翼の全角度を表す。bank用の視点計算と追従状態は別に維持し、従来のまま使う。
- 面内角は折り返さない`angles.twist`を使う。表示だけの追従は0.05秒、0〜0.3秒で保存調整可能。±180度をまたいでも最短方向を使う。操縦の計算には加えない。
- 画面自動回転は対応する方針。中立の画面角からの差を、ならした端末面内角へ別に加え、縦横切替分を遅らせない。中立を取り直すと新しい持ち方が基準となる。回転ロックを必須にはしない。実機のOS・ブラウザーごとのタイミングは未確認。
- 画面端マークには、景色の逆変換に加えてカメラの逆回転を適用した座標を渡す。visibility.jsの投影自体は変更しない。
- コピーにdisplayと結果種別を加え、resultはclear/grounded以外には出さない。rateの未使用2設定とbankの表示ならし設定をinactiveSettingsで明示。設定コピーは現在値、結果コピーは当時の値を固定する。
- 画面・favicon・package・URLを0.1.14へ。開始カードに版番号を維持し、増えた選択の説明は「基本操作」へ折りたたむ。探索の説明は開いた状態と従来配置を維持。
