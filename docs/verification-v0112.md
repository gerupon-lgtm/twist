# v0.1.12 慣性と失速からの復帰

2026-11-07。上昇して速度を失うと真下へ落ち、姿勢と出力を戻しても復帰しづらいという実機報告を受けた調整。

## 仕組みと変更

以前も前後・上下・左右の速度は保持し、速度0で入力やエンジンを無効にはしていなかった。ただし落下方向と機首の向きが大きくずれた状態では翼の支える力がほぼ0に留まり、50%出力の推進力では回復しにくかった。慣性を維持したまま、ゲーム向けの復帰補助を加える。

- 機首が水平付近・翼が上向きで出力があるとき、低速時の前進力を増す。機首方向の速度1〜4.5m/sで滑らかに弱め、通常の6m/s・出力50%巡航は以前の釣り合いを維持。
- 失速中は速度と直角の方向へ力を加え、既存の勢いを連続的に機首方向へ向け直す。速度を機首方向へ一瞬で置き換えず、この補助自体で運動のエネルギーを増やさない。増速はエンジンが担う。
- 機首の上・下15度以内で姿勢条件が最大、45度で0。翼を戻すほど使いやすい。出力0、上下へ大きく向いたまま、裏返った状態では補助しない。停止中の翼が浮力を出す仕様にも変えない。
- 補助中は「失速からの復帰補助中」。説明画面には機首0度付近・翼水平へ戻して出力を上げることを記載。スマホの前後を中立にするだけでは機首角度を戻さない操作は継続。
- 接地は地表0m。地面を見る表示補助と旋回方向への機体表示も継続。探索の操作・計算は変更しない。
- 画面番号、package、favicon、設定URLを0.1.12へ更新。JSは内容ハッシュで更新し、サービスワーカーは使わない。

## ローカルで確認済み

- 単体96件、5ファイル、終了コード0。復帰条件、速度0からの推進、姿勢変更時の慣性保持、補助の上限・滑らかさ、エンジンの仕事と空気抵抗を差し引いたエネルギーの釣り合いを含む。
- ブラウザー49件、5ファイル、Edge・1worker・2.3分、終了コード0。実ステージで上昇→失速→下降を作り、機首を水平付近へ戻して出力50%・100%の両方で接地前に復帰。速度0の空中状態でも前後・左右・出力が働くことを確認。
- 通常の上昇減速・下降加速、出力0の滑空、本体基準の入力、旋回表示、全目標と出口、地面表示と0m接地、探索、画面サイズも継続成功。
- 復帰後の画面を目視し、中央の機体、茶色の地面、速度・高さ・出力と版番号の表示を確認。
- ビルド成功、JS `index-C-RvRXHp.js` / CSS `index-Ck8BSCuf.css`。CSS変更なし。従来と同じ500kB超のJSサイズ警告は残る。
