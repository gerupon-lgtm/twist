# 画面デザイン改修の受領

2026-11-09。**v34公開後、v35として実装・検証・公開確認を完了。** UIの方向性とコピーの決定は保持する。[実装](implementation-v0135.md) と [検証](verification-v0135.md) を分けて記録する。

利用者の指定は「タイトルからUIが地味」「ゲーム自体は凄く面白くなってきた」「SIKUMI LABの作品として、洗練された、遊びたくなるデザイン」「色味はOK」。タイトル・コース選択・飛行前の地図・クリア画面の画像が提供された。

配色を作り直す依頼ではない。現在の空色・青緑・濃い文字・目標のピンク・出口の金色を活かし、主役の大きさ、文字の強弱、情報のまとまり、操作の配置、反応する演出を見直す。ゲームとしての飛ぶ楽しさが入口から伝わることを目指す。

追記で「ステージのイントロダクションもワクワクする感じ」「今の方向性は問題ない」「見せ方だけ」と指定された。飛行前の地図を含む導入にも、コースの特徴とルートを楽しみにできる見せ方を適用する。既存の遊び方・コース・開始手順・待機時間は維持し、新しい強制待機や説明ステップは増やさない。

タイトルのコピーは利用者との検討後、**Tilt to Play.** に確定した。大文字・小文字と末尾のピリオドもこの表記を使い、「傾けて、空をめぐろう。」に代えて次のデザイン版へ組み込む。

その後、利用者から「イントロでターゲットへラインがつながる演出にも音」「前後にもカッコ良いジングル」という追加希望を受領した。見た目中心で音は増やさないとしていた設計側の前提をここで更新し、導入の音演出も対象に含める。開始の短い勇敢なジングル、各目標へ線が届く軽い合図、出口まで完成した時の短い締めを設計する。待機や操作手順は増やさず、スキップで音も取り消し、音・効果音のオフと音量を尊重する。初回タップ前の自動音や、一時停止から地図を見返すたびの出発演出は加えない。本編BGMの履歴、飛行の時計、振動とは分ける。v33の静かな地図の検証へ、この次版の追加を混ぜない。

rootの初期方針は、機体とルートを主役にしたタイトル、選択中のコースを大きく見せる選択画面、空白を減らして読める地図、今回の記録と達成感を主役にしたクリア画面。これは利用者が細部まで指定した仕様ではなく、実画面を作るための設計側の提案である。プレイ中の操作部にも統一感を持たせ、操縦や案内の意味を変える作業とは分ける。

見た目は切り離した見本だけで判断せず、実際のアプリの画面で確認する。スマホの縦・横、小さい画面、タイトル／プレイの縦スクロールなし、押しやすさ、視点ごとのHUDとの重なり、動きを減らす設定、版情報の見つけやすさも対象とする。

現在のv33を検証中に画面の製品コードは変更しない。デザイン案の読取・cache内の準備だけを先行し、v33公開後に別版として実装・検証・公開する。依頼済みの手首操縦とシエラコースは、その後の別版として保持する。
