# v0.1.49 変更内容

速度の単位をkm/h・ktにすると、高速域の6文字の数値（2448.0、1321.8）が操縦席の58px幅の枠を超えていた。幅を72pxへ広げ、小数や桁を省略せず表示する。

同種の問題を、外から・追尾3D・操縦席、縦横3寸法、日本語/英語、速度3単位、標準/代替の等幅字体、上昇/下降の符号で確認した。

- 昇降速度も細い矢印用の16pxしか配置幅がなく、数値が領域外へ出ていた。数値込みで44pxを確保し、矢印を中央に置く。右の高度計を移して6pxの間を保つ。
- 高度計の数値用の小枠は、5文字以上だけ13pxの文字へ切り替える。12.5kや999.9が枠から出ないようにする。
- AB表示は文字の高さより行の高さが小さかったため、行を14pxにする。
- 新しい計器の幅に合わせ、中央の飛行表示を描ける範囲を調整する。案内は既存の計器の実際の位置を使う。

速度・高度・昇降・方位・目標高度・距離・マッハ/G・燃料・出力の864通りの表示を確認した。人工的な限界値で表示だけを調べる検証と、実際に音速を超えて上昇する飛行の検証を分けている。字体差の検査で昇降速度に追加の2pxのはみ出しを見つけ、最終的に44pxで解消した。

飛行・入力・コース・記録の条件と音は変更しない。画面の版、更新確認、manifestなどは0.1.49へ更新。公開確認済みの0.1.48は本編33ファイルをそのまま保存版へ追加する。
