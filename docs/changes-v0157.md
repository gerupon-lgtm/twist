# v0.1.57 変更内容

Overdrive HorizonのFM版リードを、承認済み試聴と同じく1オクターブ下げる。

- 専用のFM再生設定でリードだけを12半音下げる。音の開始・終了に同じ変換を適用し、音の揺れやチョーキング、音量・タイミングを維持する。
- 元のMIDIデータを書き換えず、FMへ渡すリードの音程だけを変える。SCC版、オルガン、低音、和音、ドラム、他曲、音色の設定は従来どおり。
- 設定データの型と範囲を検査し、変換で再生可能な音域を外れるデータには既存のSCCへの切り替え処理と診断を使う。実際のOverdrive Horizonでは全217音が範囲内に収まる。

画面の版表示とキャッシュ更新番号を0.1.57へ更新。公開確認済み0.1.56の本編33ファイルを、同じバイトのまま保存版へ追加する。
