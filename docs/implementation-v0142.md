## 新コースの条件

- ID `sierra10`、表示「シエラ縦断（1/10・亜音速）」。同じ推定緯度経度を水平1/10・高さ1倍で変換し、整数丸めしたA〜Gは受領表と完全一致。高さは`(推定標高−790)÷10+60`。世界を回転しない。
- Aの手前1km、高度60m、A→Bの方位約350°から開始。門は半径40m、A〜Fと出口G、平地0m。20km四方・高度2000mの境界は案内で、自動停止を追加しない。
- 専用プロファイル`sierra10-subsonic-v1`。初速150m/s、出力100%の水平終端約250m/s、AB合計推力20m/s²・全体上限300m/s、最大9G。AB解除や下降の慣性は250m/sで突然切らず、全体上限内で保つ。Mは実速度÷340。
- AB容量100・開始60・毎秒4消費、門で12、最下部の地面まで160m以内・実速100m/s以上で毎秒0.75補充。一時停止や接触後の時間へ報酬を足さない。設定はコース専用で固定し、既存の12G/無制限等を保存したまま戻せる。
- 地面の高さは共有の平面関数を通す。地面との判定は既存の実形状と移動線分を使い、山並み・柱は目印で当たり判定を持たない。数値標高データや実地形は追加しない。

## 表示・記録

地面は320/40/8mの模様、柱と旗は数十m、山は東西の遠景。模様の位相を世界座標に固定し、2048mのタイル境界と原点切替をまたいでもずれない。視野・流線・風音の基準はこのコースだけ300m/sへ合わせ、250→300でも変化する。旧高速空域の680m/s基準は維持する。

HUDは実速度・M・G・平地からの中心高度、目標と次の通知・地図はA〜G。コース選択は6個へ増やし、狭い縦画面のボタンと開始を画面内に収める。通常の探索は従来4コースのまま。

コピーはコースID/縮尺、開始→AからF→Gの7区間、最高速度・M・最大G、最低中心高度/最下部余裕、区間ごとのAB秒数/消費量を追加する。従来の海面高度のフィールドも互換のため保持する。300m/s到達を誤ってM2と記録しないよう、旧上限到達の処理に実音速との条件を加えた。旧680m/sのM2判定は維持する。

300m/sの各角を実計算で確認した際、一定刻みが門の面の直前に小数丸めを残すと通過を見落とすことを再現した。元の1e-9mの誤差範囲内へ終点が到着した場合も1回と数え、面上から出発する次の刻みは引き続き除外する。半径は変更しない。両方向・重複防止・半径外を含む再発試験と、実入力のB〜Fの各角300m/s/9G以内/有限燃料を確認した。各角の開始条件を300m/sにした単体試験であり、全区間を300m/sで連続飛行したという意味ではない。

### 全体試験で見つかった欠落曲の代替順

v39以降は選択曲だけを待つため、未要求の欠落曲は開始時には分からない。旧MML/新作3曲集の試験は開始直後に欠落済み一覧を期待していたので、初回は未読を含む一覧、次の飛行で実際に404を受けた後は除外済み一覧を確認する形へ修正した。取得失敗・代替曲の再生・一時停止/再開・音声出力という検証の目的は保つ。

さらに、欠落を後から知った際に代替の順番が違うことを単体で再現した。失敗が判明するたび、その曲を除いた一覧へ現在の飛行番号を当て直す。候補は一度ずつしか試さず、取消確認と曲の使用許可の制限も維持する。未読曲の有無を先に全て調査する方式へ戻さない。新規の3回目では未要求の2曲目を調べず選択した3曲目を再生することも固定し、「全曲を先読みした一覧との全面一致」とは区別した。47件の関連単体、MML4件と別曲集の欠落1件が成功。楽曲・音色・通常取得成功時の曲順は変更しない。
