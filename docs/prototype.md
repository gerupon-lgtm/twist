# twist 操作検証 v0.1.0（履歴）

現在の操作は [v0.1.2の改訂](control-update-v012.md) を参照。以下は初回試作の記録で、画面基準の向き固定とひねり前進の操作は2026-11-07のユーザー訂正によって失効した。旧内容は変更せず履歴として残す。

2026-11-06。操作感を実機で確認するための初回試作。ゲームとしての完成版ではない。

## ユーザーが選んだ操作

- 自機の画面上の位置と向きを固定し、周囲が動く3D探索。
- 傾けた角度で旋回の速さを指定し、傾けている間は旋回を続ける。
- 前後の傾きで上下の進路、左右の傾きで左右の進路、平面で右へ回すひねりで前進速度。速度用のひねりを基準へ戻せば前進停止。
- 自機の横回転を独立に操作するものではない。停止中にも傾きで周囲を見回せる。
- GitHubのリポジトリ作成は承認済み。名称 twist はユーザーの候補を初回試作の仮称に採用。

## 今回の実装判断

- 独立フォルダ・独立リポジトリ。既存のゲームは変更しない。
- Three.js + Vite。カメラと自機を固定し、現在地と向きの逆変換を世界に適用する。
- 浮遊する機体と広場、上下差のある3つの光、最後に出口。次の目的地の方向・上下・距離を表示する。
- 開始時の持ち方を基準にする。基準合わせは停止して行い、その場で再開する。許可は開始ボタンの操作から要求。
- 全3軸が取得できた時だけ開始可能。軸が欠ける、センサーが途切れる、画面が隠れる、画面回転時は停止して再開を明示する。
- 速度のひねりを戻すと惰性なく停止。小さな手ぶれを無視する範囲を設ける。ひねりは開始姿勢の画面に垂直な軸、傾きは開始姿勢の画面の横・縦の軸を基準に計算する。
- 上下・左右とも傾きを保つ間は旋回を続け、一周できる。移動にはステージ外へ離れすぎない位置の上限を設ける。
- スマホのセンサー、PCキーボード、画面の練習用つまみを明確に区別する。疑似入力の成功は実機確認の代用としない。
- 画面内に検証版番号と入力状態を表示。ビルドで内容ごとのファイル名を生成し、更新のキャッシュ混同を避ける。サービスワーカーは初回には導入しない。

自動検証: 基準姿勢、3軸単独と組合せ、角度の境界、停止、センサー消失、案内と収集、固定カメラ・自機、スマホ寸法の画面、ビルドと公開URL。
実機未確認: iPhone/Androidでの許可、ひねり保持中の上下左右操作、持ち直し・画面回転、長時間のずれ、酔い・見やすさ、実機の描画速度。これらを勝手に検証範囲から外さない。
