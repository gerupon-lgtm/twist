# v0.1.35 画面とステージ導入

機体とルートの形を大きく見せ、入口から飛ぶ遊びだと伝わる構成へ変更した。空色・青緑・ピンク・金色、既存の飛行条件と操作手順は保持する。公開確認は [検証記録](verification-v0135.md) に分ける。

- タイトルはゲーム内の機体を元にした透過画像とルートを主役にし、コピーを利用者指定の **Tilt to Play.**、下部を SIKUMI LAB と版情報にした。
- コース選択は選択中のルートを大きく描き、その下に全コースの切替を並べる。大図は実際の表示面積で描き直し、保存したベスト記録とコース形状を保つ。
- 紹介地図はルートを主役にした大図と、境界・目印を残した全空域の小図を併記する。元の座標・開始方向・地点高度を変えず、出発時は従来の3.6可視秒で線を描く。一時停止からの見返しは完成図を即表示する。
- 結果は今回の時間を主役にし、本当に自己ベストを更新したときだけ金色で示す。記録のコピー・拒否時の選択コピー・詳しい記録・再挑戦の入口を保つ。
- プレイ中は既存の視点別HUDと出力の配置を保つ。新たな角度設定や飛行入力を追加しない。

## 紹介の音

既存のメイン音声処理の中に、紹介専用の短い効果音を追加した。新しいBGM曲としては登録せず、飛行の時間・BGMの順番・振動を進めない。

開始の短い合図、各目標への到達音、出口まで線が完成した合図を鳴らす。到達時刻は、画面で描くルートの長さに合わせて計算する。開始操作で音声処理の準備だけを行い、タイトルを表示しただけでは鳴らさない。

スキップ・画面非表示・設定の変更・次の開始操作では、その紹介の音を取り消す。準備が間に合わなかった音は後からまとめて鳴らさず、100msを超えて遅れた合図を捨てる。音・効果音のオフと音量0を尊重する。BGMだけをオフにしても効果音は鳴らせる。

動きを減らす設定では地図を即完成し、締めの合図を最大1回だけ鳴らす。一時停止からの見返しは無音にする。地図を閉じる操作は音の完了を待たない。v34のGO音1.5秒と、実際の終了通知後にBGMへ移る処理は保持する。

## 確認の境界

作成したブラウザー環境での表示、実際の音声処理の数値、公開ファイルの一致を別々に確認する。Pixel 9aの押しやすさ、実スピーカーでの音の印象、実際の縦横回転は実機確認として残す。
