# v0.1.51 変更内容

v0.1.50の計器は、明るい空や海では文字と背景の明暗差が足りなかった。前版は文字の収まりを確認したが、それだけでは読みやすさを確かめられなかったため、計器の表示を修正する。

- 速度・高度・マッハ/G・昇降速度の面を、濃さ22%から86%の青緑へ変更する。景色は約14%だけ透ける。
- 文字は明るい白緑にする。小さい文字の輪郭をつぶしていた四方向の強い縁取りをやめ、薄い下側の影にする。
- 方位・現在/目標高度・警告・操縦席の下側の説明にも同じ濃い面と文字を適用する。警告の黄は区別して残す。
- Cの円形計器で、後から描いた円が項目名を覆っていた問題を修正する。文字を円より手前に描き、実際の表示順も検査する。

A/B/Cと全3視点で共通。配置・操縦・コース・音・記録の条件は変更しない。バージョンとキャッシュ更新番号を0.1.51に更新し、公開確認済みの0.1.50をそのまま保存版へ追加する。

前回の「景色を多く透かす」方針は、今回の読みやすさの指摘を受けて変更した。半透明であることは保ち、文字の読み取りを優先する。
