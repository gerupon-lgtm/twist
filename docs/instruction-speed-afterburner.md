# twist 次の版の指示：スピード感とアフターバーナー

「旋回の強さの見直し・ステージの拡大・3コース」の版が終わってから取りかかってください。広いステージと強い旋回があることが前提です。

## 背景（なぜ入れるか）

- 発案者の希望：「超音速戦闘機をモチーフにしているので、ある程度スピード感がほしい。今はスピード感に乏しく感じる」。
- アフターバーナーは、発案者が**必須**としている要素です。方式は**ゲージ制**（上手く飛ぶと溜まり、使うと減る）に決まっています。
- 今の速度は、巡航10m/s・最高30m/s（`flight-physics.js`）です。

### スピード感は何で決まるか（考え方）

- 人が感じる速さは、速度の数値そのものより、**景色がどれだけ速く流れて見えるか**で決まります。
  - 近くに物があるほど、速く流れて見えます（低空、細かい地面の模様、通り過ぎる物）。
  - 視野が広いほど、横を流れる量が増えて速く感じます。
  - 音と振動も、速さの感覚を強めます。
- そのため、速度の数値を上げるだけでなく、「流れて見える物」と「演出」を増やします。

## やること

### 1. 景色の流れを増やす（`view=assisted`）

- **地面の細かな物**：小さな岩、草、遺跡のかけらなどを地面に散らし、低空で飛ぶと速く流れて見えるようにします。描画の重さに気をつけ、まとめて描く方法（インスタンス描画など）を使ってください。
- **空気の流れ**：速度に応じて、画面の外側に向かって流れる細い線や粒（流線）を出します。速いほど多く・長くします。
- **雲**：通り過ぎる雲を増やし、近くを抜けると速さを感じられるようにします。当たり判定は付けません。

### 2. 速度に応じた見え方の演出

- **視野の広がり**：速度が上がるほど、視野を少し広げます（目安：最大で+10〜15°）。操縦席視点の上下の視野の設定とぶつからないようにしてください。
- **わずかな揺れ**：高速時に、カメラをごくわずかに揺らします（外から見る視点が中心。操縦席視点では控えめに）。酔いを避けるため、調整パネルでオフにできるようにします。
- **速度の単位**：HUDの速度表示の単位を、m/s・km/h・kt（ノット）から選べるようにします（初期値は km/h）。数値はごまかさず、実際の速度を換算して表示します。

### 3. アフターバーナー（ゲージ制）

- **ゲージの溜め方**
  - 目標（TGT）を取る、出口を抜ける。
  - 低空を飛ぶ（地面に近いほど早く溜まる。ただし地面の接触は今までどおり失敗）。
  - 目標を続けて素早く取る（連続で取ると多めに溜まる）。
  - 溜まる量の数値は、1か所にまとめて調整しやすくしてください。
- **発動のしかた**
  - **基本：スロットルを100%の先まで押し込む**。画面のスロットルの上の端に「AB」の領域を作り、そこまで動かすと発動します。実際の戦闘機も、スロットルを最大の位置からさらに奥へ押し込んで点火します。ゲージが空なら発動しません。
  - **補助（任意）：極端に傾けると自動で発動**。機首下げの入力と区別がつきにくく、意図しない発動や、画面が見づらくなる心配があるため、**初期値はオフ**にし、調整パネルでオンにできるようにします。条件の角度も調整できるようにします。
  - スロットルの誤操作を防ぐ仕組み（調整パネルで対策済みの考え方）を参考に、AB領域にうっかり触れて発動しないよう配慮してください。
- **発動中の効果**
  - 推力を大きく上げ、最高速度の上限を一時的に引き上げます（目安：30m/s → 45m/s）。
  - ゲージが減っていき、空になるか、スロットルをAB領域から戻すと終わります。
  - 旋回の半径は速度とともに大きくなるので、直線で使うと気持ちよく、曲がり角の手前では使いにくい、という駆け引きになります。
- **演出**
  - 噴射口の炎を大きく・明るくします（外から見る視点）。
  - 視野をさらに広げ、流線を増やします。
  - 効果音用PSGのノイズで轟音を鳴らします。点火の瞬間に短い強い音を入れます。
  - 強めの振動を続けます（振動の設定に従う）。
  - HUDに「AB」の表示とゲージを出します（HUDの英語表記に合わせる）。

### 4. 設定と記録

- 調整パネルに次を追加します：流線の量、速度による視野の広がり、高速時の揺れのオン・オフ、速度の単位、アフターバーナーの自動発動のオン・オフと角度。
- 記録とコピーに、アフターバーナーの使用回数・使用時間・ゲージの獲得量、最高速度を追加します。

### 5. 版番号・記録

- 版番号を上げ、README、`docs/settings-guide.md`（新しい設定の説明）、`docs/verification-v01xx.md` を更新します。
- 描画と音の処理の重さを、変更の前後で比べて記録してください。

## 変えないもの

- 旋回の強さ、ステージの広さ、3コースの配置（前の版で決めたもの）。
- 揚力・落下・失速の計算。
- 光・出口を取れる判定の大きさ。

## テスト

- 単体テスト：
  - ゲージの増減（取る、低空、連続、使用）。上限と0の扱い。
  - 発動・終了の条件（AB領域、ゲージ空、自動発動のオン・オフと角度）。
  - 発動中の最高速度と推力。
  - 速度の単位の換算。
- ブラウザーテスト：
  - AB領域まで動かすと発動し、戻すと終わること。ゲージが空だと発動しないこと。
  - 発動中に、炎・視野・流線・音・振動・HUD表示が変わること。
  - 自動発動は、初期値ではオフであること。
  - 各設定の保存と記録への反映。
  - 390×844・360×640・844×390で、AB表示とゲージが他の表示と重ならないこと。
- 既存のテストはすべて通ること。
- 実機でのスピード感、酔いやすさ、アフターバーナーの爽快感と操作のしやすさ、描画と音の重さは、Pixel 9aでの確認を「未確認」として記録に残してください。

## 判断の範囲

**発案者（田中）の指示で変えてよいもの**
- ゲージの溜まり方・減り方、発動中の速度・推力、AB領域の位置と大きさ、自動発動の条件。
- 流線・地面の細かな物・雲の量と見た目、視野の広がりの量、揺れの強さ、速度の単位の初期値。
- 演出の音・振動・見た目。
- 実装方法（より良い方法があれば、理由を記録して採用してください）。

**変えないもの（指示があっても確認してから）**
- 速度の表示を実際の速度と違う値にすること（演出のために数値を盛らない）。
- 光・出口を取れる判定を大きくすること。
- 端末の外へ情報を送る処理の追加（設定と記録は端末内だけで扱う）。
- 開始ボタンを押す前に音や振動を出すこと。

分からない点や、この指示どおりでは難しい点があれば、勝手に範囲を狭めずに、理由を書いて質問してください。
