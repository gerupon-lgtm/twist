# v0.1.56 変更内容

Overdrive HorizonのFM版のリードとオルガンを、音の作り方から調整する。

- リードはミニムーグ風の音を目指し、FMで音程を変化させるノコギリ波の発振を2つ重ねる。少しの音程差で唸りを作り、強い入力歪み、音の立ち上がりで明るく開く4段の共鳴フィルター、出力側の歪みを加える。
- オルガンは基音から8倍までの倍音を重ねる。オクターブ・5度・高い混合音を増やし、細かいフレーズの中でも上の響きが出るようにする。高い音では重ねる倍音数を減らす。
- 新しい発振とフィルターは該当する専用音色だけで使用する。既存のFM音色は従来の計算を通す。SCC・PSG・ドラム・他曲・演奏データ・全体の音量設定は維持。
- リードはFMの発振を活かした独自設計で、実機の回路を再現するものではない。音の重ね方と歪み・フィルターの方向性は[Moog公式Model Dマニュアル](https://cdn.inmusicbrands.com/Moog/Model%20D/Minimoog_Model_D_Manual.pdf)も参照した。

画面の版表示とキャッシュ更新番号を0.1.56へ更新。公開確認済み0.1.55の本編33ファイルを、同じバイトのまま保存版へ追加する。
