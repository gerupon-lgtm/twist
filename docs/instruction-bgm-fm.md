# 後続のBGM整理・軽量FM・追加クリア曲の依頼

2026-11-08受領、同日更新。**作業待ち・未実装。v30公開後に開始時の不備が見つかったため、v31でその修正、v32で高速空域を先に完了し、このBGM／FM／ジングル／SMFの作業はv33の予定へ変更した。** この資料を追加しただけで、曲集・音源・設定・配信物は変更していない。先行版の完了前に、この機能を実装しない。

## 利用者が指定した範囲

- 通常の飛行用BGMは「黒曜の翼」以降の曲を採用する。
- 最初の2曲と「勇進の航路」は、消さずに試聴専用で残す。
- 上の楽器パートに軽い2オペレーターFMを使う。これは、音を出す発振器と、その音色を変える発振器を組み合わせる方式。参照元は[コエキットのサエズリズム](https://github.com/gerupon-lgtm/koekit)。SCCとFMを切り替えられるようにする。
- 追加指定：「BGMの整理ですが、試聴用の選択肢でまとめていたものは無くして、曲ごとの選択肢のみにしてください。あと、追加でクリア時のジングルをあと3パターン作成してください。イグニッションスカイ以降の曲の感じでお願いします。」
- 試聴の選択肢は曲ごとのみとし、曲集としてまとめた選択肢を出さない。試聴専用の3曲も個別に選べる形で保持する。
- クリア時の短い曲をオリジナルで3パターン追加する。Ignition Sky・Steel Advance・Overdrive Horizonの雰囲気を参考にし、既存のクリア曲も残す。既存1曲＋追加3曲となるが、その選び方や初期選択はまだ指定されていない。

未完の追記「後作業のBGMno」だけから別の変更は推測しない。その後に届いた上記の確定した指示を採用する。

## 実装を始める時の推奨案と未決定事項

次は技術上の候補で、利用者が具体値まで指定したものではない。

- SCCは比較用として保持し、初期選択も勝手に消さない。FMを選んだ場合は上の旋律・和音パートを対象候補とし、低音はSCC、打楽器とABの追加打楽器はPSGを維持する案を優先する。具体的なパート番号と音色は曲ごとに調べて決める。
- 発音部品だけを必要な形で接続し、サエズリズムの制作画面・曲保存・Transport一式は持ち込まない。DX7IIの6オペレーター処理や音色資産を採用する依頼ではない。
- twistは現在MIDIのイベントをSCCへ渡し、同じAudioContextの時計で予約する。参照元はネイティブのAudioNodeへ出力するため、そのままSCCのレジスター書込み先には置けない。音符の開始／終了、音量、音高の変更、全停止、予約取消を扱う接続部が必要。現在の音源APIはAudioContextと出力先を外へ公開しないため、その境界も設計時に確認する。
- 音源切替の初期値、飛行中に切り替えるか・次の曲からか・同じ位置を引き継ぐか、追加クリア曲の選び方は未決定。今回の読取だけで操作や保存形式を増やさない。
- 確認は音符を減らして済ませず、既存の曲・AB・警告・試聴・停止・画面離脱、実際の最大の重なり、同じ条件でのSCC／FMの負荷、音割れ、余韻、公開を含める。ネイティブ音源は既存worklet内の負荷値に入らないため、その値だけで軽さを比較しない。音色の好みとPixel 9aの負荷・安定性は別に確認する。

## 追加依頼：全曲・全ジングルをSMFで書き出す

**2026-11-08の利用者の追加指示で、この独立した書き出し・ZIP納品は不要となった。** 「SMF書き出しは、githubから直接取得できたので大丈夫です」との回答を優先する。以下は以前の依頼の記録で、追加の書き出しツール・ZIP・配布一覧は作らない。BGM整理・FM切替・新しいクリア曲3パターンは継続し、その再生に必要なMIDIの作成・検証と既存曲の原本保持は行う。

利用者の指定：「現在持っているBGMやジングルをSMFで曲ごとに書き出してください」。v31の開始不備修正・v32の高速空域を終え、v33のBGM改修が完成した時点の全オリジナル曲と全ジングルを対象にする。試聴専用へ移す3曲も省かない。

現在の`public/music/`には実際に13個の`.mid`があり、`tracks.json`の13曲と対応する。上表の飛行曲10個に加え、次の3個を含む。「title」は各曲の名前の項目であり、独立したタイトル曲のMIDIは現在の一覧にはない。

| 曲ID | 曲名 | 現在のSMFファイル |
|---|---|---|
| `afterburner` | AB Pulse | `afterburner.mid` |
| `clear` | 突破の凱歌 | `clear.mid` |
| `comparison` | ひかりの航路（比較） | `flight-legacy.mid` |

既存13個を原本として保持し、前述のクリア曲3パターンもそれぞれ1個のSMFにする。他の曲の増減がなければ計16個となる。曲名・曲ID・ファイル名の対応表を添え、通常採用曲／試聴専用／AB／クリア／比較用を区別する。再生用の既存MIDIがある曲を、音声から採譜し直す必要はない。

納品は一括でダウンロードできるZIPと曲ごとの個別ファイルを用意する方針とし、具体的な置き場所・ZIP名・配布方法は実装時に確定する。現段階ではZIP生成や書き出し機能を追加しない。

SMFは音符・音の長さ・強さ・テンポ等を持つ演奏データで、録音された音声ではない。SCCの波形番号・音量・ループ位置や、FMの音色・パート割当て等は別の設定資料を添える。一般のMIDI再生ソフトで開けることと、twistと同じ音色で鳴ることは分けて確認する。MIDI単体へ固有の音色が自動で埋め込まれるとは説明しない。

実装時には全曲のSMFが読めること、音符・テンポ・終わりの位置と対応表、ZIPと個別ファイルの内容一致を確認し、試聴専用曲や追加ジングルを抜かさない。出力形式のために曲やパートを間引かない。

この資料の段階では、追加曲の制作、MIDI変更、音源の組込み、SCC/FM切替、設定変更、SMFの書き出し・ZIP生成、テスト実行、公開は行っていない。
