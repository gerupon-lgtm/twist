# twist 次の版の指示：スピード感の改善（地面・音・ABのBGM）とアフターバーナーの使いどころ

作業中の版があれば、その次の版として出してください。

## 背景（なぜ直すか）

v0.1.27の実機の記録と、発案者の感想は次のとおりです。

- アフターバーナーを1回・約5秒使い、最高速度45m/s（約162km/h）に達した。ただし発案者は「スピードが上がっているのは分かるが、感じられない。背景の効果によるものだと思う。**地面のメッシュがとてもゆっくりに見える**」。
- 「アフターバーナーに入ったときや、速度に応じて、**風切り音が変化**してもよさそう」。
- 「アフターバーナーに入ったときだけ**BGMが変わる**のもよさそう」。
- 「やさしいステージしかやっていないが、**狭いところではアフターバーナーの使いどころが無さそう**」。
- 記録では、TGT3→EXITの区間に約65秒かかった。EXITは開いてから約3.7秒で画面に入っており、**見えていたのに取れなかった**ことになる（前の記録のTGT2→TGT3でも同じ形があった）。

### コードで確認した原因

- **地面の模様が、ステージの中央にしかない**：`stage.js` の市松模様（`ground-paving`）は、4m四方のタイルを、中心(0, -24)付近の半径約80mの範囲にだけ並べています。v0.1.26でステージを前後左右350mに広げたため、その外側は**模様のない一色の地面**（`groundMaterial`、`0x9a502f`）になっています。やさしいコースはx=±125m、z=最大160mあたりを飛ぶので、ほとんど模様のない地面の上を飛んでいます。流れて見える手がかりがないので、速さを感じられません。
- **風切り音が18m/sで頭打ち**：`src/feedback/model.js` の `wind: Math.min(1, speed/18)` により、18m/sを超えると風切り音が変わりません。巡航の上限30m/sやAB中の45m/sでも、同じ音のままです。
- **ABの使いどころ**：旋回の半径は、速度の2乗に比例します。旋回の強さ9.8・翼35°で、45m/sのときの半径は約295mです。やさしいコースの区間（約40〜125m）では、ABを使うと曲がりきれません。
- **レーダーの範囲**：v0.1.26で初期値は180mになりましたが、発案者の端末には古い保存値60mが残っています（`changedSettings` に `radarRange`）。700mのステージでは狭すぎます。

## やること

### 1. 地面全体に、流れて見える模様を付ける（`view=assisted`）

- ステージ全体（境界の外の見える範囲も含む）の地面に、模様を付けます。タイルの箱を並べるのではなく、**繰り返し貼る模様の画像（テクスチャー）**などで、描画を軽く保ってください。
- **大きさの違う模様を重ねる**：高度20〜40mから見ても流れが分かる大きめの模様（畑の区画や石畳の区画：目安10〜30m）と、低空で効く細かい模様（目安2〜4m）を組み合わせます。
- 遠くで模様がちらつかない（モアレが出ない）ように、ミップマップや異方性フィルタリングなどで対策します。
- 今の中央の市松模様と道の目印は、残すか、新しい模様に置き換えるかを判断して構いません（理由を記録）。
- **通過物**：コースの近く、とくに後の3.で作る直線区間の両脇に、柱、遺跡の塔、岩などを並べます。すぐそばを通り過ぎる物は、一番強く速さを感じさせます。当たり判定は今回は付けません（見た目だけ）。
- `view=legacy` は従来のまま残します。

### 2. 速度に応じた音の変化

- **風切り音**：0m/sからAB中の最高45m/sまで、速いほど大きく、高くなるようにします（今の18m/sでの頭打ちをやめる）。速さの範囲全体で、変化が耳で分かるようにします。
- **ABの音**：点火の瞬間に「ドン」と短い強い音、AB中はうなるような低い轟音を重ねます（今の点火音・轟音を強める方向）。終わるときは、すっと消える音にします。
- **すれ違う音**：柱や塔、TGTのすぐそばを高速で通り過ぎたときに、「ヒュッ」という短い音を鳴らします（速いほど鋭く）。
- 音は効果音用PSGで鳴らします。ノイズの高さが共通である制約は、今までどおり、警告を優先する形で扱ってください。

### 3. ABのときだけBGMを変える

- AB中は、AB用の曲に切り替えます。
  - 方法は、①AB用の短いループ曲に切り替える、②今の曲に音の層（ドラムの倍打ち、速いアルペジオなど）を足す、のどちらでも構いません。曲の継ぎ目が自然な方を選び、理由を記録してください。
  - 切り替えは拍の頭に合わせ、ぶつ切りにしないでください。
  - 短いABで曲が細かく切り替わらないよう、最低でも数秒（目安2〜3秒）は保ちます。ABが終わったら、元の曲の続き（または区切りのよい位置）へ戻ります。
- AB用の曲も、オリジナルで作ります（既存の曲を写さない・似せない）。`tracks.json` と手順書（`docs/music.md`）にも追加し、発案者が差し替えられる形にします。
- 調整パネルに「ABでBGMを切り替える」のオン・オフを追加します（初期値オン）。

### 4. アフターバーナーの使いどころを作る（コース）

- **ABの直線区間**：各コースに、ABを使って気持ちよく飛べる長い直線区間を入れます。
  - 長さの目安：やさしい200m以上、ふつう・むずかしい300m以上。満タンのABは約8秒で、45m/sなら約360m進めます。
  - 直線区間の入口と出口が分かるように、見た目の印（例：遺跡の門を並べる、地面に帯を描く）を付けます。HUDに「AB」の合図を出しても構いません。
  - 直線区間の後は、速度が落ちるまでの距離を考えて、急すぎる曲がり角を置かないでください。
- **配置の検証**に、直線区間の長さの確認を追加します（`course.js`）。3コースとも合格すること。
- **ABを使う理由**：コースごとのクリア時間と自己ベストを記録・表示します（端末内に保存）。ABを上手に使うほど、タイムが縮むようにします。結果画面に、今回のタイムと自己ベストを並べて出します。

### 5. 「見えているのに取れない」を記録で分かるようにする

- 区間ごとに、目標に**一番近づいた距離**と、取れる範囲の近く（目安：15m以内）を通り過ぎたのに取れなかった回数を記録します。
- これで、取れる範囲がシビアすぎるのか、案内の問題なのかを判断できるようにします。取れる範囲の大きさは、今回は変えません。

### 6. 保存済みの古い設定の扱い

- ステージの広さが変わって初期値が変わった設定（レーダーの範囲など）は、古い保存値が残っている場合に、一度だけ「新しい初期値（180m）に更新しますか」と案内するか、更新して画面で知らせます。どちらにしたかを記録してください。

### 7. 設定・記録・版番号

- 調整パネルに、地面の模様の濃さ（任意）、すれ違う音のオン・オフ、ABのBGM切り替えのオン・オフを追加し、早見表（`docs/settings-guide.md`）にも説明を足します。
- 記録とコピーに、5.の項目、コースのタイムと自己ベスト、AB直線区間でABを使ったかどうかを追加します。
- 版番号を上げ、README と `docs/verification-v01xx.md` を更新します。描画と音の処理の重さを、変更の前後で比べて記録します。

## 変えないもの

- 旋回の強さ、揚力・落下・失速の計算、巡航・最高速度、ABの速度と推力、ゲージの量。
- 光・出口を取れる判定の大きさ。
- 操縦の入力、振動の仕組み、HUDの英語表記。

## テスト

- 単体テスト：
  - 風切り音の値が、0〜45m/sの範囲で頭打ちにならず変化すること。
  - ABのBGM切り替え（拍への合わせ方、最低保持時間、元の曲への戻り方）。
  - コースの直線区間の長さの検証。3コースが合格すること。
  - 一番近づいた距離と、近くを通り過ぎた回数の記録。
  - タイムと自己ベストの保存。
- ブラウザーテスト：
  - コースのどこを飛んでも、地面に模様があること（中央の外でも）。
  - AB中にBGMが切り替わり、終わると戻ること。オフにすると切り替わらないこと。
  - 結果画面にタイムと自己ベストが出ること。
  - 古いレーダーの保存値に対する案内（または更新）。
  - 390×844・360×640・844×390で、表示が重ならないこと。
- 既存のテストはすべて通ること。
- 実機でのスピード感、音の変化、BGMの切り替わり方、ABの爽快感、描画と音の重さは、Pixel 9aでの確認を「未確認」として記録に残してください。

## 判断の範囲

**発案者（田中）の指示で変えてよいもの**
- 地面の模様の種類・大きさ・色、通過物の種類と並べ方。
- 風切り音・AB音・すれ違う音の音色と変化のしかた。
- AB用の曲の内容と切り替え方。
- 直線区間の長さと印、タイムの表示のしかた。
- 実装方法（より良い方法があれば、理由を記録して採用してください）。

**変えないもの（指示があっても確認してから）**
- 光・出口を取れる判定を大きくすること。
- 速度の表示を実際の速度と違う値にすること。
- 既存の曲を写すこと、似せること。
- 端末の外へ情報を送る処理の追加（設定・記録・自己ベストは端末内だけで扱う）。
- 開始ボタンを押す前に音や振動を出すこと。

分からない点や、この指示どおりでは難しい点があれば、勝手に範囲を狭めずに、理由を書いて質問してください。
