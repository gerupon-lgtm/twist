# v0.1.44 — TWIST VECTOR／音速突破とFM

今回の依頼は会話の指示を仕様とする。v43のきりもみは、利用者から実機で解消したとの返答あり。これは当該症状の確認であり、端末試験全項目の承認とはしない。

- 正式名称を **TWIST VECTOR** に変更。タイトル画面、プレイ画面の小型ロゴ、ブラウザー名、PWA名、現在の案内ページへ反映。Tilt to Play. と配色は保持。保存キー、URL、リポジトリ名、過去の公開版は変更しない。
- 音速上抜けを1回だけ消費し、約0.95秒の拡散する圧力リング、周辺の白い霧、強い流線を表示。追尾3Dでは機体後方にも拡散する輪を出す。操縦席にも周辺リングを表示し、中央を白く塗り潰さない。動きを減らす設定では輪を固定して減衰する。停止・終了・再開時に遅れて再生しない。
- 爆発音は新規の短い二重の破裂と低音の余韻（0.85秒）。既存の音量・効果音設定に従い、地面などの警告、取得音、一時停止を優先。下抜けは控えめにする。振動パターンは保持。
- 追加依頼の炎は**音速超え中**のみ。出力があるとき、長い青白い芯・青紫の中間層・橙の外炎と噴射内の明るい節を表示。無出力・亜音速は従来へ戻す。機体や衝突判定、速度、操縦入力は変更しない。現実を意識した色使いのゲーム演出であり、燃焼の物理計算ではない。
- FMのみ旋律と伴奏の出力を増やす。ギターは歪み・持続・明るい倍音を強め、ベースは基音の芯と歪みを加え、硬さと厚みを持たせる。ドラムは従来PSG。SCCの音色、演奏データ、音量経路は保持。音量差は数値と試聴を分けて扱う。

検証は小分け・1組ずつ。実機の迫力、音色の好み、画面の見やすさはPCの音声計算や画面確認だけでは確定しない。
