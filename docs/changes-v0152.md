# v0.1.52 変更内容

v0.1.51は計器全体の面を濃くしたため、景色が見えづらくなった。全体の濃さだけで文字の読みやすさを確保する方針を変更し、大きな面と文字の下地を分ける。

- 大きな面は濃さ86%から28%へ変更し、背景を約72%透かす。
- 数値・項目名・小さい補助値のすぐ後ろにだけ濃い下地を付け、明るい文字の読みやすさを保つ。
- 主な数値の下地は文字幅に合わせる。計器いっぱいに濃い帯を広げない。
- 方位や目標高度も同じ考え方で、文字の周りだけ濃くする。地面・失速・出口開放などの警告は読み取りを優先した濃さを残す。

A/B/C、外から・追尾3D・操縦席に共通。円形の面が文字を覆わない修正も維持する。操縦・コース・記録・音は変更しない。

版とキャッシュ更新番号を0.1.52へ変更し、公開確認済みの0.1.51本編33ファイルを保存版へ追加する。
