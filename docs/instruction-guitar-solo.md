# リードのエレキギターだけをアレンジする

2026-11-08受領。v33のデプロイ後に着手する追加依頼。まだ未実装・未公開。

利用者は「BGMのリードギターの部分を、ディストーションギターでハードロックギターのギターソロのようにアレンジ」「ビブラートやチョーキングなど、エレキギターならではの奏法」「エレキギターでないところは、今回は変えない」と指定した。

leadという役割だけでギターと決めず、元の生成器・MML仕様・楽器の記述で対象を特定する。ギター以外の旋律、伴奏・低音・打楽器、曲全体の長さ・テンポ・ループ・曲順・クリア曲は保持する。曲全体へ歪みやピッチの揺れを掛けない。元のv33は公開検査済みの保存版バイトとして保持する。

現MIDIのピッチベンド幅はSCC/FMとも上下2半音。指定された幅の動きでチョーキング・ビブラート等を表し、楽器指定のない旧曲やシンセを推測だけでギターへ変えない。対象専用の音色にし、共通lead音色の変更をギター以外へ波及させない。判断根拠と保持の検査を次版の実装資料へ残す。

作業順は、公開を済ませたv33の次にこのギター調整をv34として行い、準備済みの新UI・導入音をv35へ、手首・シエラをその後へ送る。これは新依頼を別の公開単位へ分ける段取りで、UI依頼の取消ではない。
