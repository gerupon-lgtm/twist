# リードのエレキギターだけをアレンジする

2026-11-08受領。v33のデプロイ後に着手する追加依頼。v34として実装・検証・公開を完了した。[検証記録](verification-v0134.md)。実機の聴感は未確認。

利用者は「BGMのリードギターの部分を、ディストーションギターでハードロックギターのギターソロのようにアレンジ」「ビブラートやチョーキングなど、エレキギターならではの奏法」「エレキギターでないところは、今回は変えない」と指定した。

leadという役割だけでギターと決めず、元の生成器・MML仕様・楽器の記述で対象を特定する。ギター以外の旋律、伴奏・低音・打楽器、曲全体の長さ・テンポ・ループ・曲順・クリア曲は保持する。曲全体へ歪みやピッチの揺れを掛けない。元のv33は公開検査済みの保存版バイトとして保持する。

現MIDIのピッチベンド幅はSCC/FMとも上下2半音。指定された幅の動きでチョーキング・ビブラート等を表し、楽器指定のない旧曲やシンセを推測だけでギターへ変えない。対象専用の音色にし、共通lead音色の変更をギター以外へ波及させない。判断根拠と保持の検査を次版の実装資料へ残す。

元の資料から対象と確認したのは、黒曜の翼・鋼翼の鼓動・黎明の航跡・嵐を越えて・Overdrive Horizonの主旋律。それに、利用者が明示的に選んだIgnition Skyの主旋律を加え、計6曲のMIDIチャンネル1だけを対象にする。Ignition Skyは元資料ではシンセ・ブラスであり、今回の追加指定による例外である。伴奏側のギターやシンセの応答は対象に広げない。

今回はSCCの専用波形を優先し、FMの既存音色定義・楽器割当ては変えない。FMでも同じ譜面のチョーキング等は再生する。FMでギター・ロックベース等を個別に割り当てること、ステージのテーマ別の選曲は後続の相談として残し、今回勝手に対応表を決めない。

Ignition Skyの18小節目はC#5からE5への上向きチョーキングを一つの持続音で表す。元の開始時刻・Eに届く時刻・終わる時刻を保つ。全体のベンド幅は広げず、対象の基準音と曲げ始めの値を組み合わせる。その他の元メロディーの弾き始めの実際の音程は保ち、下から滑らせる奏法は独自に追加する短い応答音に限る。

提供された参考MIDIは、利用者が「あくまでも参考」「そのまま採用はなし」と指定した。音程を上げる速さ・幅・戻り方の参考として読み、音符列・演奏データ・波形をそのまま移さない。元の曲を土台に独自に調整し、参考例より控えめな頻度と揺れ幅にする。

初回の音源セットはSCC／Ignition Sky、個別試聴は閃光の帰還、クリア曲は突破の凱歌、AB音楽・すれ違う音はオン。保存済みの明示選択とURL指定を優先し、読込時に勝手に保存値を書き換えない。

開始の最後のGO音を約1.5秒とし、実際に鳴り終わってからBGMを始める。3・2・1の間隔、GOで飛行と記録が始まる時点は保つ。消音・効果音オフ・再生不可の場合は聞こえない音のための1.5秒待機を追加しない。停止・中断・画面切替では古い再生予約を取り消す。

作業順は、公開を済ませたv33の次にこのギター調整をv34として行い、準備済みの新UI・導入音をv35へ、手首・シエラをその後へ送る。これは新依頼を別の公開単位へ分ける段取りで、UI依頼の取消ではない。
