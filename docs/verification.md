## スマホの実機で確認すること（未確認）

未確認の項目は検証範囲から除外していません。公開URLから順に試します。

| 操作 | 確認すること |
|---|---|
| Safari / Chromeで開始 | 許可が出るか、3方向を読めるか、基準を合わせられるか |
| 前後・左右に各少し傾ける | 想定した方向に回り、保持中に旋回を続けるか |
| 右にひねって保持 | 前進し、保持中に途切れないか |
| ひねりだけ基準へ戻す | 意図したタイミングで止まるか、手ぶれで進まないか |
| ひねったまま上下左右へ傾ける | 速さが不意に変わらず、同時操作しやすいか |
| 停止したまま周囲を見る | 上下・背後の案内を読み、進路を決められるか |
| 上下・左右に一周旋回 | 途中で止まらず、画面を見ながら操れるか |
| 持ち直す・縦横を変える | 停止と基準合わせで復帰できるか |
| 別アプリから戻る | 勝手に前進せず、明示した再開から動くか |
| 数分間遊ぶ | 方角のずれ、酔いやすさ、発熱、実機の描画速度 |

端末やブラウザーごとにセンサーの通知方法が異なります。静止中の通知がない端末では、停止して再基準合わせを求める場合があります。回転の通知だけ届き向きが更新されない状態は、古い速度を保持しないよう停止します。判定のしやすさも実機で調整します。

広場の柱や浮島は奥行きを感じる目印で、この試作には障害物との衝突判定はありません。上下・外周には探索範囲の上限があります。
