# v0.1.33 音楽の整理・SCC/FM・クリア曲・開始前待機

2026-11-08。**ローカル確認済み・公開確認待ち。** 公開・保存版を確認したv32の後に、依頼済みの音楽改修を別版で進める。根拠は[instruction-bgm-fm.md](instruction-bgm-fm.md)。独立したSMF書き出し・ZIP納品は利用者が取り消したため作らない。

ゲーム用の曲順と、聴いて選ぶ曲を同じ設定にすると、旧曲の試聴が飛行中の選択にも混ざる。通常再生は黒曜の翼以降の7曲、試聴は既存13曲と新クリア3曲の全16曲を個別に選ぶ形へ分ける。最初の2曲・勇進の航路を削除せず、ゲームには使わない。AB追加打楽器・比較曲・クリア曲はそれぞれの用途を保ち、単曲試聴だけを許す。

SCC/FMは旋律と和音の音色だけを切り替える。低音はSCC、打楽器はPSGのまま、同じMIDI・音符・時計・音量と停止の仕組みを使う。初期値はSCC。音源を設定で変更した時は次の再生から反映し、試聴中だけ先頭から再開する。同位置の音源切替は追加しない。

軽量FMは、音を出す発振器と音色を変える発振器を組み合わせた独立の2オペレーター方式とする。サエズリズムで確認した役割・停止管理・高音の変調抑制という原理を参考にし、コード・音色表・数値は複製しない。参照元の全楽器がFMという前提にはしない。

新しい短いクリア曲3曲は、それぞれ勇敢に開く・重く勝つ・速く帰還する構成とし、音数を増やし続けず主旋律と終音を聴かせる。既存「突破の凱歌」は初期選択として残し、4曲を明示選択する。既存13個のMIDIは原本のバイトを保ち、新3個だけを生成する。

古い保存値は読み込みだけで書き換えない。古い曲集はゲーム採用7曲との共通部分へ解決し、旧3曲だけの指定なら採用7曲へ戻す。旧曲を指定したURLは試聴候補として扱い、ゲームへの採用に戻さない。試聴の選択と履歴は本編の曲順・飛行時計・記録と分ける。

検証範囲は全16曲の音符・終端・音量・曲別パート、SCCの保持、FMの全停止・残音・高音・負荷、試聴の許可・取消・設定保持、通常飛行・高速空域・公開を含む。音符を減らして合格させない。PCでの発音・数値検査と、Pixel 9aでの聴感・操作・発熱は区別する。[検証記録](verification-v0133.md)。

## 追加指定：最初の3の前に待つ

利用者から「カウントダウンが表示される前に少し待機」「3の時に音が出ていない」と指定された。従来の音源準備待ちは250msが目安で、準備が遅いと3の音を消費して無音となり、2から鳴る条件があった。実端末で同一原因とはまだ断定しないが、実音源のモジュール準備だけを700ms遅らせる再現では、修正前は実際に3が欠けて2・1・GOだけ受信した。

音源準備待ちの目安を1500msへ延ばし、その完了後は数字3の前に最低500msの無音待機を設ける。既存の全画面案内のための長い待機とは最大値を取り、二重には足さない。待機中は「開始の準備をしています」と…を表示する。音源が使えない場合も期限後は無音で進め、遅れた拍を後から再生しない。待機・地図・3秒のカウントダウンは飛行の経過時間へ含めず、通常の一時停止再開には追加しない。取消・画面離脱・向き変更・設定への移動による予約取消は維持する。

## 準備中の設定変更も取り消す

曲の読み込み・音源準備・resumeの途中は再生中の曲がまだ未設定になる。そこでもBGM/SFXオフ・曲/音源変更が旧要求を取り消すよう、保留中の要求を同一性付きで保持する。古い要求の終了処理は新しい要求を消さず、音量など無関係な変更は再生を取り消さない。関連28条件の失敗再現後に修正し、最終Nodeと音楽境界を確認した。
