# v0.1.43 高速コースの回転表示・シエラ1/50の速度

基準は公開v42の記録コミット`a9648f6`。利用者は高速空域と1/10のひねる・手首で開始直後にきりもみになると報告。合わせ直しても変わらず、表示設定は不明。併せて1/50の無制限ABと通常最高速度向上を指定した。今回の指定で、v42までの「1/50の速度は変更しない」という条件を更新する。

## 回転の原因と確認できる範囲

スマホから得た角度は度、共通の表示計算はラジアン（円1周を約6.28と数える単位）。通常コースでは変換していたが、高速2コースでは端末回転と画面向き変更の両方を未変換で渡していた。固定表示で約57.3倍として解釈され、わずかな動きでも画面が大きく回る。物理上の操縦入力とは別の不具合である。

修正前の本編実描画で、手首1度による画面内の約0.707度の補正が0.707ラジアン（約40.5度）になることを再現。描画の入口で一度だけ変換する。センサーの取得式、操作の符号、9G/速度・燃料、通常コースの表示は変更しない。実機の報告がこの経路だけで説明できるかは未確認として残す。

カウントダウン中に25度持ち変える別試験では、旧基準に対する旋回指令が入り開始直後に67度のバンクが出た。しかし、持ち直しても症状が続くとの返答があり、この試験を実機の原因確定や修正根拠には使わない。開始後に勝手に中立へ戻す変更も入れない。固定姿勢・小さな連続入力・画面向き変更・合わせ直し・全3視点を別々に検証する。

## シエラ1/50だけの飛行条件

|条件|従来|今回|
|---|---:|---:|
|開始/出力50%の水平巡航|10m/s|25m/s|
|通常の全体速度上限|30m/s|60m/s|
|AB上限|45m/s|75m/s|
|AB燃料|取得/低空で補充|無制限|
|旋回の強さ|保存設定、初期9.8|このコースだけ15|

通常の水平出力100%の釣り合いは約35.4m/s。60m/sは下降などを含む上限であり、出力100%にするだけで60m/sになるという意味ではない。ABはこれまでのスロットル110%操作で何度でも継続使用できる。解除後の慣性を60へ即時に切らず、自然に減速させる。一時停止/接地/完了では解除し、再使用にはスロットルを戻す。HUDは∞、コピーは実際の使用秒と残量100を記録する。

速度を上げるほど同じ翼の傾きでは曲がる半径が大きくなるため、旋回の強さを既存設定の上限15でコース固定にする。最大翼角は保存設定に従う。旋回の強さは既存の調整範囲3〜15に収める。実際の操縦入力による全区間完走とAB区間を確かめ、最高速のまま全角を曲がれるとは約束しない。

専用条件は`course-flight-profile.js`へまとめ、旧通常モデルを同じ値で移す。通常3コースと探索の操作/位置/速度、シエラ1/10・高速空域の飛行計算は維持。1/50の保存操縦設定を書き換えず、効かない旋回強度の調整欄を隠し、コピーに実効条件を載せる。速度条件が違う自己ベストを比較しないよう、1/50の飛行キーだけ条件IDを含める。旧記録は消さず、探索のキーも保持する。

表示版とキャッシュ識別子は0.1.43。公開照合済みv42の33ファイルを保存版へ確保済み。検証の結果と実機で確認してほしい点は[verification-v0143.md](verification-v0143.md)へまとめる。
